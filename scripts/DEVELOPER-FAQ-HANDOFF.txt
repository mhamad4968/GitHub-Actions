         scripts/faq-portal-ONLY-1-and-2.tar.gz
        （他に FAQ 関連を触ったらそれも）

  [ ] git commit / git push（合意ブランチへ。現状: feature/calculate-tax）

  scripts/faq-kintone-proxy/.env … 秘密。リポジトリに入れない。
