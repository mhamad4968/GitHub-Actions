■ 5. Grok 4.5 だけ詳しく（L2b 追補）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【位置】6役の番号ではない。Composer の「後段」担当。

  【モード B（デフォルト）】
    · 調査・修正案・単発 Edit
    · CIO が都度 OK を出す

  【モード C（検証ループ）】— 次の7つ全部そろったときだけ
    1. DeepSeek §50-3-8 済み
    2. Composer 初回 Diff 済み
    3. 対象 1アプリ・パス固定
    4. deploy / push / kintone PUT 禁止
    5. 終了条件が npm で機械判定できる
    6. 実行契約を CIO がチャットに貼った
    7. 上限: 15回 / 10分 / 同一エラー3回

  【Grok がやれる】in-scope 内の Edit、lint/test 系 npm
  【Grok がやれない】deploy、push、仕様変更、指揮権

  【lint 赤だけ】Fable より先に Grok C を試す（コスト節約）
