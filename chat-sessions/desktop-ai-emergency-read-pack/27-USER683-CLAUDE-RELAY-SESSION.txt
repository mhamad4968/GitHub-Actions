  1) リポルートへ移動:

  2) 683 で Claude 要約を使う日の「PC 側」:

       npm run deploy:683

  5) ブラウザは 683 を **強制再読込**（古い desktop.js を掴まない）

  「ループバック」「PNA」「127.0.0.1」
    → HTTPS の cybozu からは **http://127.0.0.1 直は不可**。必ず **トンネルの https URL**。

  「CORS」「preflight」「Access-Control-Allow-Origin」
    → 中継は **RELAY_BUILD cors-v3** 以降を **PC で再起動**（古い Python プロセスを止める）。
    → 683 側は **Content-Type: text/plain** で POST（プリフライト回避）。deploy 済みか確認。

  「中継 URL 未設定」アラート
    → 手順 3 のクエリ or window 変数が未適用。アドレス欄貼り付け後にもう一度 683 を開き直す。

  疎通（PowerShell）:
       Test-NetConnection -ComputerName 127.0.0.1 -Port 17884
