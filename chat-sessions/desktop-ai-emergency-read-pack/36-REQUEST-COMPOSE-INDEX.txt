【依頼効率化ツール v0.1 — 早見】2026-07-11（#R-GO-BOUNDARY-01 追補）

**使い方（浜田）**: チャットで「依頼文を作って」+ やりたいことを自然文で。

**AI の役割**:
  1. 足りない項目だけ聞き返し（レーン / 一行 / app / GO）
  2. `npm run cio:request:compose` でブロック生成
  3. **5行ブロックを提示 → 浜田 OK（確認A）**
  4. **確認A ≠ 実装GO** — 次は浜田の調査指示 or 実装GOを待つ
