**AI の役割**:
  1. 足りない項目だけ聞き返し（レーン / 一行 / app / GO）
  2. `npm run cio:request:compose` でブロック生成（先頭に【段階】· 既定ログ）
  3. **ブロック提示 → 浜田 OK（確認A）**
  4. **確認Aの次は調査指示 or 実装GOを待つ**（勝手に実装しない）

| 浜田 | 段階 | AI がしてよい | 禁止 |
|------|------|---------------|------|
| compose **OK** | 確認A | 依頼文確定 | コード変更 |
| **「調査から」** | G0調査 | 読取・報告・修正案 | 実装・deploy・commit |
| **「実装GO」**等 | G2実装 | コード変更・gate・deploy | スコープ外 |

**調査時の compose**:
  npm run cio:request:compose -- --lane kintone --intent "…" --app NNN --phase investigate

**実装GO後**（--phase implement が既定）:
  cio:pre-implement-gate → tool:route → 実装 → preflight → deploy
