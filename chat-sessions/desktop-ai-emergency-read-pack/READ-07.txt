## 1. Project Rules と「理解しているか」

特定のフォルダに対してルールや知識を固定できる **Project Rules** は、**自動読み込み（alwaysApply / glob）でコンテキストに載る設定になっている**想定でよい。

ただし **「自動で載る＝条文をすべて暗記済み」とは限らない**。ルールに書かれたことは **厳守**し、**例外・知らなかった**は使わない。必要なら **該当 `.mdc` / `AGENTS.md` を Read で正本確認**する。

---

## 2. 絶対に守ってほしいこと（憲法・ルール）

対応するときは次を **例外なし**で守る。

- **憲法・ルールを厳守**（例外や「知らなかった」はない前提で動く）。
- **壁時計**: **`npm run session:clock:set`** と、**`npm run session:clock:web` の URL をチャットに提示**し、浜田がブラウザで開けるようにする（スターター・§51-6-2 運用どおり）。
