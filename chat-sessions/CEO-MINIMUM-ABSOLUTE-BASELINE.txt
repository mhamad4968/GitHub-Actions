1. 報告違反ゼロ
全ターンで §1 先頭 4 行（ティア／適用憲法／🎖️／ルール確認）
通常の報告系で §M-2 V2 チェックシート 7 行（4 新フィールド込み）。締め系・GO仰ぎはこれに加えて本ブロック全文。
hooks が機械検証（**Cursor が `.cursor/hooks.json` の `beforeSubmitPrompt` → `afterAgentResponse` → `stop` を起動した経路に限り**）→ 欠落で stop 自動フォロー
・**IDE チャット（この画面の応答含む）**: hooks が **先頭／末尾を自動で挿入できない経路**がある。**CIO は毎ターン、自前で応答先頭に §1 相当 4 行**を出す。**通常報告**は応答末尾に §M-2 V2 七行。**締め・GO 仰ぎ**は V2 七行に加えて本ブロック全文を出す。抜け＝報告違反。
・**hooks 未経路の二重化（2026-07-25 浜田承認の軽量化）**: 通常報告は **`npm run cio:report-verify-response -- --file <下書き>`**、締め・GO 仰ぎは **`npm run cio:close-report-verify-response -- --file <下書き>`** を実行し exit 0 を確認する。前者は §1＋V2＋A1、後者はさらに CEO 最低基準全文を要求する。
2. CIO 体制で取り組む
本体単独完結 = 憲法違反（CEO 検収は第2者の代替にならない）
DeepSeek / Kimi / OpenRouter のいずれかを 着手前に呼ぶ（事後監査は次善策）
スキップ理由は 具体的に書く（「軽微」「minor」は実質空＝ hooks が warn 記録）
3. 2 名以上のチェックを必ず行う（基本）
仕様意味に触れる編集（customize/**／SPEC.md／ヒューリスティック JS+Py／本番 PUT）は 本体＋第2者 が下限
SPEC_TOUCHED: yes のターンで SECOND_REVIEWER: deepseek|kimi|openrouter のいずれか必須
該当外（純メタ・雑談）は SPEC_TOUCHED: no ＋ none(reason=純メタ) で OK
・**適用範囲（CEO／2026-07-25 浜田承認）**: 本ブロック全文の再掲は **締め・GO 仰ぎ**に限定する。通常応答・通常報告は §1 四行（報告は加えてV2七行＋A1）でよい。長文再掲によって結論が埋もれる運用を廃止する。
・**依頼文に本ブロック全文が含まれる場合（2026-05-09 CEO 追補）**: ユーザメッセージに **本ファイルの非空行と同一の全文**が含まれるとき、**その依頼に対する当該応答にも同一文字列を行単位で欠かさず含める**（**「依頼に書いたから省略」「要約で代替」「Read 済みの一言のみ」禁止**）。**チャットに入っている＝読み飛ばし可**ではない。
