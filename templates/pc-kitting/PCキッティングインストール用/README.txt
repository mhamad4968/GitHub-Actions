# ドメイン参加後インストール（Windows 11 Pro 向け）

配置: デスクトップ **`PCキッティングインストール用`** フォルダ内

**前提:** ドメイン参加が完了していること。  
**`PCキッティング_インストール_START.bat`** をダブルクリック（管理者 / UAC）。

## フォルダ構成

```
デスクトップ\PCキッティングインストール用\
  PCキッティング_インストール_START.bat   … 起動用（ここをダブルクリック）
  PCキッティング\
    post-domain-install.ps1
    kitting-encoding.ps1
  （新）キッティングセット\              … USB から取得したセット一式
    5… 6zoom  7office365  8デスクトップ…  等
```

USB からキッティングする場合は、**このフォルダごと**デスクトップにコピーしてください。

## 処理の流れ

1. **開始確認** … はい・いいえ
2. **1～10 フォルダを順番に実行** … フォルダ名先頭の数字で順序決定
3. **Office / Zoom / VPN** … インストール後、全ユーザー共通デスクトップにアイコン配置
4. **8番（デスクトップショートカット）** … ブロック解除 → 配置 → 4列グリッドで初期整列
5. **信頼済みサイト** … キッティングセット内の `.url` からドメインを自動登録（http/https・全ユーザー）
6. **右クリックメニュー** … Windows 11 を旧仕様（クラシック）に変更
7. **完了後** … 60 秒後に自動再起動

## （新）キッティングセットのフォルダ例

| 番号 | 例 | 内容 |
|------|-----|------|
| 5 | 5新ウイルスソフト… | Trellix 等 |
| 6 | 6zoom | Zoom |
| 7 | 7office365 | Office 365 |
| 8 | 8デスクトップに置くショートカット | .lnk / .url |
| 9 | 9もろもろ | その他 EXE |
| 10 | 10右クリック… | 任意（未設定時は自動で旧仕様化） |

※ 1～10 のうち **存在する番号だけ** 実行します。

**処理しません（触りません）:** `その他` `自動化ツール` など、番号の付いていないフォルダ（ログイン情報・メモ用）。

## ログ

| 場所 | 用途 |
|------|------|
| **`PCキッティングインストール用\logs\`** | 共有用（**`最新.log`** を AI に見せる） |
| `C:\ProgramData\JBIS-PC-Kitting\logs\` | システム側の控え |

エラー時は **`logs` フォルダごと**、または **`最新.log`** を Cursor に貼り付け／添付してください。

## 文字化け防止

- すべて UTF-8（BOM 付き）で保存
- 日本語は PowerShell ウィンドウに表示（cmd には出さない）
- ログフォント: Meiryo UI

## ① ドメイン参加前のキッティング

別フォルダ **`PCキッテング用`** の `PCキッティング_START.bat` を使用してください。
