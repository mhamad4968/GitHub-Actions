### 月次予算・ラーニング費用・都度の計算上の分離（2026-04-28）

- **月次サブテーブルの「予算」**（下記「月度ブロック」各月の予算列）と、**ラーニング費用**（上表の列 G・明細キー側）と、**都度**（レコード単位の別フィールド）は **別経路で集計**する（浜田）。**三つを無条件に一つの予算総額へ足さない**（二重計上・消費率の母数誤りを防ぐ）。
- **集計・ダッシュ・計算フィールド・API 集計**では、**月次予算系**・**ラーニング用**・**都度用**を **それぞれ別々に計算**する。**単一の合算に畳み込まない**。総括が必要なときは **内訳付き**で示す（`SPEC.md` §6・§6b・§6c）。

## 月度ブロック（予算・実績・消費率・予算修正）

- **1 ヶ月 = 連続 4 列**: 予算 → 実績 → 消費率 → **予算修正**（＝**その月の修正項目**）。**12 ヶ月すべて**に本ブロックがあり、**いずれの月も「予算修正」列を省略しない**（浜田・新フォームで月ごとの修正が必要・2026-04-28）。
- **年度内の並び**: 5月 → 6月 → … → 3月 → **4月**（12 ヶ月）。
- **起点列（行3に月名が入る列）**: 5月=7(G), 6月=11(K), 7月=15(O), 8月=19(S), 9月=23(W), 10月=27(AA), 11月=31(AE), 12月=35(AI), 1月=39(AM), 2月=43(AQ), 3月=47(AU), 4月=51(AY)。

式（0=5月 … 11=4月）: **起点列 = 7 + 4 × n**（Excel 列番号）。

## 右側の集計列（概要）

列 **BC** 付近から、**摘要別集計**・**固定費小計**・**変動費小計**など、工種別集計と四つ柱（予算・実績・消費率・予算修正）に対応する列が続く。セル結合が多い（例: 工種名称の縦結合、集計ブロックの見出し結合）。**仕様合意（2026-04-28）**: 本ブロックも含め **`新フォーマット` の項目はすべて kintone に載せる**（実装は計算フィールド・数値フィールド・customize / REST API で再現。有償プラグインは使わない）。

## kintone / CSV 設計メモ（次ステップ）

1. **実績の帰属月**は **支払日（出納日）ベース**（`SPEC.md` §8）。**集約の主軸**は **摘要（請求内容）に紐づく本シートの明細行**（複数請求は同一明細の月次実績へ合算・`SPEC.md` §6）。本シートの行だけでは支払日列が無い場合、kintone 側で **支払内訳サブテーブル**または台帳からの **API ロールアップ**が必要。
2. **明細 1 行 = レコード** とし、**12 × 4 = 48 の月度値**をサブテーブル行にするか、月キー付きの子アプリにするか、仕様で決める。
3. **消費率**は実績÷予算の派生なら、入力禁止の計算にできる。
4. Excel の結合セルは **CSV 化で崩れる**ため、取込バッチは「結合解除済みコピー」か、**正本をスプレッドシートに寄せてから**エクスポートする運用を検討する。
