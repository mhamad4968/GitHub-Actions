## 何が変わったか

1. **会社名・氏名の列を、統括の原価行から外した**  
   同じブロックの中で、同じ費目・同じ種別なら **1行にまとめる**（会社や人が違っても、統括では分けない）。

2. **行の単位**は **内訳のブロック × 費目 × 種別**  
   内訳のブロックが違うと同じ費目でも別行。ブロックをまたいで足し合わせない。

3. **画面と印刷は同じ 11 列**  
   内訳№ / 区分 / 工種番号 / システム工種 / 種別 / 材料 / 単位 / 数量 / 単価 / 金額 / 備考

- 給与手当の氏名
- 工事原価管理（予実）タブの作り直し
- 作業者設定タブ
