## 2. コード表の列構造

| ブロック | 列 | 例 |
|----------|-----|-----|
| **項目 / 費目** | コード / 名称 | `100` 材料費、`437` 運送費、`211` 外注労務費 |
| **システム工種** | コード / 名称 | `10100` （塗）材料費 |
| **種別（補助）** | コード / 名称 | （空）**塗料** / `12401` （塗）出張旅費特例 |
| **定義及び品名** | 文字 | 剥離剤･塗料･… |

**階層イメージ**

```
施工費 > 100 材料費 > 10100 （塗）材料費 > [補助] 塗料
                      └ 10100 > 鋼材･二次製品費など
                      └ 10100 > その他材料費
外注費 > 10200 （塗）塗装工事 > 材料費（補助）
```

## 3. 総括表サンプルとの対応

| 総括表（2623001-001） | コード表 |
|----------------------|---------|
| 工種: 材料費 | 工種: `10100` （塗）材料費 |
| 種別: **塗料** | 種別（補助）: **塗料** ✓ |
| 種別: **その他** | 種別（補助）: **その他**（レンタル行等） |
| 種別: **注文金額** | コード表に **明示なし** → 詳細表リンク行用 **固定ラベル**（下記 §5） |
| 種別: **労務費等** | 補助「労務費」「出向工事管理者賃金」等で近似 |
