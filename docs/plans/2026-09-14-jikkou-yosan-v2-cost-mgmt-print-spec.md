## 1. 印刷ボタン（出す場所）

メインタブは `JY2_SHEET_LABELS`。原価管理の内側タブは `jy2-cmv2-tabs`（集計 / 詳細入力（施工） / 詳細入力（保安））。

| 場所 | ボタン |
|------|--------|
| 統括表 | 既存の「印刷」（統括帳票） |
| 内訳 | 既存の「印刷」（内訳帳票） |
| 工事原価管理 → **集計** | **印刷（金額）** と **印刷（回数）** |
| 工事原価管理 → 詳細入力（施工） / 詳細入力（保安） | **出さない** |
| 工事基本情報 / 休日設定 / バージョン管理 | **出さない** |

- いまの動き（内訳以外だと総括へ切り替えて統括を刷る）は、実装GO後にやめる。  
- **印刷（回数）** は、対象行が **1つもない** とき出さない。空の紙は出さない。  
- **印刷（金額）** は集計に出す（回数ボタンだけ消えても金額は残す）。  
- 統括・内訳のボタン名は「印刷」のまま。

**回数の対象行**: 原価管理マスタの **昼夜工種**（`dayNight`）で、**予定回数がある**か **月次の実績回数が1つでもある**。統括タブの数字は使わない。**ボタンを出す判定と帳票に載せる行は同じ**（ボタンがあるのに空紙、は禁止）。

## 2. 共通（金額・回数）

- **1工事の単票**。画面の説明文・ツールチップは載せない。  
- **縮小オフ**。  
- ヘッダは次だけ。統括の18項目（発注者・工期・安衛則など）は載せない。  
  - 工事名称（`project_name`）  
  - 工事コード（`project_code`。枝番があれば `工事コード-枝番`。空なら本体のみ）  
  - **版**＝版番号（`version_seq`）。版種別は載せない  
- 表の上: 「実行予算書」＋シート名  
  - 金額 → `工事原価管理（金額）`  
  - 回数 → `工事原価管理（回数）`  
- **0 は「0」**。未入力は空欄。  
- 数字のない工種は落とす。子が全部空ならシステム工種も落とす。施工計・保安計・総合計は **残った行だけ**。  
- 印刷直前は画面の未反映を flush する（既存の統括／内訳と同じ）。未保存の画面値を刷る。  
- 円・回数・率の桁・カンマは **画面と同じ**。

## 3. 印刷（金額）

| 項目 | 決 |
|------|----|
| 用紙 | **A4横**・余白約 **5mm** |
| 月 | 工事年度 **4月〜3月** の横12。セルは **実績だけ** |
| 左列 | システム工種・工種・当初・現予算・残・率 |
| 残 | **現予算 − その行の実績合計**（実績ベース） |
| 率 | 上記の残／現予算（画面の率計算に合わせるが、分子は実績合計） |
| 出さない | 見込、採用、予定回数、残回数、月の回数列 |
| 回数を円に足さない | 禁止 |

注記（表の下・2行。回数帳票には付けない）:

```
この帳票は月次・残・率を実績で出しています。
（注意）見込は載せていません。
```

画面の残は採用（見込を含む月がある）。紙の残は実績だけなので、画面と違うことがある。注記はそのための注意。

## 4. 印刷（回数）

| 項目 | 決 |
|------|----|
| 用紙 | **A4縦** |
| 列 | システム工種・工種・予定回数・残回数・4月〜3月の実績回数 |
| 残回数 | 画面と同じ。予定回数 − 月次実績回数の合計（空月は 0 として足す）。予定が未入力なら残は空 |
| 円 | 載せない |

向きは印刷の箱と CSS を揃える（横の `@page` に縦を流し込まない）。683 MediaBox の教訓。

## 7. 実装者制約（浜田確認済みの既決を壊さないための技術）

1. **専用 print-root を新設**する。`#jy2-print-portal` と `body.jy2-printing>:not(#jy2-print-portal)` に乗せない。測長に `visibility:hidden` を使わない（S-PRINT-ROOT-01）。  
2. 金額ジョブは `@page { size: A4 landscape; margin: 5mm }`。回数ジョブは `@page { size: A4 portrait; ... }`。**ジョブごとに向きを切り替える**（同時に両向きを1つの `@page` に固定しない）。  
3. 回数の母集合は原価管理の昼夜工種。統括・内訳のモデルを読まない。  
4. `desktop.js` は bundle。印刷 DOM は `desktop.ui.js`。80行超は Composer Subagent。CIO 本体は大量 Diff しない。  
5. 実装GOが出るまで、本節を先取りして customize しない。
