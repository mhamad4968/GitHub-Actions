## 7. 仕様への示唆（スキャン結論）

1. **取引先の正本リスト**は `データマスタ!J`（見出し「取引先」）。内訳の取引先欄（Y/AA 帯など）の DD がこれを参照。
2. **名称・規格のリスト**は主に `データマスタ!H`（および一部 `H$3:$H$11` の短い範囲・単一セル `H4`/`H6`）。ブロック種別で参照範囲が分かれている。
3. **システム／契約工種系**は `データマスタ!C`（総括の契約工種 DD も同系）。内訳の工種見出し行にも C 列サブレンジ。
4. **リスト外の実値**がある場合は、Excel運用上も手入力が行われている → 試作は **候補選択＋手入力可（コンボ）** が妥当。
5. 一部範囲は直書き `"現場経費"` のみ（名称グループ固定）。
