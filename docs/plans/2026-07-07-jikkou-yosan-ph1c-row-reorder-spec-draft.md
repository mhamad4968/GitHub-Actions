### 0.3.5 並び替え許可ゾーン原則（浜田 2026-07-07 · Q0 確定）

> **方針**: **並び替えを行ってよいところを限定**し、そのゾーン内だけ並び替え可とする（**許可リスト方式**）。  
> 全面許可＋禁止ルールではなく、**ブロックごとに「ここだけ可」**を S1/S2 で積み上げる。

| 区分 | 内容 |
|------|------|
| **設計** | 移動 UI は **許可ゾーンに入った行だけ** ⋮ に「行を移動」を出す · 移動先も **同一ゾーン内**に限定 |
| **計算安全** | **計算に問題・不具合が出ない範囲でのみ OK**（浜田 2026-07-07）— 実装時は `recalcState` / 小計集計 / ⑧合計の **回帰確認必須** |
| **常時不可** | 小計「計」行 · 外注テンプレの計算行（諸経費/合計/注文金額等）· ⑧⑨ フッター — **全ブロック共通で NG**（浜田 2026-07-07） |
| **ブロック別** | 下表 §0.3.5a — S1/S2 の Q0 で **ゾーン定義を追加**していく |

**#4 技術メモ**（2026-07-07）: `calcCostTotal8` は明細+連携行の **合計のみ**（順序非依存）。リスクは **小計グループ境界への誤挿入**（`applyCostGroupSubtotals` の遡り集計が変わる）のみ → **単独明細ゾーン内に移動先を閉じる**。

**#5 技術メモ**（2026-07-07）: グループ内明細の入替は **小計の合計値は不変**（加算の順序非依存）。リスクは **計行をまたぐ移動**・**別 `cost_group_key` への移動**（集計対象が変わる）→ **グループ内に移動先を閉じる**。

**#9〜#12 技術メモ**（2026-07-07）: `calcSubcontractBlock` の `detailSum` は **detail 行の合算**（順序非依存）。`SUB_CALC` 行は **位置で計算結果を書き戻す**ため移動 NG。許可ゾーンは **最初の `SUB_CALC` 行より上**の detail 行に閉じる。

### 0.3.6 PH1b 部分解凍候補 — 詳細・外注④〜⑦ テキスト行（浜田 2026-07-07 提案）

> **浜田**: ④〜⑦ であれば **テキスト行を追加できてもよいのでは** — **計算行は除く**。  
> **浜田（用途 · 確定 2026-07-07）**: **諸経費には計算式が入っている**が、**計算式を入れずにラベルとして利用できる**ようにしたい、という意味。  
> **浜田（訂正）**: 同じような使い方であって **同じ場所ではない**。

| 項目 | 内容 |
|------|------|
| **背景** | PH1b は 2026-07-06 **全体凍結** |
| **今回** | **詳細表・外注④〜⑦ ブロック内のみ** テキスト行追加を **再検討** |
| **使い方（確定）** | **諸経費行の「ラベル側」だけを切り出した行** — 種別・備考など **表示用テキスト**は書ける · **計算式・％・自動金額は持たない** |
| **諸経費との対比** | **諸経費**: 種別「諸経費」· 基準「上記金額合計の10%」· 数量 0.1 · 金額 **自動** · `SUB_CALC` · 移動/削除 NG / **テキスト行**: **同ブロック内の掲載行**だが **式なし** · `detailSum` **不加算** · 配置は **固定しない**（明細の間に ⋮ で上/下追加） |
| **制約（案）** | 既存 **計算行**（諸経費/合計/注文金額等）は変更しない · テキスト行は **`SUB_CALC` より上**のみ · 並び替えは detail＋テキスト行の許可ゾーン内 |
| **UX（案）** | ⋮ **「テキスト行を上/下に追加」** · 入力は **種別・備考（ラベル）**中心 · 数量/単価/金額は空または非表示 |
| **実装** | 新 `sub_row_kind`（例: `label`）· `calcSubcontractBlock` で **集計スキップ** · PH1c 並び替えとは **別機能** |
| **7/11 スコープ** | **(2) 仕様だけ起票** · implement は **7/11 以降**（浜田 2026-07-07）— **PH1c（並び替え）のみ 7/11** |
| **状態** | **用途確定** · **仕様起票待ち**（PH1b 部分解凍草案へ昇格予定） |

|------|------|
