## 合意（チャット 2026-09-10）

1 レコード＝1PC×1ソフトは維持。VL は同じシリアルを複数行に載せてよい。

| 項目 | 内容 |
|------|------|
| コピー | 製品名 / バージョン / シリアル番号（識別種別が「シリアル番号」のスロットのみ） / ライセンス種別（次画面は VL） |
| 空 | 利用者 / PC / 備考 / 識別スロットのプロダクトID等 |
| 新規保存成功後 | 「既に登録されています。これは VL ライセンスですか？」 |
| **はい** | 今の件は保存済 → 上記コピーの新規を開く |
| **いいえ** | **今の件は保存して終わる**（保存中止ではない） |
| 1件目 | 保存前は重複が無いので、**保存成功後**に同じ質問を出す |
| 買い切り／サブスク | 保存前の「登録しますか？」（はい＝保存 / いいえ＝保存中止）を維持。連続ループなし |
| 編集 | 連続しない |
| 別PCへ複製 | 残す（同じ人の2台目。今回の口増しとは別） |
