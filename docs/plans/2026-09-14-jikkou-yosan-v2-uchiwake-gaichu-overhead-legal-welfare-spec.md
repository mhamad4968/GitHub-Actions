## 2. 外注費と諸経費

外注費の中身は **材料費＋労務費＋仮設機械経費＋現場経費＋その他費用**（費目▼の5件。字面「外注費」だけではない）。

| 項目 | 決 |
|------|----|
| 置き場 | 上記14の **施工** ブロック末の自動フッタ |
| 計算 | 母数 × 10%（ROUND 0）。読取専用 |
| 母数 | 費目が5件のいずれか、または保存値が「外注費」 |
| 母数に入れない | 種別＝法定福利費。種別＝各種保険料(任意保険）。費目＝諸経費の明細 |
| 出さないとき | 対象外のシステム工種。保安。母数が1つも無い |
| マスタ行 | 諸経費は **作らない**（自動のため） |

---

## 3. 法定福利費（内訳）

マスタは費目名称＝その他費用、工種＝法定福利費。独立のシステム工種行もあるが、**内訳の工種一覧には出さない**（Q7 維持）。

| 項目 | 決 |
|------|----|
| 置き場 | 上記14のブロック内。費目＝その他費用、種別（工種）＝法定福利費 |
| 入力 | 明細の金額手入力 |
| 諸経費 | 外注費ではない。10%母数に入れない |
| 原価管理 | 独立システム工種行は残す（P9 マスタ全件）。内訳ブロックにはしない |

## 4. 運用 Excel の追記（作り直ししない）

各対象システム工種の外注費行の直下に 1 行足す。

- 区分・工種番号・システム工種は上の行に合わせる（番号が空なら空）  
- 費目名称＝その他費用  
- 工種＝法定福利費  
- 外注費の工種セル（5件の＋結合）は変えない  

運用 Excel が開いていて追記できないときは、同フォルダの `マスタ整理（システム工種）-見本-20260914.xlsx` を正の控えとする。閉じたあと本番ファイルへ行を移してよい。
