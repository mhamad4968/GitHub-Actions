## §1. 背景・目的

### 1.1 背景

- **JR システム**をインストールしたタブレット（iPad）を **Excel 1 シート**で管理している。
- 管理部署単位の **ステータス別台数**、端末ごとの **アカウント情報印刷** が必要。
- Apple ID は現状 **重複あり**（買替時に 1 台 1 アカウントへ移行予定）。移行時は **重複許容**。

### 1.2 目的

1. Excel と同等の台帳を kintone に置き、**日常操作はダッシュのみ**で行う。
2. **新規端末採番**（端末名 `JBIS*` + Apple ID `jb*m@icloud.com`）を **694 型 2 系統**で自動化。
3. **管理部署 × ステータス** の件数集計表をダッシュに常時表示。
4. **端末 1 台 = A4 1 枚** のアカウント情報印刷。

### 1.3 スコープ外（v1）

| 項目 | 理由 |
|------|------|
| **Apple ID 台帳 694 との連携** | 別ドメイン。ID プール共有はしない |
| **PC 台帳 674 との自動連携** | v1 独立台帳 |
| **集計表セルクリック絞込** | v1 は表示のみ（Q16） |
| **旧 `kent*` の新規採番** | **移行データのみ**（新規は `JBIS*` のみ） |
| **有償 kintone プラグイン** | 使用しない |

## §6. ステータスとライフサイクル

### 6.1 ステータス（DROP_DOWN `status`）

| 値 | 意味 |
|----|------|
| **待機** | 未貸出・在庫相当（Excel「空白は待機端末」） |
| **貸出中** | 貸出先入力あり |
| **確認中** | 動作・設定確認中 |
| **故障** | 故障・修理待ち等 |
| **廃棄** | 使用停止（履歴保持） |

**新規採番時の既定**: **待機**（自動セット）。

### 6.2 廃棄 vs 削除（Q12）

| 操作 | 意味 | 実装 |
|------|------|------|
| **廃棄** | 端末使用停止 | `status=廃棄`（レコード残存） |
| **削除** | 登録ミス・テスト行 | 編集モーダル内 **削除** + 確認ダイアログ → REST DELETE |

## §9. 採番・入力ルール

### 9.1 2 系統採番（694 型メタバー — Q6）

ダッシュ上部に **次採番を 2 行並列表示** + **「新規端末を作成」** ボタン。

| 項目 | 形式 | 次の値（2026-06-15 時点） | アルゴリズム |
|------|------|---------------------------|-------------|
| **端末名** | `JBIS` + **3 桁** | **JBIS009** | 既存 `JBIS###` の max + 1 |
| **Apple ID** | `jb` + **3 桁** + `m@icloud.com` | **jb007m@icloud.com** | 既存 `jb###m@icloud.com` の max + 1 |
| **Apple PW** | 固定 | **Honten00** | 新規 JBIS 系は自動セット |

**同時 POST**: ボタン 1 回で端末名・Apple ID・PW・ステータス（待機）・購入日（当日）・購入先（au）をセットし DB に POST → 編集モーダルを開く。

**legacy**: `kent*` 端末名・旧 Apple ID 形式は **移行データのみ**。新規採番では生成しない。

### 9.2 一意性・重複（Q5）

| フィールド | ルール |
|-----------|--------|
| `device_name` | **重複不可**（保存前チェック） |
| `phone_number` | **重複不可**（§9.4・数字のみ照合） |
| `apple_id` | **重複可** |

### 9.3 モデル欄（Q15 / Q17）

| 機能 | 内容 |
|------|------|
| **入力** | 自由入力 + **登録済みモデル一覧から選択**（コンボボックス） |
| **新規機種** | 一覧にない名前を入力して保存 → 次回から一覧に追加 |
| **保存時** | `NFKC` 正規化 + 前後空白除去 |
| **ゆれ統合** | 正規化後、既存 distinct と同一意味なら **既存表記に自動置換** |

**移行時の既存モデル（Excel 6 種）**:

- iPad（A16）128GB
- iPad（第10世代） 64GB
- iPad（第09世代） 64GB
- iPad Air2 16GB
- iPad Pro 10.5インチ 64GB
- iPad 4G LTE用 SIM

### 9.4 電話番号の保存時正規化（Q25）

| 処理 | 内容 |
|------|------|
| NFKC | 全角数字 → 半角等 |
| 空白除去 | 前後・途中スペース削除 |
| **重複チェック** | **数字のみ**で照合（ハイフン有無は同一番号） |
| 表示 | 正規化後の入力表記のまま保存 |
