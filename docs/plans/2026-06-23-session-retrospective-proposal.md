## A. 今日の教訓（事実）

1. **再計算パイプラインは保存フィールドを落とす** — `recalcState` → `costLineFromCalcRow` が `row_key` を捨て、差分・保存の両方に影響しうる。
2. **差分は「合計が合う」≠「行突合が正しい」** — ⑧⑨ が +7,600 で正しくても、53行「削除」誤表示があり得る。
3. **自動反映（連携・小計）を直接編集と同列に出すと誤解** — 材料1箇所変更で全体が変更に見えた。
4. **プレビュー機能は仕様 GO 前でもスモーク必須** — 担当者が触る前に「修正版1件・金額1箇所」シナリオを固定テストすべきだった。
