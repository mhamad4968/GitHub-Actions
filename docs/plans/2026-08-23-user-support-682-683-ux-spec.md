## §2. A — 682 入力

### A6（本命）

一覧ヘッダ（欠日・月切替ツールバー付近）に3ボタン:

| ボタン | 対象（JST） |
|--------|-------------|
| 昨日を作成 | 昨日 |
| 今日を作成 | 今日 |
| 翌日を作成 | 明日 |

- 対象日のレコードが **無い** → `record_date` のみ設定、件数 0、対応内容空で POST → **編集画面を開く**  
- **既にある** → 新規作成せず「既にあります」相当の通知のうえ **そのレコードの編集を開く**  
- 既存の暦日重複検査と両立

### A1

ヘッダに「昨日を開く」「今日を開く」（A6 と併置可）。無ければ「未作成」案内＋A6 誘導。

### A2

一覧で `am`/`pm` 本文が空かつ件数が空扱いの行と、明示 0 の行を視覚差（例: 行背景または件数セルのラベル）。フィールド追加なし。

### A3

新規・編集で対応内容 textarea を広く、件数フィールドは小さく／補助表示。

## §4. C — AI・月報コメント

### C1 プロンプト（週次・月次）

追記方針（既存の大型連休「稼働日減」文言は維持）:

- 土日祝に **実際に対応した内容**（件数>0）は **本来不要だが特別に行った対応** として区別して触れよ  
- 平日と同列の通常業務として書くな  
- 件数 0 の土日祝は特別扱いしない  

月次出力形式に追加:

```
【土・日・祝日対応】1〜3文または「土・日・祝日対応なし」。具体例があれば「土曜に…」等。コーパスに無い内容は書かない。全体は従来どおり完結（目安+80字以内で枠を食いすぎない）。
```

週次は200字以内のまま、該当があれば1点だけ特別に触れてよい。

### C2 コーパス

日次メモを LLM に渡す前に、特別対応日は行頭に `[特別対応・曜]` 等を付与（`user683-sync-summaries-to-kintone.mjs` および中継が読むコーパス経路）。

### C3

月次テンプレの【特別対応】枠（C1）。

### C4

文言変更後、対象月を `npm run user683:sync-summaries:apply -- --year Y --month M` で再生成（運用手順を完成報告／runbook に1行）。**本セッションではプロンプト反映まで必須・再生成実行は浜田確認後でも可**（API 費用・キー都合）。

対象ファイル: `scripts/user683-sync-summaries-to-kintone.mjs`・`scripts/user683_claude_relay.py`（プロンプト同期）。

## §5. 印刷（グラフ保護・必須）

| 規則 | 内容 |
|------|------|
| 枚数 | A4 **縦**・**2枚**厳守 |
| グラフ | 1枚目の棒／週グラフの **min-height・棒描画高さは現行維持**。縮小して余白を捻出しない |
