# UI `<details>` アコーデオン — 仕様チェックリスト（#I-SPEC-ACC-01）

**用途**: 688 気象ヘルプ・猛暑日オプション等、**通常は閉じる**折りたたみ UI を仕様化するときの必須項目。  
**参照実装**: [`2026-07-13-688-weather-ui-accordion-spec.md`](../plans/2026-07-13-688-weather-ui-accordion-spec.md)

---

## 必須（仕様に明記すること）

| # | 項目 | 例 |
|---|------|-----|
| 1 | **初期状態** | **閉じる**（`<details>` に `open` 属性を付けない） |
| 2 | **読込時の挙動** | レコード読込・`fillFormFromState` 後も **自動展開しない**（`details.open = false` を維持） |
| 3 | **サマリー文言（閉じたとき）** | ユーザーが開く理由が分かる 1 行（例:「〜を追加したい場合は開いて設定をしてください」） |
| 4 | **開いた中身** | タイトル · 注意書き（稼働計算に含めない等）· 操作 UI |
| 5 | **スコープ** | 折りたたみ対象と **常時表示** の境界（タブ・表は別、など） |

---

## 仕様テンプレ（コピー用）

```markdown
### N.N 〈機能名〉（アコーデオン）

| 項目 | 仕様 |
|------|------|
| 配置 | （画面上の位置） |
| 表示 | `<details>` · **初期は閉じる** · 読込時も **自動展開しない** |
| サマリー（閉） | 「（閉じたときの案内文）」 |
| 開いた中身 | （チェックボックス・手順・ボタン等） |
| 厳守 | （計算・印刷への影響があれば明記） |
```
