## 0. 目的

日常利用では画面を簡潔に保ち、**照合・監査用の気象庁 CSV 手順**と**猛暑日（参考）オプション**は **折りたたみ（`<details>`）** で隠す。必要なときだけ開いて操作する。

**計算ロジック・稼働日数への影響は変更しない**（UI のみ）。

---

## 1. 気象データの入手（過去5年・気象庁）

| 項目 | 仕様 |
|------|------|
| 配置 | 再算出バー直下 · 月別タブの直上 |
| 表示 | `<details>` アコーデオン · **初期状態は閉じる** |
| サマリー | 「気象データの入手（過去5年・気象庁）— 照合・監査用（通常は閉じる）」 |
| 本文 | 風速①・降雨②・猛暑日③の気象庁/環境省手順 · 各 `CSV→*` ボタン |
| 過去5年表 | タブ「過去5年(風速/降雨/猛暑日)」は **常時タブとして表示**（本アコーデオンとは別） |

※1 の月平均は **組込参照表**（過去5年タブ）を正とし、本ブロックは **監査・打合せ資料との照合用**。

---

## 2. 猛暑日オプション（参考のみ）

| 項目 | 仕様 |
|------|------|
| 配置 | フォーム行（風速/降雨閾値の下）· 全幅 |
| 表示 | `<details>` アコーデオン · **常に閉じた状態で表示**（読込時も自動展開しない） |
| サマリー（閉） | 「**猛暑日（WBGT・参考のみ）をオプションで追加したい場合は開いて設定をしてください**」 |
| 開いた中身 | タイトル · 「稼働可能日数・不稼働率・雨休率には含めません」注記 · チェック2つ |
| 画面表示 | `show_heat_reference` — 足場/塗装/休日の月別表に猛暑日行 |
| 印刷 | `print_heat_reference` — 施工主報告用印刷に猛暑日行 |
| 視覚 | オレンジ系枠 · チェックはカード風ラベル（操作しやすく） |

**厳守**: 猛暑日は参考のみ。`calcWorkdays` / 稼働可能日数 / 不稼働率 / 雨休率に **含めない**（既存 WBGT SPEC 踏襲）。
