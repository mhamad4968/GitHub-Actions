## 1. 目的

- 初版（当初）以降の **仕様変更・価格変更等** を版として残し、**何が変わったか** を担当者が kintone 上で把握できるようにする。
- **工事件名（工事）ごとにグループ** して一覧・操作し、担当者の日常運用を妨げないことを **最優先** とする。

## 2.1 Q-VER-01 確定（2026-06-20）— 版種別の表記

**選択**: **A案** — 変更理由が主（連番は版種別に含めない）

### 版種別（`version_type`）選択肢

| 値 | 用途 |
|----|------|
| `当初` | 初版（1工事につき1件） |
| `仕様変更` | 仕様・数量・明細の変更 |
| `価格変更` | 単価・金額・率の変更（仕様同一） |
| `仕様・価格変更` | 両方に該当 |
| `その他` | 上記に当てはまらない修正 |

### 運用ルール（案）

- 修正版作成時、担当者が上記から **1つ選択**（複製直後に必須）。
- **同一理由の版を複数持てる**（例: 仕様変更が2回）。一覧・詳細では **版種別＋作成日時（または版連番）** で区別。
- `その他` 選択時の備考は **任意**（Q-VER-06: M2）。

### UI 表示例

一覧グループ内: `仕様変更`（2026-06-20 作成） / `価格変更`（2026-08-01 作成）

### 2.2.1 R-17 確定（2026-06-21）— 一覧クリックで開く版（浜田）

## 2.3 Q-VER-03 確定（2026-06-20）— 差分の比較基準

**選択**: **C案** — 画面上で比較対象を切替

浜田コメント: **初版（当初）とどう変わってきたかも必要** → 当初版との比較を常時利用可能にする。

### 比較モード（2択）

| モード | 比較元 | 用途 |
|--------|--------|------|
| **直前版と比較** | 1つ前の版（`source_record_id` の版） | 今回の修正で何が変わったか |
| **当初版と比較** | 同一 `project_code` の `版種別=当初` | 初版からの累積変化 |

### UI（案）

- 詳細画面ヘッダ付近に **比較モード切替**（ラジオまたはタブ）: `直前版` / `当初版`
- **初期表示**: `直前版`（直近の修正内容を先に見せる）
- 切替時に **セル／行のハイライトを再計算**（①⑧⑨・明細行・詳細表を対象 — §4）
- 現在の比較モードを画面上に明示（例: 「比較対象: 仕様変更（2026-06-20）」）

### 当初版を開いている場合

- `直前版` モードは **無効または非表示**（比較元がない）
- `当初版` モードも **差分なし**（自身との比較は意味がない）→ ハイライト OFF

### 印刷

- **Q-VER-04 確定: P3** — 「差分付き印刷」／「通常印刷」を選択（下記 §2.4）

## 2.4 Q-VER-04 確定（2026-06-20）— 色付け・削除行・印刷

**色**: **B案** — 5色＋記号（金額増減は色または ▲▼）  
**削除行**: **伸縮（折りたたみ）** で隠せる  
**印刷**: **P3** — 差分付き／通常を選択

### 変更種別の色・記号

| 種別 | 背景色 | 記号・備考 |
|------|--------|------------|
| **値変更** | 薄い黄 `#fff3cd` | 数量・単価・金額・率・テキスト等の変更 |
| **行追加** | 薄い緑 `#d4edda` | 比較元にない行 |
| **行削除** | 薄い赤 `#f8d7da` | 比較元にあった行（削除として表示） |
| **金額増** | 黄ベース＋**青系アクセント** `#cfe2ff` またはセル内 **▲** | ①⑧⑨・行金額が増加（値変更と併用可） |
| **金額減** | 黄ベース＋**赤系アクセント** `#f5c2c7` またはセル内 **▼** | 金額が減少 |

- 金額セルは **値変更（黄）＋増減（▲▼ または青／赤アクセント）** を併用。
- ①⑧⑨ は優先度高 — 必ず増減が視認できること。

### 削除行の折りたたみ UI

| 項目 | 内容 |
|------|------|
| **デフォルト** | 削除行ブロックは **折りたたみ（非表示）** |
| **見出し** | 例: `削除された行（3件） ▼` — クリックで展開 |
| **展開時** | 削除行を薄赤背景で一覧表示（打ち消し線は任意・実装時に調整） |
| **再折りたたみ** | 見出しクリックで再度隠す |
| **対象** | 仕様明細・原価行・詳細表サブテーブルすべて |

通常の作業画面を邪魔しないよう、**削除行は普段は隠す**運用。

### 印刷（P3）

| モード | 内容 |
|--------|------|
| **通常印刷** | ハイライトなし（Excel 原本に近い白背景） |
| **差分付き印刷** | 画面上の比較モード・色付けを印刷に反映（削除行は **展開状態に応じる** — 折りたたみ中は印刷にも出さない） |

- 印刷ボタン付近に **印刷種別** を選択（ラジオまたはドロップダウン）。
- 差分付き印刷時は **比較対象版** をフッター等に印字（例: 「比較: 当初版」）。

### 差分表示の用語（2026-06-23 確定 — v2c 実装と一致）

| 用語 | 意味 | 画面表示 |
|------|------|----------|
| **直接編集** | ユーザーが入力・変更した行 | 薄黄 `#fff3cd` |
| **自動反映** | 再計算で連動した連携行・小計・合計（cascade） | 水色 `#cfe2ff`（金額セルに増減のみ） |
| **合計への影響** | ①⑧⑨ 等のトップレベル合計 | 増減 ▲▼ 必須 |

- **v2c 画面プレビュー** は本番稼働（BUILD `2026-06-23-jikkou-yosan-diff-structural-match` rev **123**）。
- **差分付き印刷（P3）** は **未実装** — 明日セッション着手（[`2026-06-24-jikkou-yosan-diff-print-session-memo.md`](2026-06-24-jikkou-yosan-diff-print-session-memo.md)）。

## 2.5 Q-VER-05 確定（2026-06-20）— 修正版作成の条件

| # | 論点 | 決定 |
|---|------|------|
| 1 | **誰が** | **W1** — 736 に編集権限がある全ユーザー |
| 2 | **どの版から** | **S1** — **最新版のみ**。「最新版からでないと先祖返り等の事故が起きる」ため厳守 |
| 3 | **同時編集** | **E1** — 1工事（`project_code`）につき **`status=下書き` は1件まで**（版種別を問わない） |
| 4 | **旧版ロック** | **L1** — 「修正版を作成」**押下直後**に旧版を参照のみ（複製と同時） |

### 操作ガード（実装要件）

- **最新版判定（S1）**: 同一 `project_code` の **`version_seq` 最大** のレコードのみ `[修正版を作成]` を表示（§3.1 R-01）。
- **編集中版チェック（E1）**: 同一 `project_code` に **`status=下書き` が1件でも存在** すれば `[修正版を作成]` 無効＋理由表示（**版種別を問わない**）。
- **確定前提（T1）**: 複製元は **`status=版確定` かつ `is_locked=false`**（最新の確定版）であること。`下書き` の版からは作成不可。
- **旧版（L1）**: 複製元を **`is_locked=true`** に更新。ロック済みレコードは UI `readOnly` ＋ 保存 API 拒否（§2.5.2）。

### 2.5.1 R-02 確定（2026-06-21）— E1 × 当初下書き × T1

| ルール | 内容 |
|--------|------|
| **E1** | 同一 `project_code` に `下書き` が **1件でも** あれば `[修正版を作成]` **不可** |
| **T1** | 複製元は `版確定` かつ未ロック（最新確定版）のみ |
| **当初下書き** | `version_type=当初` ＋ `下書き` ＝ 新規初版編集中 → 修正版ボタン **非表示**（T1 未充足） |

**事故防止の意図**（浜田・AIチーム合意）: 2つの下書きが並ぶと「どちらが正」か分からず、先祖返り・二重保存・連番飛びの原因になるため **常に1下書き** に限定する。

| 状態 | `[修正版を作成]` |
|------|------------------|
| 当初・下書き | 不可（T1） |
| 当初・版確定（下書きなし） | 可 |
| 修正版・下書き | 不可（E1） |
| 全版・版確定（下書きなし） | 可（最新版のみ表示 — S1） |

### 2.5.2 R-03 確定（2026-06-21）— L1 ロック範囲

| 項目 | 決定 |
|------|------|
| **トリガー** | `[修正版を作成]` **押下直後**（全量複製と同時） |
| **ロック対象** | **複製元レコードのみ** → `is_locked=true` |
| **既存ロック** | それ以前の版は **すでに `is_locked=true` なら維持**（再ロック不要） |
| **結果** | **全過去版は常に参照のみ**（D3「それ以前の版は参照のみ」と整合） |
| **新版** | 複製先は `下書き`・`is_locked=false`・編集可 |

**版を確定**（`status=版確定`）時点では **ロックしない**（R-12 で別途確定予定）。L1 ロックは **修正版作成時のみ**。

```
[修正版を作成] 押下
  → 複製元: is_locked=true（参照のみ）
  → 複製先: 下書き・編集可
  → それより古い版: 変更なし（既に locked）
```

## 2.6 Q-VER-06 確定（2026-06-20）— メタ・ステータス

| 論点 | 決定 |
|------|------|
| **T1** | 修正版作成は **親版が確定済み** のときのみ（`下書き` の版からは作成不可） |
| **M2** | **版種別必須** ＋ **修正理由メモ（任意）** — 自由記述欄あり、空でも保存可 |
| **ST2** | **`下書き` / `版確定`**（当初・修正版共通）— **確定** |

| 値 | 意味 |
|----|------|
| `下書き` | 編集中（1工事1件まで — E1） |
| `版確定` | 確定済み。**`is_locked=false` の間は編集可**（案A — §9.3）。`is_locked=true`（L1 後）は参照のみ ＋ 修正版作成の前提（T1） |

- 現行 `初版確定` は **版確定** に名称統一（表示・選択肢・既存レコードは読み取り時に互換）。
- 「初版だけ特別」は **版種別=当初** で判別する（ステータス名に載せない）。

### 修正理由メモ（新フィールド案）

- フィールド名案: `revision_note`（修正理由メモ）
- 複製直後のダイアログまたはヘッダで入力促し（未入力でも保存可）

### T1 × S1 × E1 の整合

1. 最新版が `版確定` かつ下書き版が無い → `[修正版を作成]` 有効  
2. 複製 → 新版 `下書き`、旧版即ロック  
3. 新版を `版確定` にする操作は v1 の「初版確定」ボタンを **「版を確定」** に改称

### 2.6.1 R-07 確定（2026-06-21）— `初版確定` → `版確定` 移行

| 項目 | 決定 |
|------|------|
| **正のステータス値** | **`版確定`**（当初・修正版共通 — ST2） |
| **kintone 選択肢** | `下書き` / `版確定` を正。`初版確定` は **移行期間のみ読取互換** |
| **読込** | `初版確定` → 内部 **`版確定`** に正規化 |
| **保存** | 常に **`版確定`** を書く（次回保存時に既存レコードも置換） |
| **UI ボタン** | **「版を確定」**（旧「初版確定」を改称） |
| **confirm 文言** | v2 向けに更新（「初版」限定表現を廃止） |
| **初版の特別扱い** | ステータス名ではなく **`version_type=当初`** で判別 |

## 2.7 R-16 確定（2026-06-21）— 版管理タブ（浜田）

編集画面に **第3タブ「版管理」** を追加。総括表・詳細表と **同列のタブ** とし、版の全体像を一覧で把握する。

### 2.7.1 タブ構成

| タブ | 内容 |

### 2.7.3 「版の位置」表示ルール

| 条件 | 表示 |
|------|------|
| `version_seq` = 同一 `project_code` の最大 | **最新版** |
| `is_locked=true` | **過去版（参照のみ）** 🔒 |
| `status=下書き` | **編集中** |
| 最新版かつ `status=版確定` かつ未ロック | **最新版**（修正版作成可） |

### 2.7.4 操作

| 操作 | 動作 |
|------|------|
