## 2. 外注費×材料費の品名（§10 拡張・確定）

列が費目／種別／詳細の3段では足りないため:

- 費目＝**外注費** かつ 種別＝**材料費** のとき、詳細を **左右2セル**にする（Excel「その他材料費」型に近い）。
  - **左**: 細目（塗料・鋼材・二次製品・生コンクリート･石材・ＡＳ合材・鋼製製品･ゴム製品等・その他材料 等＝材料費の種別マスタ流用）
  - **右**: 左が **塗料** または **その他材料** のときだけ **材料品名マスタ**（listOnly）
- **保存（Q1・A）**: 詳細左（細目）と詳細右（品名）は **別フィールド**。費目 (name1)・種別 (name2) は潰さない（既存 dual の name2／name3 流用では中分類が壊れるため）。
- **品名マスタが無い細目（Q2）**: 右セルは **「－」固定**（入力不可。非表示にはしない）。

## 3. 会社名（取引先）・氏名（確定）

### 3.1 表示条件

| 条件 | 会社名（行） | 氏名（行・会社名の右隣） |
|------|--------------|--------------------------|
| 費目＝**労務費** | ○ | ○ |
| 費目＝**外注労務費** | ○ | ○ |
| 費目＝**仮設機械経費** | ○ | ×（会社のみ） |
| 費目＝**外注費** かつ 種別＝**労務費** | ○ | ○ |
| 費目＝**外注費** かつ 種別＝**仮設機械経費** | ○ | ×（会社のみ・レンタル先） |
| 上記以外 | × | × |

- 会社名候補（Q6）: **協力会社∪取引先をまとめた1本**（現行 V1 どおり。協力会社のみへの絞り込みはしない）。
- 氏名: **行のみ**（ブロックに氏名列は作らない）。費目＝労務費の候補は支店社員（S1）系統を想定。外注系は当面自由入力可＋警告でも可（マスタ新設は必須にしない）。
- **列の表示（Q8・A）**: 会社名・氏名列は **必要な費目・種別のときだけ表示**（常時列にはしない）。
- **費目／種別変更時（Q3・A）**: **条件外になった項目だけクリア**（例: 外注費×労務→×仮設にしたら氏名だけ消す。会社名は残す）。条件内の値は残す。
- **帳票（Q5・A）**: 行の会社名・氏名は **帳票・印刷にも出す**。

### 3.2 ブロック取引先との使い分け

| ケース | ブロックの取引先 | 行の会社名 |
|--------|------------------|------------|
| 1社でまとめられる | 会社名を入れる | 空でよい |
| 複数社が混在（レンタル等） | **「－」** | 行ごとに入れる |

**自動・警告（確定）**

1. 行に会社名を入れた → ブロックの取引先を **自動で「－」**  
2. どの行にも会社名がなく、ブロックも空（または「－」のまま）→ **「ブロックの会社名を入れてください」系の警告**  
3. ブロックが「－」で一部行だけ会社名・他行は空 → 空行に薄い警告  
4. **警告のみ・保存は可能**（入力途中を止めない）  
5. **警告のタイミング（Q4・A）**: **保存時のみ**（リアルタイム警告はしない）

## 5. 実装メモ（GO 後）

1. 外注費: 詳細 cascade（種別→マスタ細目）。材料費時は詳細左右を **別フィールド**＋品名 listOnly。品名なし細目の右は「－」。  
2. 行フィールド: 会社名・氏名は **条件時のみ列表示**。会社の右隣が氏名。スキーマ拡張。  
3. ブロック取引先自動「－」。警告は **保存時のみ**・保存非ブロック。費目／種別変更時は条件外項目のみクリア。  
4. システム工種選択／ENSURE 時の費目**既定と▼候補**を本正本 JSON に合わせる（7件の部分集合。コード表の諸経費／予備費は混ぜない。現行値が候補外なら listOnly 祖父。**法定福利費は工種一覧に出さない**）。JSON 費目＝外注費の工種（塗装工事・足場・追加工事等）の費目▼は **材料費／労務費／仮設機械経費／現場経費／その他費用** の5件（工種名や外注費は出さない）。内訳の費目既定に原価管理 Excel の OVERRIDE（10200→塗装工事）を使わない。**種別▼は工種 JSON の types**（例: 建設機械オペレーターは軌陸車／その他建設機械オペレーターの4件のみ。労務費マスタ8件を出さない）。外注工事で選んだ費目の種別は費目マスタを流用。システム工種・費目・種別は空クリア可。  
5. 帳票に行の会社名・氏名を出す。  
6. G0 §10 本文を本仕様の拡張に合わせて追記。  

実装 GO（2026-09-05）。段階: P1 757 ADD+deploy → P2–P4 customize → P5 JSON／法定福利非表示 → P6 帳票 → P7 テスト・preflight・756 deploy。完了後は浜田が画面目視。
