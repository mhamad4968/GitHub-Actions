# PC棚卸（674）運用手順 — システム運用マニュアル追記用

> **オープン課題**: 運用チェック未。棚卸時に更新できない場合は CIO に相談。課題台帳 `docs/backlog/cio-open-issues-2026-05-17.md` の **#5a** に記載。

## 概要

新・PC台帳（674）で年次棚卸を行う。**正本はサブテーブル「棚卸履歴」**。親フィールド「最新棚卸日」は履歴の最大日を **自動反映**する（手入力しない・編集不可）。

- **年次棚卸**: 詳細の **棚卸** ボタン／一覧の **一括棚卸**（履歴追記＋最新棚卸日更新）
- **新規登録**: 種別が個人／共有／JR のとき、保存時に履歴へ **登録日1行を自動追加**（実施区分＝個別・棚卸者＝ログイン名）
- 画面で最新棚卸日だけをいじっても履歴には出ない → そのため最新棚卸日は入力不可にした（2026-08-11）

## 実施期間

環境設定マスタ（670）の次のキーで制御する。期間外は棚卸ボタンを表示しない。

| 設定キー | 例 | 説明 |
|----------|-----|------|
| `PC_INVENTORY_PERIOD_START` | `2026-05-01` | 開始日（含む） |
| `PC_INVENTORY_PERIOD_END` | `2026-05-31` | 終了日（含む） |

変更は 670 のレコード編集のみ（アプリ設定の変更は不要）。

## 対象

- ステータスが **利用中** または **保管** の PC
- **廃棄** は対象外

## 操作

### 個別棚卸（レコード詳細）

1. 実施期間中に対象レコードを開く
2. ヘッダの **棚卸** を押す
3. 棚卸者・設置場所を入力（任意: 本人確認・持ち出し）
4. **棚卸を記録** — サブテーブルに「個別」行が追加され、最新棚卸日が当日になる

### 一括棚卸（一覧）

1. 一覧の検索バーで **一括棚卸** を押す
2. **所属名** を選び **一覧取得**
3. 共通の棚卸者・設置場所を入力し、行ごとに上書き可
4. チェックした行のみ **チェック行を棚卸済にする**（実施区分は「一括」）

### 未棚卸一覧

- 一覧の **未棚卸一覧** — 最新棚卸日が空、または期間開始日より前の対象 PC を表示（参照用）
