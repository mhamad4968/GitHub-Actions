# 756 業者契約期間（工事基本情報）

> **状態**: **実装 GO**（浜田）

## 合意（チャット 2026-09-10）

施工期間（着手日／竣工日）とは別に、**業者ごとの契約期間**を工事基本情報へ載せる。

| 列 | 内容 |
|------|------|
| 会社名 | 内訳と同じ協力会社リストから **選択のみ**（手入力しない） |
| 開始 | 日付 |
| 終了 | 日付 |
| 契約日数 | **自動**（工期日数と同じ暦日・包含。片方空なら空） |
| 備考 | 任意 |

- 1 行＝1 業者。追加・削除可。**0 行でも保存可**。
- 開始が終了より後: 着手日／竣工日と同じ（警告・一時保存可・**版確定は拒否**）。日付片方空は対象外。
- 保存は SUBTABLE。会社名は **SINGLE_LINE_TEXT**（UI だけ select）。マスタに無い既存値は選択肢へ残して表示する。
- 版複製は行 id を落として複写する。契約日数は日付から再計算。

## フィールド

SUBTABLE `vendor_contract_lines`（業者契約期間）

| コード | 型 |
|------|------|
| `vendor_contract_name` | 文字列(1行) 会社名 |
| `vendor_contract_start` | 日付 |
| `vendor_contract_end` | 日付 |
| `vendor_contract_days` | 数値（表示キャッシュ） |
| `vendor_contract_note` | 文字列(1行) |
