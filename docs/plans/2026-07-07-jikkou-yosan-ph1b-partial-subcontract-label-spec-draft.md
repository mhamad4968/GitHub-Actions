## 1. 目的

詳細表・外注 **④〜⑦** ブロック内に、**計算式なしのラベル行**を追加できるようにする。

## 2. 用途（浜田 2026-07-07 確定）

| 項目 | 内容 |
|------|------|
| **意味** | 諸経費は **計算式入り**（`%` · 金額自動 · `上記金額合計の10%` 等）— テキスト行は **式なしでラベルとして使う** |
| **位置** | 諸経費と **同じ場所ではない** — 明細の間に ⋮ で **上/下追加** |
| **金額** | **加算しない**（`detailSum` に含めない） |

## 3. 制約（案）

- 対象: `subcontract_block` = repair / scaffold / paint / labor のみ
- **`SUB_CALC` 行**（諸経費/合計/注文金額等）は変更しない
- 挿入・並び替え: **`SUB_CALC` より上**のゾーン内のみ（PH1c §0.3.5a と整合）
