## §1. 背景・目的

### 1.1 背景

- **トータルネットワーク**（システム専用回線）の IP は **DHCP ではなく端末固定**。
- 拠点ごとに **割当範囲** を決め、**次に払い出す IP** を Excel の **一覧表 + IP アドレスレンジマトリックス** で管理している。
- 社外業者への情報提供にも Excel を利用。

### 1.2 目的

1. Excel 2 シート相当の操作を kintone 台帳で再現する。
2. **拠点 22 件**をマスタに登録（未接続拠点も含む — **今後のアプリ共通ルール**）。
3. **次 IP 提案**（拠点単位ボタン）で運用ミスを減らす。
4. **一覧印刷** / **マトリックス印刷**（拠点指定・全拠点）/ **Excel 出力**（社外提供用・分かりやすいレイアウト）。

### 1.3 スコープ外（v1）

| 項目 | 理由 |
|------|------|
| **社内ネットワーク管理台帳**（別系統）とのデータ連携 | 独立台帳。v1 はリンクなし |
| **PC 台帳 674 自動連携** | v1 対象外 |
| **DHCP 連携・ルータ API** | 手動台帳運用のまま |

## §2. Excel 移行元の整理（2026-06-21 機械確認）

### 2.1 シート構成

| シート | 行・列 | 役割 |
|--------|--------|------|
| **一覧表** | 12 拠点 + ヘッダ | 拠点別ネットワーク設定（GW / DNS / マスク / 割当範囲 / 住所 / 備考） |
| **IPアドレスレンジマトリックス** | 12 拠点列 × 可変行 | IP ごとの用途（ノート PC 等）。空欄 = **空き** |

### 2.2 一覧表 — 列定義

| Excel 列 | kintone（拠点マスタ） | 型 |
|----------|----------------------|-----|
| 拠点名 | `location_name` | 文字列（短名称。Excel 接頭辞 `(株)J-BISメンテナンス　` は **除去**） |
| ネットワークアドレス | `network_address` | 文字列 |
| サブネットマスク | `subnet_mask` | 文字列 |
| ゲートウェイ | `gateway` | 文字列 |
| 優先 DNS | `dns_primary` | 文字列 |
| 代替 DNS | `dns_secondary` | 文字列 |
| IP 数 | `ip_count` | 数値（Excel「IP数」列。範囲内の使用可能ホスト数） |
| IP アドレス範囲 | `ip_range_start` / `ip_range_end` | 文字列（`10.208.1.2～10.208.1.8` をパース） |
| 住所 | `address` | 文字列（複数行） |
| 備考 | `note` | 文字列（複数行） |

### 2.3 マトリックス — セル意味

| 状態 | Excel 表現 | kintone |
|------|------------|---------|
| **空き** | IP のみ（右列空） | **DB レコードなし**。画面が `ip_range_start`〜`ip_range_end` と使用中 IP から **動的計算** |
| **使用中** | IP + 用途ラベル | `record_type=ip` レコード 1 件 = 1 IP（`device_type` + 必要時 `device_type_other`） |
| **行の意味** | 拠点の割当範囲内 IP を上から列挙 | マトリックスは **ビュー**（範囲内全 IP 表示。未割当は薄色） |

**移行時件数**: Excel で **使用中**（用途ラベルあり）の IP のみ DB 登録（**約 26 件**）。空き行（141 行中の未使用分）は **移行しない**。

### 2.4 特記事項（Excel）

| 項目 | 内容 |
|------|------|
| **東北支店 / 仙台営業所** | 同一 `10.208.1.0/28`・同一 GW。**ルータ等共有**。IP 範囲は `.2–.8` と `.9–.14` で **重複なし** |

## §6. 台帳 UI（Excel 風）

### 6.1 タブ構成

| タブ | 相当 Excel | 機能 |
|------|------------|------|
| **一覧表** | 一覧表 | 拠点ネットワーク設定の表形式 CRUD。変更時 **理由必須** → 履歴サブテーブル |
| **IP マトリックス** | IPアドレスレンジマトリックス | 拠点列 × IP 行グリッド。セルクリックで割当モーダル |
| **設定** | — | **用途マスタ** CRUD（追加・無効化） |

### 6.2 一覧表

- 列: 拠点名 / NW アドレス / マスク / GW / DNS×2 / IP 数 / 範囲 / 住所 / 備考 / 操作
- **デフォルト表示**: **接続拠点のみ**（`total_network_enabled=true`）。将来 ON にした拠点は **自動表示**
- **フィルタ**: 拠点指定 / 接続拠点 / 未接続拠点 等で絞り込み（バッチ・印刷・Excel 出力にも適用可）
- **未接続拠点**（`total_network_enabled=false`）: ネットワーク列は空表示・グレー背景
- 保存: 拠点設定変更 → **変更理由モーダル**（必須）→ REST PUT

### 6.3 IP マトリックス

- 列: **`sort_no` 昇順の 22 拠点**（千葉→水戸。Excel 列順の水戸→千葉は **採用しない**）。未接続拠点は **グレーアウト** または「未接続」表示
- セル: IP アドレス + 用途（空きは IP のみ薄色 — **画面計算**、DB レコードなし）
- **次の IP を提案** ボタン（**拠点単位**）: 割当範囲内で **DB 未登録の最小 IP** を算出・ハイライト → クリックで割当モーダル → **REST POST で IP レコード作成**
- 割当モーダル: 用途（device_type）/ その他テキスト / 備考
- **割当解除**: マトリックス上の削除操作 → **REST DELETE**（DB 標準 UI は触らない運用）

### 6.4 印刷

| ボタン | 内容 | 用紙 |
|--------|------|------|
| **一覧表を印刷** | 接続拠点一覧（フィルタ: 全拠点 / 接続拠点のみ） | A4 横 |
| **マトリックスを印刷** | 拠点選択（単一 / 複数 / 全拠点） | A4 横 |

### 6.5 Excel 出力

- **2 シート相当**（シート名: `一覧表` / `IPマトリックス`）を **1 xlsx** でダウンロード
- レイアウト: Excel 完全再現ではなく **社外業者向けに分かりやすく整理**（表題・列幅・接続拠点の明示）
- ボタン: 台帳ヘッダー **Excel 出力**

## §7. バリデーション

| ルール | 内容 |
|--------|------|
| **IP unique** | 全レコードで `ip_address` 重複不可 |
| **範囲内** | IP は当該拠点の `ip_range_start`〜`ip_range_end` 内のみ |

| **拠点変更** | ネットワーク設定変更 → `change_reason` 必須 |
