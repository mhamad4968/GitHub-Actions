## 1 枚目（表面）：グラフ（大）＋月次要約 → 週次サマリー

**目的**: **今月の数字の動き**を大きい図で示し、**月次の要約**→**週次（第1週〜第4週）**の順で読めるようにする。

### タイトル（固定形式）

`{暦月}月度 ユーザー問い合わせ 日別案件サマリー`  
例: `2026年5月度 ユーザー問い合わせ 日別案件サマリー`

### ビジュアル（2 つ・大きめ優先）

1. **日別棒グラフ**  
   - **対象**: 当該暦月 **1 日〜月末**の **日ごとの問い合わせ件数**（**682** の `day_total` を **同一 `record_date` 複数行時は max で 1 日 1 値**とする。683 ダッシュと同型）。
2. **月別棒グラフ**  
   - **対象**: **過去数ヶ月**（既定 **6 暦月**、右端＝対象月）の **月ごとの件数合計**（682 REST 集計。683 の「直近6暦月」と同型にできる）。

**レイアウト**: **横並びより「大きさ」を優先**する。既定は **各グラフを用紙幅に近い横幅で縦に積む**（2 行×1 列）。収まりが厳しい場合のみ、実装側で **横並びや高さの段階的縮小**に切り替えてよい。

### テキスト（この順序を厳守）

1. **月次要約**  
   - フィールド **`user683_month`** の **先頭 N 文字**（既定 **1200 文字**、改行尊重。末尾は `…` で省略可）。
2. **週次サマリー（第1週〜第4週）**  
   - **683** の **`user683_week_1` … `user683_week_4`** を、**第1週→第4週**の順で掲載する。

### レイアウト制約（1 枚目に収める）

- **1 枚目にグラフ 2 つ（大）＋月次＋週次が収まること**。**表面の本文が裏面へ食い込まない**こと。
- **自動調整ロジック**（実装側・ReportLab 想定）:
  - **グラフ**: `Drawing` の **高さ・棒幅・ラベルフォント**を段階的に縮小（下限あり）。**ただし「大きく」方針を優先**し、テキスト側の省略・縮小を先に検討する。
  - **テキスト**: `Paragraph` の **フォントサイズを段階的に下げ**、`wrap` 後の高さが枠内に入るまで繰り返す（下限 **7pt**）。それでも超える場合は **末尾省略**（`…`）。
  - **ブロック単位**: **`KeepTogether`**（ReportLab）等で、**可能な範囲で週次ブロックの途中分割を避ける**。

## 2 枚目（裏面）：対応案件一覧（サマリー）のみ

**目的**: **暦月内の各日の対応内容を一覧で参照**する（長文の章立て月報は **本ページには載せない**）。

### タイトル（固定形式）

`{暦月}月度 ユーザー問い合わせ 対応案件一覧（サマリー）`  
例: `2026年5月度 ユーザー問い合わせ 対応案件一覧（サマリー）`

### 掲載内容

- **当該月の各日**について、**682** の **午前／午後の対応文**（`am_correspondence` / `pm_correspondence`）から **一覧向けの短いサマリー**を生成して並べる（**非 LLM**の整形でよい。先頭の非空行の重複除去・文字数上限など）。
- **件数ゼロ・無記載の日**も行を置くかどうかは実装で統一（既定: **行を置き**「特記なし」等で揃える）。

### レイアウト

- **1 ページ（裏面）に収める**ことを最優先。収まらない場合は **セル内省略**・**フォント縮小**・**行間縮小**の順で調整し、**3 ページ目以降に続けない**（提出物は **両面1枚＝PDF 2 ページまで**）。

## 実装メモ（ReportLab）

- **配色・タイポ**: スクリプト先頭の **`ACCENT` / `PANEL_BG` / `INK`** 等を **編集デザインのトークン**とする。図表は **カード枠**、一覧表は **見出し行＋薄い罫線**で読みやすくする。
- **1 枚目の図**: 既定 **`Table([[drawing_day],[drawing_month]])`**（各 `chart_panel` は **用紙幅に近い `colWidths`**）。
- **KeepTogether**: 表面の **図ブロック**と **月次／週次カード**の分割を制御し、**可能な範囲で意図しない改ページを避ける**。
- **CLI**:  
  `python scripts/user683-monthly-pdf/generate_monthly_pdf.py --year YYYY --month M --out C:\tmp\user-support-YYYY-MM.pdf`（例）  
  認証はリポ **`.env`**（`KINTONE_BASE_URL` / `KINTONE_USERNAME` / `KINTONE_PASSWORD`、Basic があれば従来スクリプトと同型）。  
  **`--demo`**: kintone 無しで **ダミーデータ**の PDF を生成（レイアウト確認用）。**`npm run user683:monthly-pdf:demo`** は **`C:\tmp\user683-monthly-demo.pdf`** へ出力（Windows 想定）。  
  **`user683-monthly-pdf-serve`**: 生成一時ファイルは **Windows 既定 `C:\tmp\_user683-monthly-serve-temp.pdf`**（環境変数 `USER683_MONTHLY_PDF_SERVE_TEMP` で変更可）。
