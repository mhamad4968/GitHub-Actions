## 1. 確定仕様（浜田 2026-07-04）

| # | 論点 | 決定 |
|---|------|------|
| Q1 | 載せ方 | 差分付き印刷の **先頭 1 ページ**「差分サマリー」 |
| Q2 | 対象 | **総括表・詳細表の両方** |
| Q3 | 粒度 | **簡潔 / 詳細** を UI で切替（既定=簡潔） |
| Q4 | 比較 | **直前版 / 当初版** 両対応（画面と同期） |
| Q5 | 変更なし | 先頭 1 ページに **「変更はありません」** ＋ 比較対象版 → 本体続行 |

### Q3 詳細

| モード | 内容 |
|--------|------|
| **簡潔** | ①⑧⑨ ＋ ブロック合計（②③等）の増減 ＋ テーブル別 **件数**（追加/変更/削除 N 行） |
| **詳細** | 画面「差分一覧」パネル相当（行ラベル列挙あり） |

### UI（2026-07-04 確定 — 依頼者UX v2）

**固定行（`.jy-sticky-top`・スクロールしても残る）**

| 要素 | 配置 |
|------|------|
| 文字サイズ（標準/大/特大） | action bar 右 |
| 印刷（通常/差分付き）＋印刷ボタン | 文字サイズの横 |
| タブ（総括表/詳細表/バージョン管理） | action bar 下 |
| 差分表示（プレビュー）バー | 青帯・ボタン風（オフ/直前版/当初版/比較対象） |
| 差分サマリー（印刷1ページ目）簡潔/詳細 | 黄帯・ボタン風（差分比較 ON 時） |
| 差分一覧（直接編集/自動反映） | **デフォルト閉**・タイトル横に茶色案内「※確認時にはクリックして開いてください」 |

**スクロールする要素**

| 要素 | 備考 |
|------|------|
| 工　事　基　本　情　報 | **デフォルト閉**・「確認したい場合はクリックして開いてください」（茶色） |
| 実　行　予　算　書 / 総　括　表（または詳細表）バナー | 工事基本情報の**下**・中央揃え |

```
[固定] 文字サイズ | 印刷 通常/差分付き [印刷]
[固定] タブ
[固定] 差分表示（青帯）— オフ / 直前版 / 当初版 / 比較対象
[固定] 差分サマリー（黄帯）— 簡潔 / 詳細   ← 差分比較 ON 時
[固定] 差分一覧（折りたたみ・デフォルト閉）
[流れる] 工事基本情報（折りたたみ・デフォルト閉）
[流れる] 実行予算書バナー
[流れる] 表本体
```

**削除行**: 各ブロック合計行の**直下**（仕様/原価は連携・小計ごと、材料は塗料/その他、外注はブロック別）。印刷も同位置。
