## §1. 背景・目的

### 1.1 背景

- 部署・支店・グループ単位の **共有メールアドレス**（`@j-bis.co.jp`）を **Excel 1 シート**で管理している。
- **46 件**（2026-06-06 時点。重複行削除後に再確認済み）。
- **個人の会社メール**は **PC 台帳 674**（595 ルックアップ）で管理済み。**共有メールだけ別管理が必要**。

### 1.2 目的

1. Excel と同等の台帳を kintone に置き、**日常操作はダッシュ**で行う。
2. 移行完了後は **kintone のみ**。会社 **ファイルサーバー**の共有メール一覧 Excel は **削除済（2026-06-06）**。
3. 登録ミス時の **修正・廃止**をダッシュから行える（Apple ID 694 で実装した運用を踏襲）。

### 1.3 PC 台帳・他案件との境界（重要）

| 対象 | 管理場所 | ドメイン・用途 |
|------|----------|----------------|
| **個人 PC の会社メール** | **674 新・PC台帳**（`mail` / `mail_acct`・595 連携） | 個人 `@j-bis.co.jp` 等 |
| **共有 PC の M365** | **674** + **671 M365管理マスタ** | `@…onmicrosoft.com`（`sjm-*` 等） |
| **本案件：部署・グループ共有メール** | **本台帳（新規）** | **`@j-bis.co.jp` の共有アドレス** |

**674 との連携は不要** — **単独台帳として運用**（浜田確認済み）。

## §4. ダッシュ UI 要件（案・Apple ID 694 踏襲）

| 機能 | 内容 |
|------|------|
| 一覧 | 部署・メール名・アドレス・アカウント・PW（コピー可）・操作 |
| フィルタ | すべて / **利用中** / **廃止** |
| 検索 | メールアドレス・部署・共有メールアドレス名・アカウント |
| **新規登録** | 手入力モーダル。`mail_address` は **`@j-bis.co.jp` 必須**。PW は **`sjb`+乱数4桁+`1M#`** 自動 |
| **接続設定** | 画面上部 **共通パネル**（SMTP 587 / POP 110 / サーバー `j-bis.co.jp`） |

| **印刷** | **v1 に実装**（Apple ID 694 同様・浜田要望） |

### 4.1 メール接続設定（Excel 外・全件共通）

浜田ヒアリング（2026-06-06）: `mail_account` / `password` は **WEB メール閲覧・Outlook 登録・POP 設定**の ID/PW を兼ねる。

| 項目 | 値（全共有メール共通） |
|------|------------------------|
| 送信（SMTP）サーバー | `j-bis.co.jp` |
| 送信ポート | **587** |
| 受信（POP）サーバー | `j-bis.co.jp` |
| 受信ポート | **110** |

**レコードに持つか？** → 全 46 件同一のため **レコード項目には載せない案を推奨**（重複 46 件は変更時に手間）。代わりに **ダッシュ上部に「接続設定（共通）」パネル**を固定表示し、コピーしやすくする。将来サーバー変更時は customize 1 箇所で済む。

代替案:

| 案 | 内容 | メリット | デメリット |
|----|------|----------|------------|
| **A（推奨）** | ダッシュ固定パネルのみ | 重複なし・変更が楽 | 印刷で 1 枚にまとめる場合はレイアウト工夫 |
| **B** | 各レコードに readonly フィールドで同一値を保持 | 行単位の印刷・エクスポートに載せやすい | 46 件同じ値の冗長・変更漏れリスク |
| **C** | Space 21 に接続マスタ 1 レコードのアプリ | kintone 上で値変更可 | アプリが増える・v1 では過剰の可能性 |

**確定**: **案 A** — ダッシュ上部に接続設定パネル（SMTP/POP 共通値）を固定表示。kintone フィールドは追加しない。

### 4.2 パスワードポリシー（新規登録時）

| 区分 | ルール |
|------|--------|
| **移行（Excel 46 件）** | Excel の `パスワード` を **そのまま**投入（現行 `jbxxxxM#` 形式を含む） |
| **新規登録（ダッシュ）** | **自動生成**: `sjb` + **乱数4桁** + `1M#` |
| **編集** | 手修正可（登録ミス・ポリシー変更後の再設定用） |

**生成例**: `sjb48291M#`（4 桁は `0000`〜`9999` の乱数。PC 台帳 674 の個人メール PW 生成と同型）

**旧ポリシー（参考）**: 現行 Excel 新規時は `jb` + 乱数4桁 + `M#` → kintone 新規からは **`sjb…1M#`** に移行。

**ダッシュ UI**:

- 新規モーダル表示時に上記を **自動セット**（再生成ボタン任意）
- 一覧 **平文表示** + クリックコピー（IT 管理者向け）
