## 1. 目的

実行予算書（App 736）の Excel 風表で、ユーザーが **列幅をドラッグ調整**し、**レコードごと**に幅を保持する。どの PC から開いても同じレコードなら同じ列幅。

## 3. データ設計

### 3.1 フィールド

| コード | 型 | ラベル | 備考 |
|--------|-----|--------|------|
| `ui_col_layout_json` | MULTI_LINE_TEXT | 列幅レイアウト | フォームに **配置しない**（customize のみ読み書き） |

### 3.2 JSON スキーマ v1

```json
{
  "v": 1,
  "spec": { "jy-col-spec": "38%", "jy-col-unit": "64px", "..." : "..." },
  "cost": { "jy-col-wcd": "68px", "..." : "..." },
  "mat":  { "jy-col-vendor": "11%", "..." : "..." },
  "sub":  { "col-kind": "120px", "col-unit": "48px", "..." : "..." },
  "print": { "..." : "..." }
}
```

| キー | 対象表 |
|------|--------|
| `spec` | 仕様明細 1 表 |
| `cost` | 原価行 1 表 |
| `mat` | 材料② + 材料③（**共有**） |
| `sub` | 外注 repair / scaffold / paint / labor（**共有**） |
| `print` | 印刷プレビュー用マッピング |

- **未設定 / 空 / パース失敗** → 現行 CSS デフォルト（`desktop.ui.js` 内 `.jy-col-*`）
- **未知の col キー** → 無視（スキーマ検証）
- **サイズ上限** → `JSON.stringify` 長が 64KB 未満であること（超過時は PUT 拒否 + トースト）

### 3.3 外注表の DOM 補足

現状、外注④〜⑦は `<table class="jy-table">` で **colgroup なし**。v1 で **colgroup + 列クラス**を追加し、他表と同型のリサイズ基盤を入れる。

## 4. 機能要件

### 4.1 操作 UX

| 項目 | 仕様 |
|------|------|
| 操作 | ヘッダ **列境界**をドラッグ（Excel 風） |
| カーソル | `col-resize`（編集可時のみ） |
| 最小幅 | 現行 CSS 既定値を **下限** |
| ドラッグ中 | リアルタイム幅変更（画面のみ） |
| ドラッグ終了 | **即時部分 PUT**（§4.2） |

### 4.2 即時保存（部分 PUT）

| 項目 | 仕様 |
|------|------|
| API | `PUT /k/v1/record.json` — **`ui_col_layout_json` のみ** + `$revision` |
| 予算データ | **触らない** · `recalcState` を走らせない |
| revision | 成功後 **`state.revision` を更新**（次の一時保存と整合） |
| 409 競合 | revision 再取得 → **最大 3 回リトライ**（1s / 2s / 4s） |
| 失敗 | トースト「列幅の保存に失敗しました」· 画面上の幅は維持 · **localStorage フォールバックなし** |
| dirty | 列幅変更は **予算の `dirty` フラグと分離** |

### 4.3 版ロック（`is_locked`）

| 状態 | ドラッグ | 表示 |
|------|----------|------|
| 編集可 | 可 | 保存 JSON → なければ CSS デフォルト |
| 版ロック | **不可**（ハンドル非表示） | 保存 JSON を画面・印刷に反映 |

### 4.4 修正版複製

- `cloneRecordBody` が全フィールドをコピーするため **`ui_col_layout_json` も自動引き継ぎ**（追加実装最小）
- 新規ドラフト（空レコード）は JSON 空 = デフォルト幅

### 4.5 列幅リセット

| 項目 | 仕様 |
|------|------|
| 配置 | ツールバー（フォント切替付近） |
| 確認 | 「列幅を初期値に戻しますか？」 |
| 動作 | JSON クリア → デフォルト CSS 適用 → **即時 PUT** |
| 版ロック | ボタン非表示または disabled |

### 4.6 印刷プレビュー

- 保存 JSON から **動的 `<style>`** を生成し `.jy-pr-spec` / `.jy-pr-cost` / `.jy-pr-mat` / `.jy-pr-sub` に幅を適用
- 画面表と **同一比率**（mm 完全一致は v1 非目標）

### 4.7 外注ブロック削除後の JSON

- 無効ブロックの `sub` 内キーは **削除しなくてよい**（孤児キー許容 · 再追加時に復元可能）
