## 4. 集計タブ

### 4.1 開閉

- 開閉の単位は **システム工種**（＋／−）。  
- **既定で開く**: 配下に **円の会社実績** があるシステム工種（後述の「実績あり」）。  
- **既定で閉じる**: 実績が無いもの。実績予想だけの月では自動では開かない。現予算・実績予想を入れるときは自分で開く。  
- 閉じたシステム工種行: 配下工種の **現予算・採用・残** の合計。昼夜工種があれば **回数の予定・採用・残** も足して出す。  
- この行は表示だけ。

### 4.2 円の欄（工種行）

| 欄 | 入力 | 残・率 |
|----|------|--------|
| 実行予算当初（設計当初） | **手入力しない**。初版確定後に自動コピーして **ロック** | 残の母数にしない |
| **現予算** | **作成者が手入力**。内訳・統括から持ってこない | **残＝現予算−採用合計**、**率＝採用合計÷現予算**（現予算0は率空または出さない。実装時に0除算しない） |
| 月次 | 実績と実績予想を別保持。計算は **採用** | 下表 |

率は工種の率を平均しない。合計行も **合計の採用 ÷ 合計の現予算**。

### 4.3 実績予想と採用（円）

Excel 青文字の代替。色をデータにしない。

- **実績予想**: 集計の工種×月。手入力。会社では分けない。  
- **実績**: 詳細入力の会社×月から自動合計。集計では金額を直さない。  
- **採用（計算用）**:  
  - その工種のその月に **実績が無ければ** 実績予想  
  - **実績があれば** 実績（実績予想は残す。上書きしない。残の計算には使わない）  
- **「実績がある」**: その工種のその月に、いずれかの会社の月次金額が **空でない**。**0 は入力あり**。全社がその月空なら未入力（実績予想のまま）。会社行が他月にだけある場合、空の月は切替しない。  
- 円の切替と回数の切替は **独立**。

### 4.4 回数（昼夜付き工種だけ）

原価の円合計には **入れない**。工種「回数」は作らない。

対象: マスタ工種名に昼間／夜間（または同義の昼／夜）が付いているもの。塗料・レンタル等は回数欄なし。

| 欄 | 入力 |
|----|------|
| 予定回数 | 集計の工種行に **工事通しで1つ**（工期＝通常は工事年度）。月ごとの予定は置かない |
| 回数の実績予想 | 集計の工種×月。手入力。会社では分けない |
| 実績回数 | **集計の月次に直接**。会社・氏名は付けない。オーダーもまだ無い |
| 残回数 | 予定回数 − 採用回数の年合計 |

回数の採用: その月の **実績回数に入力があれば**（0含む）実績回数。空なら回数の実績予想。  
円の会社入力が付いても、回数は自動では切り替わらない。逆も同じ。

### 4.5 合計

- 施工小計（円の採用・当初・現予算・残・率）  
- 保安小計（同上）  
- いちばん下に **全体の円合計**（回数は足さない）

### 4.6 初版確定（集計タブに1つ）

- 工事に **1回**。工種ごとに確定日は分けない。入力タブには置かない。  
- 押すと確認: **「初版として固定しますか？」**  
  - はい → その時点で **空でない現予算** を当初へコピーしてロック。ボタンは押せなくする（初版確定済と分かる）。  
  - いいえ → 何もしない。  
- 確定前: 現予算は入れられる。当初は空。  
- 確定後に現予算を入れた工種: 当初は **空のまま（初版に含めない）**。確定のやり直しはしない。現予算・実績・残はその工種でも普通に動く。  
- 現予算を先に入れても、確定するまでは当初にしない。

## 5. 詳細入力（施工／保安）

円の実績だけ。回数はここへ入れない。

### 5.1 ブロック

- 使う **システム工種ブロックを追加／削除**。空の工種を全部は並べない。  
- 候補は **開いているタブの区分だけ**（施工タブに保安の工種を出さない）。  
- 同じシステム工種は **二重に足さない**。  
- ブロック追加直後は空。最初の会社行で、そのシステムの **子工種** を選ぶ。

### 5.2 会社行の足し方

- 相手は **会社名だけ**（氏名なし）。  
- 会社名は **協力会社リストから選択のみ（listOnly）**。無い会社は先にマスタへ足す。自由記述しない。リストは既存の会社マスタ1本（原価管理専用名簿は作らない）。  
- **その工種がブロックにまだ無い** → 工種を追加し、その下に会社行を足す。  
- **すでに同じ工種がある** → 会社行はその工種の下に足す（工種を二重にしない）。  
- 並びは **マスタの工種順**。

会社行の中身: 会社名 ＋ 4月〜3月の金額。空月可。

### 5.3 削除

| 対象 | 動作 |
|------|------|
| 会社の詳細行 | 行単位で消せる |
| システム工種ブロック（中に詳細行が無い） | そのまま消す（空枠の掃除） |
| システム工種ブロック（詳細行がある） | **「詳細行がありますが消しますか？」** → はいなら会社行ごと消す。いいえなら残す |

### 5.4 集計への流れ

会社×月の合計が、その工種のその月の **実績** になる。集計側で実績金額を手で直さない。

## 7. 計算（実装が守る式）

工種行（円）:

- `実績[月] = Σ 会社行のその月`（会社行が無い／その月が空なら実績なし）  
- `採用[月] = 実績があるなら実績[月]、なければ実績予想[月]`（両方空なら 0）  
- `採用合計 = Σ 採用[4..3]`  
- `残 = 現予算 − 採用合計`  
- `率 = 採用合計 / 現予算`（現予算が空または0なら率を無理に出さない）

昼夜工種（回数）:

- `採用回数[月] = 実績回数に入力があればそれ、なければ回数の実績予想`  
- `残回数 = 予定回数 − Σ 採用回数[4..3]`

システム工種の閉じ行・区分小計・全体合計: 配下の **工種行を足す**（回数は円合計に入れない）。

案 Excel の合計残 `…-AM93+AP93`（3月が足し算）は **バグ**。持ち込まない。各行どおり 3月も引く。

## 13. 夜セッション（2026-09-12 昼クローズ時点）

**この節が次の1手の正本。** 昼はここまで。実装しない。実装GOは、夜の決定が終わったあとに浜田が出す。

進め方: **1件ずつ**検討して決める。決まったら本ファイルへ追記。まとめ決めしない。

### 13.1 夜の順（第1回の穴 → 手の動き → 旧データ）

1. その月の会社入力を空に戻したら、採用は実績予想に戻すか  
2. 実績が入ったあと、実績予想を直せるか（ロックするか）  
3. 同じ工種に同じ会社を2行、足せるか  
4. 初版確定と、既存の版確定／「予実を保存」は別物か（版複製で当初ロックがコピーされるか）
