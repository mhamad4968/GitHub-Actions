## §1. P2-1 — 集計セル絞込

| 操作 | 結果 |
|------|------|
| 数値セル（部署×ステータス、n≥0） | `filterDept`＋`filterStatus` をその値に。`いまの条件` に `集計=部署×ステータス` |
| 部署名セル（合計行以外） | `filterDept` のみ。ステータスチップは「すべて」。条件に `集計=部署` |
| 合計行・合計列 | **クリック不可**（cursor 通常・ハンドラなし） |
| 廃棄セル | `lifecycleFilter=retired` に切替＋ステータス=廃棄 |
| 非廃棄セル（有効表示中） | `lifecycleFilter=active` を維持。廃棄チップ選択時の既存 sync は維持 |
| 0 件セル | クリック可 → 該当 0 台＋条件表示 |

絞込後は既存の検索・部署 select・ステータスチップ・有効/廃止も併用可（後勝ちで state 更新）。  
一覧印刷・Excel は `filteredRecords()` に追従。

### A — 解除

- 条件バーに **「集計絞込を外す」**（集計由来時のみ表示）  
- **クリア** でも集計由来フラグ＋部署／ステータスを初期化（有効表示へ）  
- 外すと `集計=…` 文言消失。部署・ステータスは「すべて」に戻す（検索文言はクリア時のみ全消し）

state 例: `summaryFilterActive` boolean ＋ 既存 filterDept/filterStatus。

## §2. B — コピー

一覧の **端末名** / **Apple ID** セルに小さな「コピー」操作（ボタン or クリック可能表示）。  
`navigator.clipboard.writeText`（失敗時は一時選択＋`execCommand('copy')` フォールバック）。  
成功時は短いトースト／ボタン文言「コピー済」（1〜2 秒）。

## §3. V-1〜V-7

| ID | 仕様 |
|----|------|
| **V-1** | ステータスチップ＋一覧ステータスセルに色クラス（待機/貸出中/確認中/故障/廃棄） |
| **V-2** | 部署が前行と変わった行に区切りクラス（上ボーダー or 薄い帯） |
| **V-3** | 絞込を 2 段: ①有効/廃止＋ステータスチップ ②検索＋部署＋クリア |
| **V-4** | 集計のクリック可能セルに `jip-summary-clickable`（hover・cursor）。合計は非対象 |
| **V-5** | メタの「全 N 台」→ **「登録 N 台」**（総件数）。該当件数は条件バーのみ |
| **V-6** | 故障・確認中の行に左ボーダー強調 |
| **V-7** | 列幅目安: 端末名・Apple ID をやや広め（`min-width` / `col` クラス） |
