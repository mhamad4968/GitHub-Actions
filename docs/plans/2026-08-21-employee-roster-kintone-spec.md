## 4. Space 48 新アプリ「社員名簿」

### 4.1 アプリ概要

| 項目 | 内容 |
|------|------|
| 名前 | 社員名簿 |
| Space | **48** |
| 性質 | 595 の **投影＋行展開**（編集の正本は 595。名簿は同期結果＋出力 UI） |
| 対象フィルタ | `employment_category` ∈ {社員, 準社員} のみ同期対象 |

### 4.2 フィールド案（名簿アプリ）

| code | 型 | label | 由来 |
|------|-----|-------|------|
| `source_595_id` | NUMBER | 595レコード番号 | 同期キー |
| `emp_id_ref` | SINGLE_LINE_TEXT | 社員管理番号(参照) | 595 `emp_id` **読取コピーのみ** |
| `employee_no` | SINGLE_LINE_TEXT | 社員番号 | 595 同期 |
| `user_name` | SINGLE_LINE_TEXT | 社員名 | 595 |
| `mail` | SINGLE_LINE_TEXT | メールアドレス | 595 |
| `employment_category` | DROP_DOWN | 雇用区分 | 595 |
| `row_role` | DROP_DOWN | 行区分 | **本務** / **兼務** |
| `dept_name` | SINGLE_LINE_TEXT | 部署名 | 本務=595 / 兼務=ST |
| `group_name` | SINGLE_LINE_TEXT | 事業所（拠点） | 同上。680 グループ名相当 |
| `job_title` | SINGLE_LINE_TEXT | 役職 | 本務/兼務 |
| `is_primary` | CHECK_BOX または DROP_DOWN | 本務フラグ | 集計フィルタ用 |
| `match_status` | DROP_DOWN | 突合状態 | 一致 / 曖昧 / 人手確定 / 未突合 |

> 1 人・兼務 N 件 → 名簿は **1+N 行**（本務 1＋兼務 N）。

### 4.3 一覧・出力

- フィルタ: 所属（`dept_name`）**複数選択**、拠点（`group_name`）**複数選択**
- 出力: Excel エクスポート／印刷（機密扱い 1 行注記を既存台帳 UX に合わせる）
- 集計ビュー: **人ベース**・所属別・拠点別は **`row_role=本務`（または `is_primary`）のみ**

## 5. 同期・移行

### 5.1 初期突合

1. Excel「社員一覧」を読む（列: 事業所／部署名／役職／社員番号／社員名／メール）
2. キー候補: **氏名（`user_name`）＋所属（部署名）**
3. 一意ヒット → `employee_no`・雇用区分・兼務行・メールを 595 に反映（`emp_id` は触らない）
4. 0 件／複数件 → **曖昧リスト**を出し人手確定（`match_status`）
5. 確定ペアは **マッピング永続化**（氏名＋所属 → `employee_no` / 595 `$id`）。以降の定期同期はこれを優先（DeepSeek 盲点③）

### 5.2 595 → 名簿同期

1. 595 で `employment_category` ∈ {社員, 準社員} かつ在籍系を抽出
2. 本務行 1 件＋ `concurrent_posts` 各行を名簿へ upsert（キー: `source_595_id` + `row_role` + 兼務行インデックス）
3. 所属コード／名称の型差がある場合は **680 マスタで名称解決**してから名簿へ書く（DeepSeek 盲点①）
4. メールは 595 `mail` を名簿へ上書き同期

### 5.3 兼務展開ルール（DeepSeek 盲点②）

- 595 **1 レコード** → 名簿 **複数行**になり得る
- 集計・人数カウントは **本務行のみ**（兼務行は一覧・印刷には出す）

### 5.4 Excel 削除

- 条件: 移行完了＋浜田目視 OK＋曖昧リスト解消（または明示スキップ合意）
- それまで `C:\tmp\社員名簿（正社員・準社員）\社員一覧表.xlsx` は **削除禁止**
