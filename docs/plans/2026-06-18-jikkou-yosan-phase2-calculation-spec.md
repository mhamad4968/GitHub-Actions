```
仕様明細 ──SUM──► contract_total_1 …①
                        │
原価行(detail+link) ──SUM──► cost_total_8 …⑧ ──► profit_9 = ①−⑧ …⑨

詳細表 ──► 材料②③ / 外注④⑤⑥⑦ ──► 原価行 link へ反映
```

| # | ルール |

| R1 | **小計行・計算行は ⑧ に含めない**（detail + link のみ合算） |
| R2 | 数量×単価 → 金額（材料・外注明細） |
| R3 | 詳細表集計 → 原価行 `cost_amount` へ **自動反映**（link 行） |
| R4 | 率列 = `cost_amount / contract_total_1` |
| R5 | 外注 **注文金額** = 有効数字3桁以下 **切捨** |

## 4. 外注ブロック計算（④⑤⑥⑦）

### 4.1 明細合計（諸経費・保険除く）

```
detail_sum = SUM(sub_amount WHERE sub_row_kind=detail)
```

### 4.2 諸経費（10%）

```
overhead = detail_sum × 0.10
```

サンプル⑥: 47,245,000 × 10% = **4,724,500** ✓

### 4.3 各種保険料（任意保険）

```
IF contract_total_1 >= 10,000,000:
  insurance_deduct = contract_total_1 × 0.003   # 減額
ELSE:
  insurance_deduct = 0
```

サンプル: 164,697,500 ≥ 1千万 → 減額 **494,092.5**（本案件は Excel 上 0 表示 — **OPEN-CALC-01** 下記）

### 4.4 合計

```
block_total = detail_sum + overhead − insurance_deduct
```

サンプル⑥: 47,245,000 + 4,724,500 = **51,969,500** ✓

### 4.5 法定福利費 — **重要（サンプル検算で確定）**

**誤**: `block_total × 15.33%` → 7,966,924（Excel と不一致）

**正（サンプル⑥）**:

```
legal_welfare = (労務費昼 + 労務費夜) × 0.1533
              = (11,375,000 + 28,080,000) × 0.1533
              = **6,048,451.5** ✓
```

根拠: 詳細表 R68 計算基準「15.33%（昼：@2,658　夜：@3,800）」— **労務費行のみ** が対象。

| block | 法定福利の対象行 |
|-------|-----------------|
| ④⑤⑥ | `労務費（昼）` + `労務費（夜）` |
| ⑦ | 労務ブロックは **合計行のみ**（福利・注文金額なし） |

### 4.6 注文金額（④⑤⑥）

```
raw_order = block_total + legal_welfare
order_amount = truncate_sig3(raw_order)   # 有効数字3桁以下切捨
```

| 段階 | ⑥ 塗装 |
|------|--------|
| raw_order | 51,969,500 + 6,048,451.5 = **58,017,951.5** |
| 切捨後 | **58,000,000** ✓ |

**切捨関数 `truncate_sig3`**

```javascript
function truncateSig3(x) {
  if (x === 0) return 0;
  const exp = Math.floor(Math.log10(Math.abs(x)));
  const factor = Math.pow(10, exp - 2);
  return Math.floor(x / factor) * factor;
}
```
