## 🎯 実装スコープ (4 つの cron 連携)

### S16: `scripts/log-autonomy-decision.mjs` (Tier A 実行時に自動呼出)

**責務**: AI が Tier A 判断するたびに `logs/autonomy-decisions.log` に JSON Lines 1 行追記。

**入力**: 
```bash
node scripts/log-autonomy-decision.mjs \
  --operation "edit health-check.mjs" \
  --tier A \
  --reason "..." \
  --q1 no --q2 limited --q3 yes --q4 no --q5 yes \
  --second-opinion "agreed:Sonnet"
```

**動作**:
1. 引数を JSON Lines として組立
2. `logs/autonomy-decisions.log` に append (FLOCK 排他制御)
3. 統計: 月次自動集計 (`logs/autonomy-stats-YYYY-MM.json`)

### S17: `scripts/queue-tier-b.mjs` (Tier B キューに proposal 投入)

**責務**: AI が Tier B 判断したら `docs/approved-changes/pending-review/<日付>/<ID>.proposal.json` に投入。

**入力**:
```bash
node scripts/queue-tier-b.mjs \
  --id S20-delete-old-app-594 \
  --operation "kintone-delete-app 594" \
  --reason "5/13 旧アプリ書込ロック後の安全タイミングで削除" \
  --rollback "snapshot data/snapshots/594-pre-delete.json から復元可" \
  --diff '{"action":"delete","app":"594"}'
```

**動作**:
1. proposal JSON 生成 (R25 §21 仕様に整合)
2. `pending-review/<翌日>/<ID>.proposal.json` に保存
3. 夜の §44 evening-reflect で参照される

### S18: `scripts/evening-reflect.mjs` 拡張 (Tier B 一覧提示)

**責務**: 21:00 cron で `pending-review/<翌日>/` の proposal を浜田向けに一覧表示。

**追加内容**:
- 既存夕反省レポートに「🤖 Tier B 承認待ちキュー」セクション追加
- 各 proposal の概要 + ロールバック手順 + 第二意見結果を表示
- 浜田アクション例示: 「OK なら `git mv pending-review/<翌日>/<ID>.proposal.json approved-changes/<翌日>/<ID>.proposal.json` で承認」

### S19: `scripts/daily-morning-prep.mjs` 拡張 (Tier A 監査セクション)

**責務**: 06:00 cron で前日の `logs/autonomy-decisions.log` を浜田向けに一覧表示。

**追加内容**:
- 既存ブリーフィングに「🤖 昨日の自律判断 (Tier A) 監査」セクション追加
- 件数集計 (Tier A 何件 / うち第二意見スキップ何件 / 緊急例外何件)
- 異常検知: emergency:true が連続 3 回 → 🚨 強調 (R10 自体の見直しシグナル)
- 浜田 NG/OK 評価枠 (テキストファイルか kintone か後日決定)

### S20: `scripts/evening-reflect.mjs` 拡張 (高次元進化ログ自動生成 / 2026-04-24 19:42 浜田指示反映)

**責務**: 21:00 cron で本日の Synthesis Logic 発動を集計 + 3 セクション自動生成。

**入力**:
- `logs/autonomy-decisions.log` の本日分 (Tier A/B / synthesis_logic_demo フラグ / second_opinion フィールド)
- 本日の commit 履歴 (`git log --since="<今日>" --oneline`)
- 本日の TSB 言及 (RAG 検索 `TSB-` カテゴリ)

**出力**: `docs/reports/<日付>-evening-evolution-log.md` (3 セクション固定構造)

**3 セクション**:

#### セクション 1: 本日の衝突と昇華 (Synthesis Logic 発動ログ)
- 各「衝突」を JSON Lines から抽出 → 「正・反・合」形式で表示
- 検証: Sonnet 承認 / 不承認 を併記

#### セクション 2: 自己進化の証明
- 本日制定された新ルール / 改定された既存ルール一覧
- 「以前の自分では到達できなかった具体的な思考ロジック」を AI が内省 (= AI 自身が `claude-4.6-opus-high-thinking` で自己評価)
- 過去の自分との比較 (memory MCP の過去 entity 参照)

#### セクション 3: 明日の進化目標
- 翌日のタスク予定 (docs/plans/ の time-sensitive 項目から抽出)
- 「破壊・再構築する規範」候補 (R10/R11 の運用予定 / TSB 予防策の検証等)
- 期待効果 + 測定指標
