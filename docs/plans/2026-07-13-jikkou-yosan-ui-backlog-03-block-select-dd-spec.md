## 1. 目的

詳細表で行・ブロックを追加するとき、**スクロール不要**で **常に見える固定メニュー**から追加先を選び操作する。

---

## 2. スコープ

### 2.1 対象（IN）

| 領域 | 内容 |
|------|------|
| 詳細表タブ | 固定メニュー **2 セット**（§4） |
| 明細追加 | ②塗料 · ③その他 · ④修繕 · ⑤足場 · ⑥塗装 · ⑦労務 — 各ブロック **末尾に明細1行**（既存 insert ロジック流用） |
| ブロック追加 | PH1d 準拠 — **未追加**の外注④〜⑦のみ DD に表示 · `insertSubcontractBlockRows` 流用 |
| 追加後 | スクロール＋**追加専用フラッシュ**（**Q0-9 案 B** · `jy-add-flash` · 水色）· ジャンプ連携の `jy-ref-highlight` は触らない |
| 削除対象 UI | 見出し `data-mat-add` / `data-sub-add` ボタン · `jy-sub-block-toolbar` |

### 2.2 対象外（OUT）

| 項目 | 理由 |
|------|------|
| 総括表タブ | 詳細表のみ（浜田 2026-07-13） |
| スマホ専用 UI | **想定なし（Q0-11）** — 縦積み等の専用対応はしない |
| 各行 ⋮（上／下に1行） | 編集可時は残置（Q0-4）· 参照のみは非表示（Q0-10） |
| 行並び替え | PH1c 済 |
| 列幅 | UI-BACKLOG-02 済 |
| kintone フィールド追加 | 不要（既存 `mat_lines` / `subcontract_lines`） |
| 仕様明細・原価行の追加 | 詳細表バックログの範囲外 |

## 3. 固定メニュー UI

### 3.1 表示条件

| 条件 | 表示 |
|------|------|
| `activeTab === 'detail'` かつ編集可 | **表示** |
| `readOnly` または `state.is_locked` | **非表示** |
| 総括表・バージョン管理タブ | **非表示** |

### 3.2 レイアウト（案）

**固定** = 詳細表をスクロールしても画面上部に残る（既存 **`jy-sticky-top`** 内 · Q0-12）。

版メタ行（`版N / 版種別 / ステータス`）の **直下に専用1行**:

```
[ sticky 内・版メタ行 ]
[ 明細を追加: [DD▼] [追加] ]  [ 外注ブロック: [DD▼] [ブロック追加] ]   ← 同じ sticky の次の行
```

- sticky から外して表の途中に置く、という意味ではない
- **① 明細 DD** — **動的**: `mat:塗料` / `mat:その他` は常時 · 外注④〜⑦は **`isSubBlockActive` のブロックだけ**（**Q0-7** · 未追加は出さない · ブロック追加後に出現）
- **② ブロック DD** — `SUB_BLOCKS` のうち `!isSubBlockActive` のみ · 0 件時は DD 無効＋「追加可能なブロックなし」

### 3.3 ラベル（DD 表示名）

| 値 | 表示 |
|----|------|
| `mat:塗料` | ② 材料（塗料） |
| `mat:その他` | ③ 材料（その他） |
| `repair` | ④ 修繕工事 |
| `scaffold` | ⑤ 足場工事 |
| `paint` | ⑥ 塗装工事 |
| `labor` | ⑦ 労務費 |

## 4. 動作

| 操作 | 既存関数（想定） | 追加後 |
|------|------------------|--------|
| 明細「追加」 | `insertMatRowAtGroupEnd` / `insertSubDetailRow` | 該当行へスクロール＋**`jy-add-flash`** |
| ブロック「ブロック追加」 | `insertSubcontractBlockRows`（`addSubBlock`） | ブロック先頭へスクロール＋**`jy-add-flash`** · DD は render で再計算 |
- **再計算** · **dirty** · **総括連携行** — 既存 PH1d / 材料ロジックどおり（変更なし）
- **選択肢の同期**: DD①②は **毎 render で state から再計算**（ブロック **追加・削除**の両方で自然更新 · Q0-8 の「追加直後」はこの一例）
- **明細「追加」後**も必要なら DD① の選択状態を維持（選択肢自体は Q0-7 どおり）
- **連打対策（Q0-13）**: 「追加」「ブロック追加」押下〜処理完了（render 完了）まで当該ボタンを **disabled**
- 詳細表タブヒント文（「見出しの末尾に追加…」）— **固定メニュー説明に更新**
