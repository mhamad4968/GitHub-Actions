## 1. 目的

詳細表で行・ブロックを追加するとき、**スクロール不要**で **常に見える固定メニュー**から追加先を選び操作する。

## 2. スコープ

### 2.1 対象（IN）

| 領域 | 内容 |
|------|------|

## 3. 固定メニュー UI

### 3.1 表示条件

| 条件 | 表示 |
|------|------|
| `activeTab === 'detail'` かつ編集可 | **表示** |
| `readOnly` または `state.is_locked` | **非表示** |
| 総括表・バージョン管理タブ | **非表示** |

### 3.2 レイアウト（案）

`renderFormActionBar()` 内 · 版メタ（`版N / 版種別 / ステータス`）の **右隣** または **直下**（詳細表タブ時のみ）:

```
[ 明細を追加: [DD▼] [追加] ]  [ 外注ブロック: [DD▼] [ブロック追加] ]
```

- **① 明細 DD** — 常に 6 項目（ブロック未追加の外注を選んでも **エラー表示**し追加しない · または DD から除外 — **7/14 レビューで確定**）
- **② ブロック DD** — `SUB_BLOCKS` のうち `!isSubBlockActive` のみ · 0 件時は DD 無効＋「追加可能なブロックなし」

### 3.3 ラベル（DD 表示名）

| 値 | 表示 |
|----|------|
| `mat:塗料` | ② 材料（塗料） |
| `mat:その他` | ③ 材料（その他） |
| `repair` | ④ 修繕工事 |
| `scaffold` | ⑤ 足場工事 |
| `paint` | ⑥ 塗装工事 |
| `labor` | ⑦ 労務費 |

## 4. 動作

| 操作 | 既存関数（想定） | 追加後 |
|------|------------------|--------|
| 明細「追加」 | `insertMatRowAtGroupEnd` / `insertSubDetailRow` | 該当行へスクロール＋ハイライト |
| ブロック「ブロック追加」 | `insertSubcontractBlockRows` | ブロック先頭行へスクロール＋ハイライト |

- **再計算** · **dirty** · **総括連携行** — 既存 PH1d / 材料ロジックどおり（変更なし）
- 詳細表タブヒント文（「見出しの末尾に追加…」）— **固定メニュー説明に更新**
