## 2. AIチーム提案（Recommended）

### 2.1 行種別 `cost_row_kind`

| 値 | 画面表示 | 入力 | 説明 |
|----|---------|------|------|
| `group_header` | 工種名のみ（太字） | 作成者 | 例: 「材料費」「レンタル」— Excel 1行目相当 |
| `detail` | 通常行 | 作成者 | 数量・単価・金額を入力 |
| `subtotal` | 工種列に **「計」** | **自動生成＋読取専用** | 同一グループの detail を合算 |
| `link` | 詳細表連携行 | 半自動 | `detail_marker` ②〜⑦ — 金額は詳細表から反映 |

**⑧⑨ は行種別に含めない** — 表の **固定フッター**（レコード本体フィールド `cost_total_8` / `profit_9`）として Excel R64–65 相当を再現。

### 2.2 グループキー `cost_group_key`

- 英語内部キー（例: `material`, `rental`, `line_close`, `manager_wage`）
- 画面では **グループ見出し行** の工種名を表示
- **小計行**は同じ `cost_group_key` を持つ `detail` / `link` 行の `cost_amount` を合算

### 2.3 Excel 風 UI ルール

| ルール | 内容 |
|--------|------|
| 見た目 | 小計行: **太字**・背景薄グレー・金額列のみ表示（数量/単価は空） |
| 操作 | 行末に **「小計行を挿入」** — 直前の group 内 detail を合算して 1 行追加 |
| 自動提案 | グループ内 detail を編集したら、小計行が無ければ **「小計を追加しますか？」** |
| ロック | 小計行の金額セルは **編集不可**（detail 変更で再計算） |
| 削除 | 小計行削除 → detail は残る。detail 全削除 → 小計行も警告付き削除 |

### 2.4 ⑧⑨ フッター（表外）

```
┌─ 原価行（スクロール） ─────────────────┐
│ 材料費 / 塗料 …                        │
│ 計 …                                   │
│ レンタル / 足場材 …                    │
│ 計 …                                   │
└────────────────────────────────────────┘
  工事原価額（⑧）  83,633,440   ← 固定フッター（自動）
  粗利額（⑨）      81,064,060   ← 固定フッター（自動）
  粗利率           49.2%
```

- 688 の Excel 表 + 下段メタと同型
- **契約合計（①）** も総括表タブ上部に固定表示

### 2.5 集計ルール（Phase 2 検算と共有）

| 集計 | 式 |
|------|-----|
| 小計行 | `SUM(cost_amount WHERE group_key=X AND row_kind IN (detail, link))` |
| ⑧ 工事原価 | **`SUM(cost_amount WHERE row_kind IN (detail, link))`** — **小計行は二重計上しない** |
| ⑨ 粗利 | `contract_total_1 − cost_total_8` |

※ レンタル等、Excel では **親行＋子行＋計** がある場合 — **親行は `group_header` のみ（金額0）**、金額は **子 detail 行のみ** に持たせる。
