## §1. 背景・目的

### 1.1 背景

- 社内各拠点の **Wi-Fi 接続情報（SSID・パスワード）** を **Excel 1 シート**で管理している。
- 拠点の **システム担当者**が接続情報を確認し、**会議室等への掲示用印刷**を行う必要がある。
- Wi-Fi 機器の入替・SSID 追加・変更は **当部署（kintone admin）** が更新する。

### 1.2 目的

1. Excel と同等の情報を kintone に置き、**日常の確認・印刷は台帳 ver.1** で行う。
2. **全拠点一覧**を社内ユーザーが参照できる（社内公開・パスワードも隠さない）。
3. **拠点単位の A4 印刷**（必要なら **Wi-Fi 接続用 QR** 付き）で会議室掲示に使える。
4. 移行・目視 OK 後は **Excel 表を削除**し、kintone のみ正本とする。

### 1.3 スコープ外（v1）

| 項目 | 理由 |
|------|------|
| **来訪者向けゲスト Wi-Fi の自動発行** | 本台帳は社内拠点 SSID の台帳。来訪者運用は別 |
| **PC 台帳 674 / M365 671 との自動連携** | v1 独立台帳 |
| **RADIUS / 802.1X 等の詳細設定** | SSID・パスワードの台帳化のみ |
| **有償 kintone プラグイン** | 使用しない |

## §5. データアプリ — フィールド定義（確定）

**1 拠点 = 1 レコード**。サブテーブルは **使わない**（SSID 最大 2 は固定フィールド）。

| # | ラベル（画面） | コード | 型 | 必須 | 備考 |
|---|----------------|--------|-----|------|------|
| 1 | 並び順 | `sort_no` | 数値 | ○ | §10 の順。一覧デフォルト `order by sort_no asc` |
| 2 | 拠点名 | `location_name` | 文字列(1行) | ○ | **unique** 推奨 |
| 3 | SSID① | `ssid_1` | 文字列(1行) | ○ | 設備なし拠点は **`設備なし`** |
| 4 | SSIDパスワード① | `password_1` | 文字列(1行) | — | 設備なしは **`設備なし`**。それ以外は平文 |
| 5 | SSID② | `ssid_2` | 文字列(1行) | — | 未使用は **空** |
| 6 | SSIDパスワード② | `password_2` | 文字列(1行) | — | 未使用は **空** |
| 7 | 登録日 | `registered_date` | 日付 | — | 初回投入日。移行時は投入日 or Excel 基準日 |
| 8 | 更新日 | `updated_date` | 日付 | — | **REST 保存のたびにダッシュ側で当日（JST）をセット** |
| 9 | 備考 | `note` | 文字列(複数行) | — | 帯域メモ・注意等 |

**kintone 標準の作成日時・更新日時**も参照可だが、画面・印刷では上記 **`registered_date` / `updated_date`** を表示する（694 型）。

**DB customize（693/714 型）**:

- レコード追加・編集・削除 UI を **ブロック**（`event.error` または保存前ガード）。
- 閲覧のみ許可。

### 8.5 印刷デザイン — 会議室掲示（浜田追加 2026-06-14・確定）

**目的**: 広い会議室でも **離れた席から読める**こと。来客時に見られても **体裁が整った社内掲示**に見えること（「手書き Excel 貼り付け」感・業務システム画面の丸写しは **NG**）。

| 項目 | 要件 |
|------|------|
| 用紙 | **A4 縦**（§8.1 どおり） |
| 文字サイズ | **一覧画面より大きめ**。694 印刷（値 12.5pt 級）より **1段階以上** |
| 拠点名 | **22〜28pt 相当**（ページ内で最も目立つ） |
| ラベル（SSID① 等） | **14〜16pt**・太字 |
| SSID / パスワード **値** | **18〜22pt**・太字・`word-break` 対応（長い SSID も折返し） |
| タイトル | **「Wi-Fi 接続情報」** — **20〜24pt** |
| 登録日 / 更新日 | **10〜11pt**（フッター。主情報を邪魔しない） |
| QR | **1辺 45mm 以上**（②がある場合は横並びまたは縦積み。**スキャンしやすいサイズ**） |
| フォント | **`Noto Sans JP`**（694 同様・Google Fonts `@import` 可） |
| レイアウト | **余白多め**・情報を **2〜3 ブロック**に整理（①② は **カード型**で区切る） |
| 配色 | **落ち着いた単色系**（例: ヘッダー淡青/淡緑・本文白・枠線は薄グレー）。**蛍光・原色・過度なグラデは NG** |
| 来客向け体裁 | 印刷ヘッダー上段 **(株）J-BISメンテナンス** → 拠点名 → **Wi-Fi 接続情報**（§8.5 レイアウト案） |
| 避ける表現 | 「社外秘」「取り扱い注意」の **過剰な赤帯**（Apple ID 694 印刷のような機密帯は **本台帳では使わない**） |
| 備考 | 値がある場合のみ **12pt 以下**で下部。空なら **非表示** |

**レイアウト案（v1 固定）**:

```
┌─────────────────────────────────────┐
│  (株）J-BISメンテナンス  （社名）    │
│  ○○営業所 / ○○支店      （拠点名・最大）│
│  Wi-Fi 接続情報          （タイトル）│
├─────────────────────────────────────┤
│ ┌─ SSID① ───────────────── [QR] ─┐ │
│ │  （SSID 値・大）    （45mm+）   │ │
│ │  パスワード① （値・大）         │ │
│ └─────────────────────────────────┘ │
│ ┌─ SSID② ───────────────── [QR] ─┐ │  ※②空ならブロック非表示
│ │  …                              │ │
│ └─────────────────────────────────┘ │
│  更新日: YYYY-MM-DD   （フッター）   │
└─────────────────────────────────────┘
```

**受入（目視）**: 浜田または担当者が **実際の A4 印刷**で「**2m 離れて拠点名と SSID が読める**」「**来客が見ても不自然でない**」を確認してから M6 へ進む。
