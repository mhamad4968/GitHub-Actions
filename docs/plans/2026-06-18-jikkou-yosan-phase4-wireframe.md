## 4. コード列 UI ルール（確定要件）

> Excel 総括表にはコード入力欄がない。**kintone ではコード列を明示**（浜田 2026-06-18）。

### 4.1 リストマスタ連動（Phase 3b 前提）

工種・種別を **名称** で選ぶ（候補 = **【リストマスタ ver.01】** から REST 取得）:

| マスタ状態 | 工種コード / 種別コード |
|-----------|------------------------|
| **`item_code` あり** | **自動入力**（M 正。編集可・上書き時薄黄） |
| **`item_code` 空白** | **空欄** — 作成者が **行上で仮入力** 可 |
| **コード確定** | 管理者が **M で `item_code` 登録** → 以降の新規行に自動反映 |

### 4.2 入力・保存

| ルール | 内容 |
|--------|------|
| 必須 | v1 **任意**（未決コードは空のまま保存可） |
| 保存先 | **実行予算レコードの原価行**（スナップショット） |
| マスタ更新 | **M アプリ**（管理者）。v1 は B→M 書戻しなし |
| 表示 | コード列 80px・右寄せ・プレースホルダ「未設定」 |

### 4.3 リストでコード空白の行（参考）

（塗）軌道工事 / 調査設計費 / 外注試験費 / 交通規制費 / 建設機械オペレーター賃金 / その他労務者賃金 / 建設機械油脂類 / 現場代理人給与手当 他 — **計 11 行程度**

## 5. 初版作成フロー

```
[新規作成]
    → ヘッダ入力（工事コード必須）
    → 版種別=当初（固定）
    → 仕様明細入力 → ① 自動
    → 詳細表: 材料・外注入力（④〜⑦）
    → 総括原価行: リンク行は詳細から自動反映
    → 総括直入力行: 線閉・レンタル等
    → 工種/種別選択 → コード自動 or 手入力
    → [保存]（下書き）
    → ⑧⑨ 検算表示確認
    → [初版確定] → status=初版確定（編集ロックは v1 なし・将来 WF）
```

| ステップ | 作成者操作 | システム |
|---------|-----------|---------|
| 1 | 工事コード・名称 | 外注 4 ブロック **テンプレ行生成** |
| 2 | 仕様行 | ① 計算 |
| 3 | 詳細表入力 | ②〜⑦ 集計 |
| 4 | 総括原価確認 | ⑧⑨・率 |
| 5 | コード空欄行 | **後日入力可**（保存後も編集可） |
| 6 | 初版確定 | ステータス更新 |
