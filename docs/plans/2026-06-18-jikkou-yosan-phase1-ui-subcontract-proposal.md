## 1. Excel 上の構造（サンプル）

| ブロック | 見出し | マーカー | 出力 |
|----------|--------|---------|------|
| ④ | 【修繕工事】 | …④ | 注文金額 → 総括 |
| ⑤ | 【足場工事】 | …⑤ | 注文金額 → 総括 |
| ⑥ | 【塗装工事】 | …⑥ | 注文金額 58,000,000 → 総括 |
| ⑦ | 【労務費】 | …⑦ | 合計 → 総括 |

各ブロック共通:

- 先頭: **会社名**（1社）
- 中間: 固定行種別（塗装一式 / 労務昼夜 / 諸経費 10% / 法定福利 15.33% 等）
- 末尾: **合計** → **法定福利費** → **注文金額**（⑦のみ **合計** で終了）

## 2. AIチーム提案（Recommended）

### 2.1 データモデル（変更なし）

- **1 サブテーブル** `subcontract_lines`
- **`subcontract_block`**: `repair` / `scaffold` / `paint` / `labor`（画面: 修繕/足場/塗装/労務）
- 行順 = Excel 行順（ブロック内 sort）

### 2.2 詳細タブレイアウト

```
┌─ 詳細表タブ ─────────────────────────────────────┐
│ [材料明細]  …② …③  （既存・上部セクション）        │
├──────────────────────────────────────────────────┤
│ 外注ブロック                                        │
│ ┌─ ▼ 【修繕工事】…④ ──────────────────────────┐  │
│ │  会社名 | 種別 | 単位 | 数量 | 単価 | 金額 …  │  │
│ │  （Excel 同型の固定行テンプレ）               │  │
│ │  ── 注文金額  0  ─────────────────────────── │  │
│ └──────────────────────────────────────────────┘  │
│ ┌─ ▶ 【足場工事】…⑤  （折りたたみ・0円時）─────┐  │
│ ┌─ ▼ 【塗装工事】…⑥ ──────────────────────────┐  │
│ ┌─ ▶ 【労務費】…⑦ ────────────────────────────┐  │
└──────────────────────────────────────────────────┘
```

| ルール | 内容 |
|--------|------|
| セクション分割 | 材料（上）＋ 外注 4 パネル（下）— **Excel の縦並び再現** |
| 折りたたみ | 各ブロック独立。**注文金額=0 かつ未入力** → 初期は **折りたたみ** |
| ブロック見出し | Excel 同型 `【修繕工事】` + 右端に `…④` バッジ |
| ブロックフッター | パネル下に **注文金額（または⑦合計）** を固定表示 → 総括へリンク可視化 |
| ワイド表示 | 688 同型: 材料左 / 外注右 の **2 カラム** も可（狭い画面は縦積み） |

### 2.3 行種別 `sub_row_kind`

| 値 | 画面 | 入力 | 備考 |
|----|------|------|------|
| `vendor` | 会社名行 | 作成者 | ブロック先頭 1 行 |
| `detail` | 通常明細 | 作成者 | 数量×単価→金額 |
| `overhead` | 諸経費 | 自動 | 明細合計×10%、単位 `%` |
| `insurance` | 各種保険料 | 自動/手動 | 1千万以上 0.3% 減額（Phase 2） |
| `block_total` | **合　計** | 自動 | 明細+諸経費−保険 |
| `legal_welfare` | 法定福利費 | 自動 | 合計×率（Phase 2） |
| `order_amount` | **注　文　金　額** | 自動 | 切捨 → 総括 link ④⑤⑥ |
| `labor_total` | **合　計**（⑦専用） | 自動 | 労務ブロックのみ → 総括 link ⑦ |

**計算行は金額セル読取専用**（小計行 UI 案①と同型）。

### 2.4 ブロック初期化

| 操作 | 動作 |
|------|------|
| 新規レコード | 4 ブロック分の **固定行テンプレ** を自動生成（Excel 5.2 行種別） |
| ブロック展開 | 折りたたみを開くとテーブル表示（データは既に存在） |
| 行追加 | `detail` 行のみ **「明細行を追加」**（`その他` 配下など） |

### 2.5 見やすさ（スタイル）

| 要素 | スタイル |
|------|---------|
| ブロック見出し | 背景 `#E8EEF4`・太字・左ボーダー 4px（ブロック色） |
| 計算行 | 薄グレー背景・金額列右寄せ |
| 注文金額行 | **太字**・フッター固定・マーカー `…⑥` を右端表示 |
| ブロック間 | 8px 余白 + 区切り線 |
| 総括連携 | フッター横に **「総括表 ⑥ へ」** リンク風ラベル（ジャンプは同一画面内アンカー） |
