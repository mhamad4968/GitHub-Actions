## 0. 目的

Space 48 のお知らせ＋アプリリンク乱立を解消し、**システム推進室メンバー**が **1 画面（ポータルアプリ）** から各ツールへ辿れる **WEB 風ハブ**を提供する。

| 項目 | 内容 |
|------|------|
| **利用者** | **システム推進室メンバー**（全員） |
| **Space 48 の役割** | **お知らせ（kintone 標準）** ＋ **ポータルアプリへのリンク 1 つ** |
| **一般社員** | 本ポータルは **対象外**。業務改善は [ご利用ガイド 699](https://jbis-kintone.cybozu.com/k/699/) を直接開く（**ポータル画面上にその旨の説明文は出さない** — 口頭・別資料で案内） |

## 4. リンク設定 — 浜田メンテ（再デプロイ不要）

### 4.1 フィールド設計（案）

ポータルアプリに **レコード 1 件**（`record_kind = 共通設定` 等）:

| フィールド | 型 | 備考 |
|------------|-----|------|
| `portal_links` | サブテーブル | 下記列 |

サブテーブル行:

| フィールドコード | 型 | 内容 |
|------------------|-----|------|
| `portal_tab` | ドロップダウン | **業務改善提案** / **台帳** / **運用** / **情報** / **その他**（kintone 保存値＝日本語。customize は内部 `bi` 等にマップ） |
| `title` | 文字列 | カードタイトル |
| `description` | 文字列（1行） | 任意 |
| `link_type` | ドロップダウン | **アプリ** / **スペース** / **URL** |
| `app_id` | 数値 | `link_type=アプリ` 時 |
| `link_url` | 文字列 | `link_type=スペース` or `URL` 時 |
| `sort_no` | 数値 | 小さいほど上 |
| `active` | チェック | **有効** OFF で非表示 |

> **API 注意**: サブテーブル内ドロップダウンは **選択肢キーを日本語**にすること（ASCII 短コード `bi` / `app` 等は REST 追加時 **CB_VA01**）。

### 4.2 追加手順（運用）

1. ポータルアプリの **設定レコード**を kintone **標準画面**で開く  
2. `portal_links` に **行を 1 つ追加**（タブ・表示名・リンク先・表示順・有効）  
3. 保存  
4. ポータル画面を **再読み込み** → カードが反映  

| 操作 | 方法 |
|------|------|
| 新アプリ追加 | サブテーブル 1 行追加 |
| 名称変更 | `title` 編集 |
| 一時非表示 | `active` OFF |
| タブ移動 | `tab` 変更 |
| 並び順 | `sort_no` 変更 |
| 色・レイアウト変更 | customize 要（稀） |

### 4.3 JS の読み方

1. 起動時 REST で設定レコードを GET  
2. `active` 行を `tab` → `sort_no` でソートして描画  
3. **設定 0 件・取得失敗** → §3 の **内蔵フォールバック一覧** を表示（初回・障害時）

## 6. 権限

| 対象 | 方針 |
|------|------|
| ポータルアプリ | **システム推進室メンバー**（スペース 48 参加者と整合） |
