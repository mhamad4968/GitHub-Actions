## 3. フィールド設計（新規・推奨）

既存 §4.2.3 の 4 項目（`skysea_status` / `skysea_checked_at` / `skysea_install_log` / `skysea_target_flag`）は **自動配信・CSV突合用メタ**として残す。  
本運用の正本は **下記の手動管理フィールド**とする（用途混同防止・DeepSeek §50-3-8）。

| code（案） | type | ラベル案 | 内容 |
|------------|------|----------|------|
| `skysea_manual_done` | RADIO_BUTTON または DROP_DOWN（2択UI） | SKYSEA対応 | **完了**／**未了**（初期値 **未了**・必須） |
| `skysea_manual_date` | DATE | SKYSEA対応日 | **必須ではない**。デフォルト規則は下表。手修正可 |
| `skysea_manual_handler` | SINGLE_LINE_TEXT | SKYSEA対応者 | 手入力。**最大64文字**。必須ではない（完了時は運用上推奨・customize 警告のみ可） |

**対応日デフォルト（確定）**

| 状況 | 動作 |
|------|------|
| 新規レコード／未了のまま | 対応日は **空のまま**（未了に今日を強制しない） |
| 未了 → **完了** に変更した瞬間 | 対応日が空なら **今日**をセット。既に日付があれば **触らない** |
| 完了 → 未了 | 対応日は **消さない**（履歴として残す。手で消してよい） |

**グループ**: 既存 `skysea_system_meta`（SKYSEA処理用）内に配置するか、同グループを拡張。`admin` 以外はグループごと不可視。

### 3.1 既存 4 項目との関係（必須ルール）

| 項目 | ルール |
|------|--------|
| 優先 | 手動運用の表示・一覧・印刷・進捗判断は **`skysea_manual_*` のみ**。既存4項目は **画面上も admin 以外非表示**（権限）だが **本運用の判定には使わない** |
| 自動同期 | v1 では **双方向とも自動書込しない**（`skysea_manual_*` ⇄ 既存4項目） |
| 表示 | SKYSEA専用一覧・印刷は `skysea_manual_*` のみ。既存4項目の値を列に出さない |
| 将来 | CSV突合や配信再開時は **別 GO** でマッピング表を追加 |

### 3.2 対象レコード（v1）

| 含む | 除外 |
|------|------|
| **個人** PC（`account_type`＝個人） | `pc_status`＝**廃棄**／**取消** |
| （任意・実装GO時に確認）共有・JR | 上記除外と同じ |

**Open（実装GO直前の確認1行）**: 共有・JRを v1 一覧に含めるか。未指定時の既定＝**個人のみ**。

## 4. 権限

1. **フィールド権限（正・必須）**: `skysea_manual_*`（および配置グループ）と、既存 `skysea_status`／`skysea_checked_at`／`skysea_install_log`／`skysea_target_flag` を **Everyone 閲覧不可**、**ユーザ `admin` のみ閲覧・編集可**。
2. **customize（補助・必須）**: `kintone.getLoginUser().code === 'admin'`（**厳密一致・大文字小文字区別**）のときだけ SKYSEA 入力UI・「SKYSEA対応一覧」ボタン・印刷 UI を出す。非 admin は **DOM を出さない**（無効化ボタンのみは不可）。
3. **優先**: 認可の本丸は **フィールド権限**。customize 漏れがあっても値は見えないこと。customize は UX／ボタン露出の二重化。
4. 通常の 674 一覧・業務機能は従来どおり（非 admin も利用可）。SKYSEA 列は通常一覧に出さない。
5. API／CSV: フィールド権限により非 admin では値を取得できないことを Acceptance に含める（実装後に `admin`／一般ユーザで疎通確認）。

## 5. UI／customize

### 5.1 詳細・編集（`admin` のみ）

- `skysea_manual_done`／`date`／`handler` を表示・編集。
- **対応日**: レコード編集開始時または「未了→完了」変更時に空なら **今日**をセット。既存値は上書きしない（ユーザーが消した場合のみ再デフォルト可＝実装時に1行仕様化）。

### 5.2 SKYSEA 専用一覧（`admin` のみ）

- 起動: 一覧画面ヘッダ／操作帯に **「SKYSEA対応一覧」**ボタン（非 admin は **非表示**）。クリックで **同ページ全画面パネル**（既存リスト一覧作成と同様の UX）。
- 切替: パネル内に **「未了」「完了」** の2ボタン（トグル）。同時選択なし。
- クエリ軸:
  - 完了: `skysea_manual_done in ("完了")`
  - 未了: `skysea_manual_done in ("未了")`（フィールド追加時に全件初期値 **未了** を入れるか、空＝未了としてクエリで吸収。実装時に一方に統一）
  - 廃棄・取消除外（既存 674 一覧ポリシーに準拠）
  - v1 既定: 個人のみ
- ソート: 既定 **所属名昇順 → PC名昇順**
- 表示列（固定）: **所属（`dept_name`）／利用者（`user_name`）／PC名（`pc_name`）／完了・未了／対応者**
- 既存「リスト一覧作成」を流用してよいが、**パスワード・メールPW・M365 PW・VPN PW 列はカタログから除外**（絶対に出さない）。

### 5.3 印刷

- 専用一覧パネル上で **所属（`dept_name`）を1つまたは複数選択**（チェックボックス。未選択時は印刷ボタン無効または「所属を選んでください」）。
- 出力: **ブラウザ印刷**（既存リスト一覧と同じ `window.print` 系。CSV/PDF専用エンジンは v1 対象外）。
- 印刷対象: 現在の完了／未了モード ∩ 選択所属 ∩ 画面上の取得結果。
- 印刷列は一覧と同型（機密列なし）。ソートは画面と同じ。
- 横向き・「社内チェック用・第三者提示禁止」注意書き1行。
