## 3. フィールド設計（新規・推奨）

既存 §4.2.3 の 4 項目（`skysea_status` / `skysea_checked_at` / `skysea_install_log` / `skysea_target_flag`）は **2026-08-06 浜田合意で削除**（利用予定なし・バックアップ JSON 退避後）。  
本運用の正本は **下記の手動管理フィールドのみ**。

| code（案） | type | ラベル案 | 内容 |
|------------|------|----------|------|
| `skysea_manual_done` | RADIO_BUTTON または DROP_DOWN（2択UI） | SKYSEA対応 | **完了**／**未了**（初期値 **未了**・必須） |
| `skysea_manual_date` | DATE | SKYSEA対応日 | **必須ではない**。デフォルト規則は下表。手修正可 |
| `skysea_manual_handler` | SINGLE_LINE_TEXT | SKYSEA対応者 | 手入力。**最大64文字**。必須ではない（完了時は運用上推奨・customize 警告のみ可） |

**対応日デフォルト（確定）**

| 状況 | 動作 |
|------|------|
| 新規レコード／未了のまま | 対応日は **空のまま**（未了に今日を強制しない） |
| 未了 → **完了** に変更した瞬間 | 対応日が空なら **今日**をセット。既に日付があれば **触らない** |
| 完了 → 未了 | 対応日は **消さない**（履歴として残す。手で消してよい） |

**グループ**: 既存 `skysea_system_meta`（SKYSEA処理用）内に配置するか、同グループを拡張。`admin` 以外はグループごと不可視。

## 4. 権限

1. **フィールド権限（正・必須）**: `skysea_manual_*`（および配置グループ）を **Everyone 閲覧不可**、**ユーザ `admin` のみ閲覧・編集可**。
2. **customize（補助・必須）**: `kintone.getLoginUser().code === 'admin'`（**厳密一致・大文字小文字区別**）のときだけ SKYSEA 入力UI・「SKYSEA対応一覧」ボタン・印刷 UI を出す。非 admin は **DOM を出さない**（無効化ボタンのみは不可）。
3. **優先**: 認可の本丸は **フィールド権限**。customize 漏れがあっても値は見えないこと。customize は UX／ボタン露出の二重化。
4. 通常の 674 一覧・業務機能は従来どおり（非 admin も利用可）。SKYSEA 列は通常一覧に出さない。
5. API／CSV: フィールド権限により非 admin では値を取得できないことを Acceptance に含める（実装後に `admin`／一般ユーザで疎通確認）。

## 5. UI／customize

### 5.1 詳細・編集（`admin` かつ種別=個人 のみ）

- `skysea_manual_done`／`date`／`handler` を表示・編集（共有/JR端末/サーバーNAS/その他では非表示）。
- **対応日**: レコード編集開始時または「未了→完了」変更時に空なら **今日**をセット。既存値は上書きしない（ユーザーが消した場合のみ再デフォルト可＝実装時に1行仕様化）。

### 5.2 SKYSEA 専用一覧（`admin` のみ）— **as-built**

- 起動: 一覧画面に **「SKYSEA対応一覧」**（非 admin は非表示）。同ページ全画面パネル。
- 切替: パネル内 **「未了」「完了」**（同時選択なし）。行ごとに完了⇔未了トグル可。
- **SCOPE=** `account_type=個人` ; `pc_status not in (保管,廃棄,取消)`（S-SCOPE-LINE-01）
- 所属: **App680 `sort_no` 全件**＋件数。レコード出現集合のみから組み立てない（S-DEPT-MASTER-01）
- **UI除外所属**（チェックバー・所属別集計・リストから非表示）: システム推進室、関越支店施工部、東京支店橋りょうリペア部、東京支店施工部（BUILD `2026-08-07-674-skysea-exclude-4-depts`）
- UX: **①所属選択 → ②「リスト表示」**（未選択で全件リストを出さない）
- **所属別集計表**（画面上部・印刷対象外）: 個人 SCOPE 内の **完了／未了** を所属別に件数集計。680 `sort_no` 順・合計行・完了率。パネル表示時および完了⇔未了トグル後に更新
- クエリ: `skysea_manual_done in ("完了"|"未了")`（空は setup で未了初期化。空 DROP_DOWN は `not in` で拾えない → クライアント空判定）
- ソート表示: 680 順の所属 → PC名
- 表示列（固定）: **所属／利用者／PC名／完了・未了／対応者**（パスワード列なし）

### 5.3 印刷 — **as-built**

- 所属を1つまたは複数選択後に印刷。
- **専用 `#npl674-skysea-print-root`**＋他 `display:none`（`visibility:hidden` 禁止・S-PRINT-ROOT-01）
- 横向き・「社内チェック用・第三者提示禁止」1行。列は一覧と同型。
