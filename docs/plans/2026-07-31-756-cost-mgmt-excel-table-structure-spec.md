## 2. Excel 表構造（正本）

### 2.1 行階層

```
システム工種（工種番号 B + 費目名のブロック）
 └ 費目（外枠）
     └ 種別（補助）… 行挿入単位
         └ 詳細 / 品名（手入力）
             └ （費目により）昼間・夜間・特例区分など追加段
```

- **1ブロック＝1システム工種**（例: 10100 材料費、10900 工事管理者賃金、12400 旅費交通費、13600 交際費）。
- 横断合算（全工種から材料費だけ合算）は**対象外**（工種ブロック内集計）。

### 2.2 列（画面に出す）

| 列 | 役割 | 入力 |
|----|------|------|
| システム工種 / 工種番号 | ブロック識別 | 選択・表示 |
| 費目 | 外枠 | リスト／コード表（種別はコード表固定・UIで種別行追加しない） |
| 種別（補助） | 種別枠（表示専用 SUM） | 表示 |
| 詳細 / 品名 | 手入力 | 可 |
| **操作**（UI専用・#R-EXCEL-UI-01） | 詳細行＋／－ | ボタンのみ（Excel正本列ではない） |
| 単価 | 明細行 | 可（**千区切りカンマ表示**・保存値はカンマ無し） |
| **数量**（明細計画・#R-EXCEL-UI-03） | 明細行 | 可（App757。月次数量とは別）。**単価入力時に空なら 1 を自動セット**（既存数量は上書きしない） |
| 実行予算額 | 明細＝自動 | **ROUND(単価×数量)**（手入力不可。親＝子合計） |
| 月×12（各月: 数量・金額） | 実績 | 明細は入力／灰色は合計のみ（数量はセッションのみ）。**金額入力時に数量が空なら 1**（手直し可） |
| 原価累計金額 | 自動 | 読取専用 |
| 予算との差 | 自動 | 読取専用 |
| 備考 | 内訳由来表示 | 表示（編集正は内訳） |

月ヘッダは着手月連動の既存方針を維持してよい（Excel例: 2026-02〜2027-01）。列数は Excel 同型の **数量＋金額ペア×月数**。

**集計行の見た目結合（#R-EXCEL-UI-02）**: 費目行は種別〜単価まで枠線消しで一塊に見せる。種別行は詳細〜単価まで結合。費目・種別とも **計画数量＝表示中詳細の SUM・実行予算額＝同 SUM**（本物の colspan は sticky 崩れのため使わない）。月次は結合しない。空種別の操作列＋は維持。

**行の色（#R-EXCEL-UI-04）**: 実装色は費目＝薄緑 `#e8f5e9`／種別＝薄青 `#e3f2fd`／詳細＝白。実績入力は詳細行のみ。

**暫定（#R-EXCEL-UI-05・来週まで）**: 工事原価管理では**既存内訳由来の詳細は非表示**。操作列＋で追加した詳細だけ表示・手入力（`JY2_ACTUAL_DETAIL_MANUAL_ONLY`）。内訳App757は削除しない。来週＝**内訳をどう原価管理へ持ってくるか**。

**費目の見た目統一（#R-EXCEL-UI-06）**: 費目名は**親行・費目グループ行とも太字**（ラベルのみ。数値セルは通常ウェイト）。例外費目を作らない。

**種別なし費目（#R-EXCEL-UI-07）**: 例「その他材料費」。種別行は出さないが、**費目行の色・太字・揃え・数量SUM・実行予算SUMは通常費目と同一**。差分は詳細レイアウトのみ（2セル＝種別列←name2／詳細列←name3）。新規の特殊費目を足すときも、この「共通仕様＋差分だけ」で入れる（個別その場直し禁止）。

**揃え位置（#R-EXCEL-UI-08）**: 費目名＝**左**（親行・グループ行とも `padding-left:6px`）。種別名＝左＋一段インデント。詳細テキスト＝左。数量・単価・金額・各SUM＝**右**（tabular nums）。操作列＝中央。例外行を作らない。

**Excel費目枠オーバーライド（#R-EXCEL-UI-09）**: コード表の constructionMenu（材料費・外注費…）より **原価管理明細の費目枠が正**。例: **10200 → 塗装工事**、**10300 → 足場工事**、**10400 → 塗装・足場工事**、**10600 → 修繕等工事**、**10700 → 塗装附帯工事**、および **軌道工事・調査設計費・外注試験費・交通規制費・追加工事①〜⑤**（いずれも種別なし・詳細2セル＝その他材料費と同型）。`JY2_COST_MGMT_HIMOKU_OVERRIDE` / `OVERRIDE_BY_NAME` ＋ `TYPELESS`。空のときは操作列＋で最初の詳細を追加。共通仕様（SUM/色/太字/揃え）は #R-EXCEL-UI-06〜08 を継承し、差分だけ足す。

**種別なしの詳細2セル（#R-EXCEL-UI-10）**: 列は増やさない。Excelどおり **種別列＝詳細左（name2）・詳細列＝詳細右（name3）**。全行に列を足すと表が膨らみ、通常費目の種別と混線する。一時保存前はフォーカス中 input を明示 commit（`jy2FlushActiveInputBeforeSave`）。

**コード空の名称枠（#R-EXCEL-UI-11）**: Excelでシステム工種番号が空の枠も表に出す（例: 軌道工事等）。費目枠＝名称。レイアウトは **10700 と同型（TYPELESS・詳細2セル）**。`HIMOKU_OVERRIDE_BY_NAME`。追加工事はコード 14100〜14500 があればコード側 OVERRIDE も可。**内訳にブロックが無いときは原価管理表示時に空ブロックを自動追加**し **10700 直後へ並べる**（`jy2CostMgmtEnsureTypeOnlyFrames`・一時保存で App757 へ。廃止済みは再作成しない）。内訳連動の詳細は月曜以降。

**費目→昼間／夜間→詳細（#R-EXCEL-UI-12）**: 例 **10900 工事管理者賃金**（費目＝出向工事管理者／その他工事管理者）と **建設機械オペレーター**（システム工種コードなし・費目＝建設機械オペレーター／その他労務）。コード表の「労務費」や種別としての「建設機械オペレーター」「その他労務者」は原価管理では使わない。各種別枠は **昼間／夜間**。その下に詳細を操作列＋で追加。`HIMOKU_OVERRIDE` / `OVERRIDE_BY_NAME` ＋ `TYPES_OVERRIDE` / `TYPES_OVERRIDE_BY_HIMOKU`。オペレーター枠は内訳に無ければ自動追加し **10900 直後**へ並べる。共通仕様（SUM/色/太字/揃え）は #R-EXCEL-UI-06〜08 を継承。

**種別下の詳細2セル（#R-EXCEL-UI-14）**: **種別あり費目はすべて**、種別行の下の詳細が **左・右の2セル**（種別列←詳細左／詳細列←詳細右）。列は増やさない。App757 は name1〜3 のみのため name2 に `種別` または `種別／詳細左` を格納。右だけ使う枠は左を空でよい。平坦費目（TYPELESS・種別なし）は従来の詳細2セルのまま。

**区切り線はシステム工種ごと（#R-EXCEL-UI-13）**: 薄いグレーの下線は **費目ごとではなく工種ブロックの最終行**だけ。費目が複数ある工種（10900 等）で「別工種」と誤認しない。

### 2.3 計算（Excel 検証済み）

| 項目 | 式・規則 |
|------|----------|
| 明細・月金額（多い行） | `ROUND(単価 × 当月数量, 0)` |
| 明細・月金額（例外） | **金額直入れ可**（例: ACCESS=5600、島津=70000） |
| 灰色・月金額／数量 | 費目・種別・親行は子の **SUM**（数量＝セッション数量合計・金額＝App758合計）。**編集不可**。施工計など総計行の数量は単位混在のため「－」 |
| 原価累計（明細） | 各月金額の SUM |
| 原価累計（親） | 子の原価累計の SUM |
| 予算との差 | `実行予算額 − 原価累計金額`（予算がある行） |

### 2.4 コード表依存の例（抜け漏れ防止）

実装・目視時に必ずサンプル確認する費目:

| 工種番号 | 費目 | 注意 |
|----------|------|------|
| 10900 | 工事管理者賃金 | 出向／その他 → 昼間・夜間 |
| （コード空） | 建設機械オペレーター／その他労務 | 各費目→昼間／夜間→詳細2セル（10900と同型） |
| 12400 | 旅費交通費 | 出張旅費特例／3万円未満公共交通／その他… |
| 13600 | 交際費 | 得意先接待（甲）（乙）／その他 |

正本は Excel「コード表」の補助名称。固定3段にハードコードしない。
