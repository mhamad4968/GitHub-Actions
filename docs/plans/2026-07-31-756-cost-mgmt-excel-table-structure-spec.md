## 2. Excel 表構造（正本）

### 2.1 行階層

```
システム工種（工種番号 B + 費目名のブロック）
 └ 費目（外枠）
     └ 種別（補助）… 行挿入単位
         └ 詳細 / 品名（手入力）
             └ （費目により）昼間・夜間・特例区分など追加段
```

- **1ブロック＝1システム工種**（例: 10100 材料費、10900 工事管理者賃金、12400 旅費交通費、13600 交際費）。
- 横断合算（全工種から材料費だけ合算）は**対象外**（工種ブロック内集計）。

### 2.2 列（画面に出す）

| 列 | 役割 | 入力 |
|----|------|------|
| システム工種 / 工種番号 | ブロック識別 | 選択・表示 |
| 費目 | 外枠 | リスト／コード表（種別はコード表固定・UIで種別行追加しない） |
| 種別（補助） | 種別枠（表示専用 SUM） | 表示 |
| 詳細 / 品名 | 手入力 | 可 |
| **操作**（UI専用・#R-EXCEL-UI-01） | 詳細行＋／－ | ボタンのみ（Excel正本列ではない） |
| 単価 | 明細行 | 可 |
| **数量**（明細計画・#R-EXCEL-UI-03） | 明細行 | 可（App757。月次数量とは別） |
| 実行予算額 | 明細＝自動 | **ROUND(単価×数量)**（手入力不可。親＝子合計） |
| 月×12（各月: 数量・金額） | 実績 | 明細は入力／灰色は合計のみ（数量はセッションのみ） |
| 原価累計金額 | 自動 | 読取専用 |
| 予算との差 | 自動 | 読取専用 |
| 備考 | 内訳由来表示 | 表示（編集正は内訳） |

月ヘッダは着手月連動の既存方針を維持してよい（Excel例: 2026-02〜2027-01）。列数は Excel 同型の **数量＋金額ペア×月数**。

**集計行の見た目結合（#R-EXCEL-UI-02）**: 費目行は種別〜計画数量、種別行は詳細〜計画数量を枠線消しで一塊に見せる（本物の colspan は sticky 崩れのため使わない）。実行予算額・月次は結合しない。空種別の操作列＋は維持。

**行の色（#R-EXCEL-UI-04）**: 費目＝やや濃い灰／種別＝薄い灰／詳細（実績入力）＝ごく薄い青白。実績入力は詳細行のみ。

### 2.3 計算（Excel 検証済み）

| 項目 | 式・規則 |
|------|----------|
| 明細・月金額（多い行） | `ROUND(単価 × 当月数量, 0)` |
| 明細・月金額（例外） | **金額直入れ可**（例: ACCESS=5600、島津=70000） |
| 灰色・月金額／数量 | 子行の **SUM**（費目・種別の集計行）。**編集不可** |
| 原価累計（明細） | 各月金額の SUM |
| 原価累計（親） | 子の原価累計の SUM |
| 予算との差 | `実行予算額 − 原価累計金額`（予算がある行） |

### 2.4 コード表依存の例（抜け漏れ防止）

実装・目視時に必ずサンプル確認する費目:

| 工種番号 | 費目 | 注意 |
|----------|------|------|
| 10900 | 工事管理者賃金 | 出向／その他 → 昼間・夜間 |
| （材料・労務周辺） | 建設機械オペレーター | 昼間・夜間 → 平日昼間・平日夜間・法定休日夜間 等 |
| 12400 | 旅費交通費 | 出張旅費特例／3万円未満公共交通／その他… |
| 13600 | 交際費 | 得意先接待（甲）（乙）／その他 |

正本は Excel「コード表」の補助名称。固定3段にハードコードしない。

## 5. DeepSeek §50-3-8 盲点と CIO 突合（2026-07-31）

| # | 盲点 | CIO 方針（SPEC 反映） |
|---|------|----------------------|
| 1 | 灰色合計と明細入力の二重計上 | **灰色＝読取専用 SUM**。明細のみ入力可。保存時も合計セルは書かない（再計算） |
