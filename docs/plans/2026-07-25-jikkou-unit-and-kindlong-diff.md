### 1.3 結論（単位）

1. **単位DDの正本は Ver.02 CONFIRMED**（735 unit リストではない）。
2. 735から流用するのは **`㎡`/`日`/`回` の3語だけ**（すでに Ver.02 に含まれる）。
3. `月`→`箇月` の自動置換は **しない**（表記が違う）。旧データ移行時はマッピング表で扱う。
4. **依頼者への単位質問は原則不要**（浜田確認済）。`kg` 追加の要否だけ任意。

## 2. code_row × kindLong / material 表記ゆれ（調査②）

### 2.1 規模感

| 比較 | 結果 |
|------|------|
| 735 `work_type_code`（空でない） | 41 |
| Excel `workTypeCodeToProfile` | 42 |
| **コード一致** | **40** |
| Excelのみ | `11600`, `14500` |
| 735のみ | `13400`（（塗）社員助勢費用） |
| kindLong 49語のうち seed名称と **完全一致** | 8 |
| 同上 **曖昧一致**（昼間/夜間・レンタル接尾等） | 9 |
| 同上 **seedに無い（Excel固有の明細語）** | 32 |
| materialCats 8語 vs seed `sub_type_name` | exact 3 / fuzzy 2 / missing 3（`鋼材費`・`生コンクリート費･石材費`・`塗装記録表示シール`） |

※「seedに無い」は欠陥ではない。735コード表は **費目階層・定義**、Excel kindLong は **データマスタ明細ラベル**。役割が違う。

### 2.2 材料カテゴリ（material）ゆれ — 正は Excel

| Excel `materialCats` | 735 `sub_type_name` 相当 | 関係 |
|----------------------|--------------------------|------|
| 塗料 | 塗料 | 一致 |
| 鋼材費 | （単独なし）／`鋼材･二次製品費など` に包含感 | **Excelは分割** |
| 二次製品費 | `鋼材･二次製品費など` | **Excelは分割** |
| 生コンクリート費･石材費 | `生コンクリート･石材など` | 表記ゆれ（費/など） |
| ＡＳ合材費 | `ＡＳ合材費など` | 「など」有無 |
| 鋼製製品費･ゴム製品等 | 同左 | 一致 |
| その他材料費 | 同左 | 一致 |
| 塗装記録表示シール | seedに無し（JSONにはシード済） | Excel正・CLOSED |

**運用**: UI候補は Excel。735は定義・裏取りのみ。

### 2.3 保安・労務系 — 735は「外注/直轄」、Excelは「役職＋昼夜」

735の1語が Excel の昼夜2語（または名称違い）に分かれる。**UIラベル正は Excel**。

| 735 `sub_type_name`（例） | Excel kindLong（例） | メモ |
|---------------------------|----------------------|------|
| 外注線閉責任者 / 直轄線閉責任者 | `線閉責任者　　昼間` / `…夜間` | 外注・直轄の区別は Excelラベルに無い |
| 外注列車見張員 / 直轄… | `列車見張員　　昼間` / `…夜間` | 同上 |
| 外注交通整理員 / 直轄… | `交通整理員　　昼間` / `…夜間` | 同上 |
| 外注停電責任者 / 直轄… | `停電作業者　　　　　　夜間`（昼間なし） | 名称「責任者」↔「作業者」 |
| 外注検電接地作業者 / 直轄… | `検電接地作業者　　　　昼間` / `…夜間` | 同上 |
| 外注重機誘導員 / 直轄… | `重機誘導員　　　　　　昼間` / `…夜間` | 同上 |
| 出向工事安全専任管理者 / 直轄工事安全専任管理者(昼) | `工事安全専任管理者　　　昼間` / `…夜間` | 「出向/直轄」接頭がExcelに無い |
| 出向工事管理者賃金 | `出向工事管理者賃金　　昼間` / `…夜間` | Excelが昼夜分割 |
| 建設機械オペレーター | `軌陸車オペレーター賃金　昼間` / `…夜間` | 名称が大きく違う（建設機械↔軌陸車） |
| 仮設材 / 建設機械 | `仮設材レンタル` / `建設機械レンタル` 等 | Excelは用途接尾あり |

**スペース幅**（全角スペース個数）は Excel原文どおりシード維持。独断 trim 禁止（Step1同）。

### 2.4 結論（表記）

1. **名称DDの正本 = Excel JSON**（735コード表の文言で上書きしない）。
2. 735は **工種CD→profile 裏取り** と **定義文** に使う。
3. 「外注/直轄」と「昼間/夜間」は **別軸**。移行時はマッピング表が要るが、**依頼者に全件確認は不要**（Excel採用で進める案をパックに記載）。
4. 依頼者に聞くべき穴は従来どおり主に **R-19の2語**（`労務費（夜間）` / `工具･機械使用料`）＋任意の周辺。
