## §1. 背景・目的

### 1.1 背景

- 社内 **Kintone ライセンス ID**（ログイン ID）を **Excel**（`Kintoneアカウント一覧.xlsx`）で管理している。
- 現在 **74 アカウント**（すべてステータス「使用中」）。
- 契約 **77 ID**・余剰 **3**・単価 **1,800 円/ID/月**（Excel サマリー行より）。
- 支払箇所: **本社** / **首都圏支店**。

### 1.2 目的

1. Excel と同等の台帳を kintone（**Space 48**）に置き、**日常操作はダッシュ**で行う。
2. **アカウント集計**（所属グループ × 所属）を **745 型**で表示（**所属グループ単位小計**）。
3. **月次利用費用**を **支払箇所 × 登録日（利用開始日）** ベースで集計。
4. **契約数・月額サマリー**はダッシュ上部で **手入力可**（Excel サマリー相当）。
5. **一覧 xlsx 出力** と **印刷** をダッシュから実行。

### 1.3 スコープ外（v1）

| 項目 | 理由 |
|------|------|

## §5. 集計

### 5.1 アカウント集計（745 型 — 現時点稼働数）

**目的**: 所属グループ × 所属 の **現在稼働数**（月次列は **不要** — §41 Q1）。

**カウント対象**: 利用終了日 **空** のレコード。

**レイアウト**:

| 列 | 内容 |
|----|------|
| 所属グループ | §7.3 の固定順 |
| 所属 | §7.4 の配下所属 |
| 件数 | 稼働中レコード数 |

- **小計行**: **所属グループごと**
- **最終行**: **全社合計**
- **絞込**: 所属グループ・所属 **チップ toggle**（745 同型）+ **条件クリア**
- **出力**: xlsx / 印刷

### 5.2 月次利用費用集計（支払箇所 × 登録日）

**目的**: **支払箇所**（本社 / 首都圏支店）別の **月次利用費用**。

**登録日キー**: フィールド **`start_date`（利用開始日）** を正とする（§41 Q2）。

**v1 定義（新規登録ベース）**:

```
対象月 M に含むレコード =
  start_date の年月 = M
  かつ（end_date が空 または end_date の年月 > M）
```

**金額**: 件数 × **単価**（§5.2.1 の **1アカウント月額利用料**。コード固定 **禁止**）。

#### 5.2.1 費用集計パラメータ（集計表直上 — 浜田追加要件 2026-07-05）

**背景**: Kintone（サイボウズ）の **価格改定が多い** ため、契約数・単価をソースコードや DB フィールド初期値に **固定してはならない**。

**配置**: **月次利用費用集計** アコーディオン内、**集計表の直上**（絞込条件と集計表の間）に常時表示。

| 項目 | 初期値 | 編集 | 備考 |
|------|--------|------|------|
| **1アカウント月額利用料** | 1,800 | **admin 手入力可** | 円/ID/月。改定時にここを変更 |
| **総契約数** | 77 | **admin 手入力可** | 契約 ID 数（利用数と別管理） |
| アカウント利用数 | — | 表示のみ | 稼働中レコード数から **自動** |
| アカウント余剰数 | — | 表示のみ | **総契約数 − 利用数**（**本社配賦** — §5.2.2） |
| 月額利用料合計 | — | 表示のみ | **総契約数 × 1アカウント月額利用料** |

#### 5.2.2 支払箇所のくくり（余剰＝本社 — 浜田確定 2026-07-05）

**余剰 ID はすべて本社分としてカウント**する。首都圏支店に余剰は配賃しない。

```
余剰数 = max(0, 総契約数 − 稼働中アカウント利用数合計)
```

| 支払箇所 | 内訳 | 件数の出所 |
|----------|------|-----------|
| **本社** | **利用分** | `pay_site = 本社` の稼働中レコード数 |
| **本社** | **余剰分** | 上記 **余剰数**（レコードなし・論理行） |
| **本社** | **小計** | 利用分 + 余剰分 |
| **首都圏支店** | **利用分** | `pay_site = 首都圏支店` の稼働中レコード数 |
| **首都圏支店** | **小計** | 利用分のみ（余剰 **0**） |
| **全社** | **合計** | 本社小計 + 首都圏小計 = **総契約数** と一致 |

**例（移行時点）**: 総契約 77 / 利用 74 / 余剰 3 → 本社 68+3=**71**、首都圏 **6**、合計 **77**。

**月額（サマリー表示）**:

- 本社月額 = **本社小計 × 単価**
- 首都圏月額 = **首都圏利用分 × 単価**
- 全社月額 = **総契約数 × 単価**

**UI 要件**:

- §5.2.1 パネル内、またはその直下に **支払箇所別内訳**（利用分 / 余剰分 / 小計）を表示。
- 月次集計表の **行** も同構造（本社・利用分 / 本社・余剰分 / 首都圏・利用分）。
- **余剰分**は DB レコードを持たない。**集計実行時点**の総契約数・稼働数から算出。
- 月次列について: **利用分**は各月の登録ベース件数。**余剰分**は **当月列のみ** に表示（過去月は契約数の履歴未保持のため v1 は当月スナップショット）。

**保存先**: 台帳アプリの **設定レコード**（VPN 734 `record_kind=設定` 同型）。フィールド例: `contract_total` / `unit_price_monthly` / `settings_updated_note`。

**月次集計表レイアウト**:

| 行（支払箇所） | 区分 | 列 |
|----------------|------|-----|
| 本社 | 利用分 | 各月（登録ベース件数） |
| 本社 | 余剰分 | **当月のみ**（論理行） |
| 本社 | **小計** | 利用分 + 余剰分（当月） |
| 首都圏支店 | 利用分 | 各月 |
| 首都圏支店 | **小計** | 利用分 |
| **全社** | **合計** | 本社小計 + 首都圏小計 |

**§5.2.1 共通 UI**（入力・保存）:

- 数値入力欄 + **保存** ボタン（または blur 時に設定 REST 保存）。
- 保存後 **「集計を更新」** で月次表を再計算。
- ヒント: 「余剰 ID は **本社** に計上されます。」
- xlsx / 印刷: 単価・総契約数・**支払箇所別内訳（利用/余剰）** をヘッダ注記。

**絞込**: 期間（YYYY-MM ～ YYYY-MM）・支払箇所チップ（745 集計 UI 踏襲）。

> **注**: 過去月の再集計は **745 型（終了日保持）** により整合。確定保存が必要になったら v1.1 で 734 型スナップショットを検討。

### 5.3 一覧上部サマリー（Excel 行2–5 相当）

§5.2.1 と **同一の契約・単価** を、台帳 **一覧画面上部** にもコンパクト表示（Excel サマリー相当）。

| 項目 | 内容 |
|------|------|
| 表示 | 1アカウント月額 / 総契約数 / 利用数 / 余剰（本社配賦）/ **本社・首都圏内訳** / 月額合計 |
| 編集 | **月次費用集計 §5.2.1 と連動** — どちらかで変更すれば両方反映 |
| 配置 | 一覧ヘッダ付近（アコーディオン折りたたみ可） |

> **正本**: 契約数・単価の編集 UI は **月次利用費用集計表直上（§5.2.1）** を必須とする。一覧上部は参照用ミラー。

## §14. AI チームレビュー（2026-07-05）

### 14.1 結論

**ブロッカーなし — 実装 GO 可能。**

745 型（利用終了日）により、月次利用費用の過去月再計算と矛盾しない。DB 閲覧のみ + 台帳 REST は VPN/JRE 実績どおり。

### 14.2 論点整理

| # | 論点 | 結論 | 備考 |
|---|------|------|------|
| 1 | 物理削除 vs 月次費用 | **745 型で解決** | 終了日保持。再集計 OK |
| 2 | 東京支店の千葉/水戸/鎌ヶ谷 | **マスタに含める** | Excel 74 件未使用。680 整合 |
| 3 | 札幌・首都圏の所属グループ | **リフォーム事業統括部配下** | Excel 実績どおり |
| 4 | 595 連携 | **任意ハイブリッド** | 共有・特権は手入力 |
| 5 | 月次費用の定義 | **v1 = 登録月ベース件数×単価** | 月末稼働課金が必要なら v1.1 で追加定義 |
| 6 | 契約数 77 の保存 | **734 型設定レコード** | 手入力 + 利用数自動 |
| 7 | login_id unique | **必須** | 短 ID（メール形式ではない） |
| 8 | kintone 標準集計 | **不可** | 745 同様 JS 計算 |
| 9 | Space thread ID | **実装時確定** | app-ids.json に記録 |
| 10 | status フィールド | **維持** | Excel 互換 + 終了日連動 |
| 11 | 価格改定 | **集計表直上で単価・契約数編集** | 浜田追加 2026-07-05。734 設定レコード保存 |
| 12 | 余剰の配賦 | **本社に集約** | 本社=利用+余剰 / 首都圏=利用のみ。浜田確定 2026-07-05 |

### 14.3 実装 GO 後に浜田確認推奨（1 点のみ）

| 項目 | 内容 | デフォルト |
|------|------|-----------|
| **月次費用の数え方** | **A)** その月の **新規登録数** × 単価 / **B)** その月 **末時点の稼働数** × 単価 | **A（§5.2 記載）**。Excel サマリーは現時点件数のため、履歴月は **A** が自然。B が必要なら GO 後に切替 |
