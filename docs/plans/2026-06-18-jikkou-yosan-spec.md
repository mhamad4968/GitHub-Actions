## 4. 帳票構造（書式.xls 読解 — AIチーム確認済み）

### 4.1 総括表

- **上部「仕様」**: 契約・見積明細（単位・数量・単価・金額）→ **合計 ①**
- **下部「システム入力工種」**: 工種×種別×消費税×金額。②〜⑦ は「詳細表にて内訳を記載」
- **⑧** 工事原価額（下段合計）、**⑨** 粗利（①−⑧）、各費目 **率**（対 ①）

### 4.2 詳細表

- **材料**: 仕入先・品名・容量・メーカー・所要量×単価 → …② …③
- **外注ブロック**（【修繕工事】【足場工事】【塗装工事】【労務費】）:
  - 明細 → 諸経費 **10%** → 法定福利費 → **注文金額**（有効数字3桁以下切捨）→ …④〜…⑦
  - 任意保険: 請負1千万以上 **0.3% 減額**（書式注記）

### 4.3 リスト（参照のみ・v1 未依頼）

- 発注支社 / 部門 / 桁種別 / 単位 / 消費税 / システム入力工種 / 種別
- 各列に **「※新規追加出来るようにしたい」** — **将来要件** として SPEC に保持

### 4.4 資料ギャップ（OPEN-SPEC-01）

- サンプル **詳細表は 72 行・⑦ まで**。総括表の **線閉・レンタル・消耗品** 等は **詳細表ブロックなし** で総括直入力。
- **浜田確認（Q7）**: 今回依頼は **総括表・詳細表のみ** → v1 は **書式サンプルどおり** で進め、不足ブロックは **依頼が来た時点** で拡張。

#### 9.7.1 方針
