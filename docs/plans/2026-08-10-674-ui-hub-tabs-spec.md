## 0. 目的・非目的

### 目的

- 機能追加で一覧がごちゃついた状態を、**役割（何をしたいか）で分ける**ことでシンプルにする。
- 色・階層を整え、利用者・管理者が「次に押すもの」を迷わないようにする。
- **台帳をメイン入口（ダッシュボード的）**にし、棚卸・管理は必要なときだけ開く。

### 非目的

- kintone **別アプリ**への分割（裏でアプリが違う、は**しない**）。
- SKYSEA 実配信・GPO・SG・新規案件化。
- 670 キャンペーン期間と年次期間の**完全統合**（既存どおり二系統ラベル維持・`2026-08-08-evening` O3）。
- 一度に編集ヘッダーまで全部壊す大改修（段階実施）。

## 2. 情報設計

### 2.1 一覧（`app.record.index.show`）— 3 タブ

```
[ 台帳 | 棚卸 | 管理 ]
        ↑ 既定（ダッシュボード入口）
```

| タブ | 誰向け | 置くもの | 置かないもの |
|------|--------|----------|--------------|
| **台帳** | 全員 | 次採番バー／キーワード・備考・並び／絞り込み・条件クリア／種別・ステータス等チップ（1行）／いまの条件＋該当件数／リスト一覧作成 | 一括棚卸・未棚卸・棚卸状況アコーディオン／SKYSEA 管理ボタン群／「よく使う機能」プリセット（廃止） |
| **棚卸** | 棚卸担当〜全員（閲覧可） | 期間ラベル／台帳側条件要約＋「台帳で条件変更」／一括棚卸／未棚卸一覧／棚卸状況一覧 | 日常検索の主戦場（＝台帳タブへ誘導）／SKYSEA 管理 |
| **管理** | **admin のみ表示** | SKYSEA対応一覧／SKYSEAクライアント削除対応（既存機能の移設） | 一般利用者向け検索・棚卸操作 |

**権限**: 管理タブは現行どおり LoginID `admin`（および既存 SKYSEA UI と同じ条件）のときだけタブ自体を出す。非 admin には **台帳｜棚卸** のみ。

### 2.2 編集・詳細ヘッダー（`#new-pc-ledger-buttons`）— P2 実装済

| グループ | 例 | 表示 |
|----------|----|------|
| **主操作**（常時目立つ・最大3） | 入力支援／印刷／PC買替／（詳細なら期間内）個別棚卸 | ボタン 1〜3 |
| **その他**（`<details>`・初期閉じ） | 自動生成／M365入力／転用廃棄／登録ミス取消／全フィールドリセット | 初期は閉じる |

危険操作（廃棄・取消・リセット）は赤系＋既存 confirm を維持。保管の新規・編集は従来どおりリセットのみ（主側）。

### 2.3 レコード画面とタブの関係

- タブは **一覧専用**。レコード詳細／編集を開いているときは従来どおりヘッダーバー。
- 一覧に戻ったとき、**直前のタブ**を復元（§3.2）。

### 2.4 絞り込み UX（P1 磨き・浜田 GO）

- 種別・ステータス・転用・M365／資産台帳チップ変更 → **300ms デバウンス後に自動適用**（連打は最新のみ）。
- 「いまの条件」横に **該当件数**（`getQueryCondition`＋`totalCount`・非同期）。
- 棚卸タブに台帳条件要約＋台帳へ誘導（フィルタ状態は同一一覧・タブ切替で消さない）。

## 3. 状態・URL・期間

### 3.1 フィルタ（探す条件）とタブ

- 既存 URL／hash パラメータ（`npl674kw` / `npl674note` / `npl674sort` / `query` / 標準 `q` 等）は **台帳タブの「探す」状態**として維持。
- **タブ選択は別キー**（`sessionStorage` + hash `npl674hub=ledger|inventory|admin`）。
- タブ切替でフィルタ条件を勝手に消さない。

### 3.2 既定・復元

1. 初回（キーなし）→ **台帳**
2. 同一セッション内で一覧再表示 → 直前タブを復元
3. 管理タブを開いたまま非 admin 相当になった場合 → 台帳へフォールバック

### 3.3 棚卸期間外の棚卸タブ

DeepSeek 案の「タブ全体グレーアウトで操作不可」は **採用しない**（状況一覧の通年確認を潰すため）。

| 要素 | 期間外 |
|------|--------|
| 棚卸タブ自体 | **表示する**（開ける） |
| 期間ラベル | 「現在は棚卸期間外」を明示（年次参考ラベル併記） |
| 一括棚卸・未棚卸・個別棚卸入口 | **非表示または disabled**（現行の period-gate と同趣旨） |
| 棚卸状況一覧 | **閲覧可**（通年） |

### 3.4 色・ビジュアル

ハブ別トーン（wrap）: 台帳 cream / 棚卸 green / 管理 amber。共通トークン `--npl-accent` 等。

禁止・回避: 紫グラデ／絵文字依存の意味付け／同格カラフルボタンの横並び。色だけに頼らずラベル必須。
