### 0.5 総括・原価行のサブゾーン（Q0-2 — 要すり合わせ）

原価行は **1 種類ではない**。2623001 の並び:

```text
[A] 材料費 …② + …③ + 「計」     ← 連携×2 + 小計グループ
[B] 修繕④ / 足場⑤ / 塗装⑥ / 直轄⑦  ← 連携・各1行（小計なし）
[C] 塗装附帯・鎌ヶ谷 等            ← 単独明細（小計なし）
[D] 管理者賃金 昼/夜 + 「計」  ×複数 ← 明細グループ + 小計
[E] 重機誘導・検電 等              ← 単独明細（保安費）
[F] レンタル 複数行 + 「計」        ← 明細グループ + 小計
[G] 運送費・経費 等                ← 単独明細（小計なし）
```

| ゾーン | いまの区切り | テキスト行の典型用途 | 要否（AI 仮説） |
|--------|-------------|---------------------|----------------|
| **A** 材料連携+計 | 1行目 `材料費` · ②③ · 計 | グループ前の **大見出し** | **低**（1行目が見出し役） |
| **B** 外注連携④〜⑦ | 各行が工種名＋緑 · 詳細表ブロックと1:1 | **注記**（例: 業者名メモ） | **低〜中**（行自体がラベル） |
| **C,G** 単独明細 | 各行が工種/種別 | ブロック間の **区切り見出し** | **中〜高** |
| **D,F** 明細+「計」 | 先頭行の工種名 + 自動小計 | グループ **前** の自由見出し · **計の直前/直後** の注記 | **要判断** |
| **D,F 内部** | 昼/夜 等の続き | グループ **途中** の見出し | **低**（行構造で足りる） |
| **「計」行そのもの** | 自動集計 | テキスト行に **しない** | **× 対象外** |

**技術メモ**: 小計グループ（`cost_group_key`）の **途中** にテキスト行を入れると、`計` の集計対象・差分キー・Excel 罫線ルールへの影響あり → **入れるならグループ外（前）か、集計スキップを明示**。

**Q0-2**（浜田）: 上表のうち、テキスト行を **入れたい / 要らない** ゾーンはどれか？  
（例: `C,G,F前=要, A,B=不要, D内部=不要, 計=対象外`）

### 4.1 追加操作

| 操作 | 挙動 |
|------|------|
| ⋮ → **上に1行追加** | 従来どおり **通常行**（data） |
| ⋮ → **下に1行追加** | 従来どおり **通常行**（data） |
| ⋮ → **上にテキスト行を追加** | **label 行**を当該行の**上**に挿入 |
| ⋮ → **下にテキスト行を追加** | **label 行**を当該行の**下**に挿入 |
| 見出し「＋ 末尾に追加」 | 従来どおり **通常行**（変更なし） |

### 4.2 表示

- **label 行**: **仕様列**（見出し・**太字**）＋**備考列**（補足・通常字体）のみ入力可。単位/数量/単価/金額は **—** 表示・入力不可。罫線は通常行と同じ
- **削除**: ⋮ メニュー「行を削除」は label も可
- **readOnly / 版ロック**: 現行同等（操作列非表示）

### 4.4 バリデーション（Q4=A）

- label 行は **仕様列（見出し）必須** — 空のまま保存不可（アラート）
- **備考のみ**の label 行は不可（見出しとして意味がないため）
- 通常行（data）のバリデーションは現行どおり

### 4.3 計算

```text
sumSpecLines: spec_row_kind === 'label' → spec_amount = 0, 合計加算スキップ
recalcAll: label 行は qty×price 計算しない
```
