## §1. 背景・目的

### 1.1 背景

- 東海支店系 iPad を Excel で管理。kintone 化したい。
- UI は 721 イメージ。項目は異なる。M365／VPN も載せたい。
- **tokai** と **admin** のみ本台帳を利用。**tokai に PC台帳 674・社員マスタ 595 の画面アクセスは付けない**。

### 1.2 目的

1. Excel 相当の台帳を kintone に置き、日常操作は Dash のみ。
2. 新規端末名 `tokai`＋連番の自動採番（廃棄後は欠番）。
3. 保存時に裏側 API で 595／674 から必要情報をコピー（Lookup 不使用）。
4. Excel 出力・印刷（一覧／ユーザー単位）。印刷は 721 型 A4・端末別。

### 1.3 スコープ

| 含む | 含まない |
|------|----------|
| Space 32・DB＋Dash・25 台移行 | JR 720/721 の改修 |
| tokai 編集（追加・所属変更・廃棄） | Lookup フィールドによる 595/674 直結 |
| 有効／廃棄トグル | 有償プラグイン |
| M365/VPN（ID・PW）同期・グレーアウト | tokai への 595/674 権限付与 |

### 1.4 管理対象拠点（5）

東海支店／東京営業所／静岡営業所／名古屋営業所／関西営業所

## §3. 他台帳との境界・同期

| 対象 | 役割 | 本台帳との関係 |
|------|------|----------------|
| **社員マスタ 595** | 所属・利用者の正本 | Dash 検索・保存時コピー（**裏側 API**）。tokai は画面不可 |
| **PC台帳 674** | M365 / VPN の正本 | 保存時に氏名キーで `m365_id`/`m365_pw`/`vpn_id`/`vpn_pw` をコピー。tokai は画面不可 |
| **JR iPad 720/721** | 別ドメイン | **触らない** |

### 3.1 同期タイミング

- **保存ボタン押下時**（Dash → 同期経路 → DB 更新）。
- M365／VPN 欄は **グレーアウト・手入力不可**（同期結果のみ表示）。

### 3.2 紐づけキー

- **氏名（利用者）**。
- 同姓同名はほぼ無い前提。発生時は **浜田に事前相談**（自動推定しない）。

### 3.2a 674 複数ヒット時の判定

氏名一致が複数でも、**廃棄／取消は現行ではない**と AI チームが判断してよい。

| 順 | ルール |
|----|--------|
| 1 | `pc_status` が **廃棄** または **取消** の行は除外 |
| 2 | 残りに **利用中** があれば **利用中のみ**に絞る |
| 3 | 候補が **1 件** → 自動採用（`pc_ledger_record_id` もその `$id`） |
| 4 | 候補が **0 件** → NO_HIT（空保存は確認ダイアログ） |
| 5 | 候補が **2 件以上**（例: 利用中が2台）→ **MULTI_HIT・浜田相談**（自動採用しない） |

正本実装: `scripts/lib/tokai-ipad-kintone.mjs` の `resolvePcLedgerCredentialHits`（CLI・中継・Dash 共通）。

### 3.3 検索 UX

- 所属・利用者は **検索で入力**（裏側 API が 595 を検索し候補表示）。

### 3.4 同期経路（実装）

| ログイン | 経路 |
|----------|------|
| **admin** | Dash から `kintone.api` で 595/674 を直接参照（中継不要） |
| **tokai** | ローカル中継 `http://127.0.0.1:17969`（管理者トークンはブラウザに埋め込まない） |

- 中継: `scripts/tokai-ipad-sync-relay.mjs` / `npm run tokai-ipad:sync-relay`
- Runbook: `docs/runbooks/tokai-ipad-sync-relay.md`
- 一括同期 CLI: `npm run tokai-ipad:sync-credentials:dry-run` / `:apply`

## §10. 裏側 API（保存時同期）

1. Dash 保存 → admin は `kintone.api`、tokai は **中継**（管理者トークン）。  
2. `user_name` で **595** を検索 → `location` / `user_name` を確定（検索選択済みなら ID 優先）。  
3. 同氏名で **674** を検索 → §3.2a で候補解決 → `m365_id` / `m365_pw` / `vpn_id` / `vpn_pw` をコピー。  
4. NO_HIT → 空保存は確認ダイアログ。MULTI_HIT → エラー表示・**浜田相談**。  
5. ブラウザに 595/674 の **管理者トークンを埋め込まない**。
