## §0. 背景・目的

### 0.1 背景

- 共有 PC への有料ソフト導入案件が発生した。
- 現行 v1 は **利用者（595）のみ** で **どの PC にインストールしたか** を記録できない。
- 親 SPEC §11「674 参照は v2」は **本追補で v1.2 として前倒し**（参照のみ・674 customize は触らない）。

### 0.2 目的

1. **種別（個人 / 共有）** で登録フローを分岐する。
2. **1 レコード = 1 ソフト割当 = 1 PC**（同一製品を 2 台に入れた場合は **2 レコード**）。
3. **個人**: 595 社員選択 → **674 からその社員の PC を引く**（1 台なら自動、2 台以上は選択）。
4. **共有**: **674 から共有 PC を選択** — 担当者名は **フリー入力**（595 必須にしない）。
5. **PC 0 台**（674 未登録）での保存は **不可**（浜田確定 2026-08-19）。

**674 customize / フィールド定義の変更は本案件のスコープ外。**

### 3.2 674 クエリ条件

**共通（稼働 PC のみ — ソフト設置対象）**

```
pc_status not in ("廃棄", "取消", "保管")
```

- **保管** PC は設置先候補から **除外**（674 の `pc_status=保管` は稼働外）。
- 674 側に想定外の `pc_status` 値があれば **採番対象外（廃棄同等）** として扱わない。

**個人（595 選択後）**

```
account_type in ("個人")
and emp_id = "{595.emp_id}"
and pc_status not in ("廃棄", "取消", "保管")
```

- これに加え、674 の `emp_id` が空でも拾う: **595.mail 一致**、および 595 `pc_ledger_v1_list.pc_674_record_id`。`$id` でマージ。廃棄・取消・保管は除外。
- `emp_id` / `mail` は **文字列比較**（数値化しない）。
- 0 件 → **保存不可**（§5.2）。
- 1 件 → **自動セット**（確認表示）。
- 2 件以上 → **ユーザーが 1 台選択**（ラジオまたはドロップダウン）。

**共有（共有 PC ピッカー）**

```
account_type in ("共有")
and pc_status not in ("廃棄", "取消", "保管")
```

- キーワード検索: `pc_name` / `shared_terminal_name` 部分一致可。
- 0 件選択 → **保存不可**。

### 3.3 674 から 715 へコピーする項目

| 674 フィールド | 715 フィールド | 備考 |
|----------------|----------------|------|
| `$id` | `pc_674_id` | 数値 |
| `pc_name` | `pc_name` | 一覧・検索用ミラー |
| `shared_terminal_name` | `shared_terminal_name` | 共有時表示用 |
| `dept_name` | 共有: `contact_dept` 初期値 | 手修正可 |
| `group_name` | （v1.2 では保存しない） | 必要なら v1.3 |

## §5. バリデーション

### 5.1 共通

- `install_target` 未選択 → エラー。
- `pc_674_id` / `pc_name` 空 → **エラー**（保存不可）。
- ソフト情報（製品名・識別1 等）は **現行 v1 どおり**。

### 5.2 個人

| 条件 | 動作 |
|------|------|
| 595 未選択 | エラー |
| 674 が **0 台** | **エラー** — 「PC台帳に該当 PC がありません。先に PC 台帳（674）へ登録してください。」 |
| 674 が **1 台** | **自動セット**（変更可: 再検索のみ） |
| 674 が **2 台以上** | **1 台選択必須**（未選択で保存不可） |

### 5.3 共有

| 条件 | 動作 |
|------|------|
| 共有 PC 未選択 | エラー |
| `contact_name` 空 | **エラー**（担当者名必須） |
| `emp_id` / `user_name` に値あり | **保存前にクリア**（共有行では 595 フィールドを使わない） |

### 5.4 既存 v1 レコード（移行）

| 条件 | ルール |
|------|--------|
| **一覧表示** | `pc_674_id` 空の **旧レコードも表示可**（後方互換） |
| **新規登録** | §5.1〜5.3 どおり **PC 必須** |
| **編集保存** | **PC 必須**（旧レコード初回編集時に PC を付与） |
| **595 退職者行** | §6.4 どおり非表示（個人・pc 空含む） |

### 5.5 種別変更時（編集モーダル）

| 変更 | 動作 |
|------|------|
| 個人 → 共有 | `emp_id` / `user_name` / `dept_name` / `group_name` を **クリア**。PC 選択を **リセット**（共有 PC を再選択） |
| 共有 → 個人 | `contact_name` / `contact_dept` を **クリア**。PC 選択を **リセット**（595 → 674 再照会） |

## §6. UI 要件（715 customize）

### 6.1 新規・編集モーダル

```
種別: (●) 個人  ( ) 共有

── 個人 ──
[ 社員を選ぶ (595) ]
  → 氏名・所属表示
  → 674 自動照会
     0台: エラー表示・保存不可
     1台: PC名を自動表示（読取専用）
     2台+: [ PCを選ぶ ▼ ] ラジオ/ドロップダウン

── 共有 ──
[ 共有PCを選ぶ (674) ]  ← キーワード検索可
  → PC名・共有端末名・所属表示
担当者名: [____________]  （必須・フリー入力）
担当所属: [____________]  （674 dept 初期値・編集可）
```

### 6.2 一覧表

**列追加**（操作列の前あたり）:

- `install_target`（種別）
- `pc_name`（PC名）

**利用者列の表示**

| 種別 | 表示 |
|------|------|
| 個人 | `user_name` |
| 共有 | `contact_name`（ラベル **担当者**） |

### 6.3 検索・フィルタ

- キーワード横断に **`pc_name`** を追加。
- 種別フィルタ（個人 / 共有 / すべて）は **v1.2 推奨**（必須ではない）。

### 6.4 リスト一覧作成・印刷（§9.5 拡張）

- 結果表に **種別**・**PC名** 列を追加。
- 社員別印刷: **個人行のみ**（従来どおり `emp_id` 基準）。
- **PC別リスト**（共有向け）は v1.3 検討 — v1.2 ではキーワード `pc_name` で代替。

### 6.5 複製（推奨）

- 行操作または編集モーダルに **「別 PC へ複製」**:
  - 製品・識別・ライセンス種別・備考をコピー。
  - **PC だけ未選択**にして新規 POST 画面を開く。
  - 個人: 595 は維持 → 別 PC 選択。
  - 共有: 担当者・共有 PC を再指定。
