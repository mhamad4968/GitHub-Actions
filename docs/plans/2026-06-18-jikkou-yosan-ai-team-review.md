## 4. 印刷仕様突合（2026-06-20）

**親**: [`2026-06-18-jikkou-yosan-spec.md` §9.7](2026-06-18-jikkou-yosan-spec.md)

| 手段 | 内容 |
|------|------|
| Sequential Thinking | 688 portal パターン・〃 変換・calc 整合 |
| Excel 書式.xls | シート **総括表** / **詳細表**（69×46 / 72×49）— タブ別印刷と一致 |

### 4.1 総評

| 区分 | 評価 |
|------|------|
| 実装可能性 | **問題なし** — 688 と同型で kintone customize 範囲内 |
| 計算正確性 | **要遵守** — 印刷 HTML は **state クローン不可**。`recalcState` 後に **専用 renderer** |
| 〃 表示 | **妥当** — 画面空白と印刷〃の二系統は Excel 帳票慣行と一致 |
| リスク | **横長表** — A4 横・列幅調整と改ページの **目視必須** |

### 4.2 推奨（実装時）

1. 画面 DOM の `cloneNode` は **使わない**（input 空白・〃 が崩れる）
2. 印刷ボタン押下時に **未保存なら保存促す** または **印刷時点の state を印刷**（どちらかを仕様化 — 推奨: **印刷時点の画面 state**、未保存警告は出さないが dirty のまま印刷可）
3. `afterprint` で portal クリア（688 同型）
