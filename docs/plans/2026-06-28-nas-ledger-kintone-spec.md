## §1. 背景・目的

### 1.1 背景

- 社内各拠点の **NAS** 情報を **Excel 1 シート**で管理している。
- 管理コンソール接続情報（IP・ID/PW）を当部署が保守する。
- NAS 未配置拠点も **一覧上で「設備なし」** として可視化したい。

### 1.2 目的

1. Excel と同等の情報を kintone に置き、**日常操作は台帳**で行う。
2. **キーワード検索**・**組織/状態/種別絞込**・**一覧印刷**・**xlsx 出力**をダッシュから行う。
3. 移行・目視 OK 後は **Excel 表を削除**し、kintone のみ正本とする。

### 1.3 スコープ外（v1）

| 項目 | 理由 |
|------|------|
| **Space 48 ポータル 712 へのリンク追加** | **済**（2026-06-28 浜田手動） |
| **複合機 / PC / Wi-Fi 台帳との自動連携** | v1 独立台帳 |
| **SNMP / 死活監視** | 台帳化のみ |
| **九州支店（閉店済）** | Excel から除外済・移行しない |
| **有償 kintone プラグイン** | 使用しない |

## §6. 組織・拠点・並び順

### 6.1 組織名・拠点名・設置先

| フィールド | 入力 |
|------------|------|
| **組織名** | `nas-org-sort-master.json` から選択 + 自由入力禁止は **v1 ではしない**（マスタ外は移行値をそのまま保存） |
| **拠点名** | R68 `location_name` から選択（利用拠点） |
| **設置先** | R68 から選択（物理設置場所） |

**旧称正規化**: Excel `本店` → **本社**（組織名・拠点名・設置先すべて）。

**リフォーム**: Excel `リフォーム\n事業統括部` → **リフォーム事業統括部**。首都圏支店・札幌支店行の組織名は R26 から **引き継ぎ**。

### 6.2 Excel 引き継ぎ（移行時）

| パターン | 処理 |
|----------|------|
| 組織名空欄 | **直上のデータ行**の組織名を引き継ぎ |
| 拠点名 `〃` | **直上のデータ行**の拠点名を引き継ぎ |
| IP 2 行（改行） | **上段（本番用）のみ** 採用。下段（保守用）は捨てる |
| 種別 `予備` | **移行しない**（Excel 手直し済: 状態=保管・種別空・備考=予備（キャビネット保管中）） |

### 6.3 sort_no（デフォルト並び）

**第1キー**: 組織ブロック（NAS-R1 正本）

| 順 | 組織名 |
|----|--------|
| 1 | 本社 |
| 2 | 東北支店 |
| 3 | 関越支店 |
| 4 | 東京支店 |
| 5 | 東海支店 |
| 6 | リフォーム事業統括部 |
| 7 | 鉄構支店 |
| 8 | 湾岸工事所 |
| 9 | 子会社（株）ブリッジニアプラス |

**第2キー**: 同一組織内で **R68 拠点名 sort_no** 昇順。

**第3キー**: 同一拠点内で **Excel 行順**。

**設備なし 3 行**: 各組織ブロック内で該当拠点の **末尾**（実機が無い拠点のプレースホルダ）。

## §7. ダッシュアプリ — UI（確定）

### 7.1 一覧

| 項目 | 仕様 |
|------|------|
| レイアウト | **742/719 型** Excel 風テーブル |

| 一覧空欄 | 状態・種別・設置先・IP・メーカー・機種名・実効容量の空欄は **「－」**（全角）で表示 |
| 検索 | **キーワード**（組織・拠点・IP・ホスト名・購入先・備考等） |
| 絞込ボタン | **状態**（全/有効/保管/設備なし **－**）・**種別**（全/本番/バックアップ）・**組織名** |
| 操作 | 新規・編集・削除（Space 48 メンバー全員） |
| ID/PW | **平文表示・コピー機能なし** |

### 7.2 バリデーション

| 条件 | 必須 |
|------|------|
| **状態 = 有効** | 組織名・拠点名・設置先・種別・IP・管理者ID・パスワード |
| **状態 = 保管** | 組織名・拠点名・設置先・IP・管理者ID・パスワード（**種別は空可**） |
| **状態 = `－`（設備なし）** | 組織名・拠点名・設置先（`-` 可）・備考（`設備なし`）。**IP / 種別 / ID / PW は不要** |

| **状態 = 廃棄** | v1 移行対象外（Excel から削除済） |
| **端末情報** | メーカー・機種名・シリアル・実効容量・RAID 等は **すべて任意** |
