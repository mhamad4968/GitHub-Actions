## 5. 計算（G0 §7）

- `実績[月] = Σ 会社行のその月`（全社がその月 `null` なら実績なし。0 は実績あり）
- `採用[月] = 実績ありなら実績、なければ実績予想`（両方 `null` なら 0）
- `採用合計 = Σ 採用[4..3]`
- `残 = 現予算 − 採用合計`
- `率 = 採用合計 / 現予算`（現予算が空または0なら出さない）
- 空に戻した月の採用は実績予想へ戻す。実績がある月の実績予想は残すが採用・残に使わない。
- 回数: `採用回数[月] = 実績回数があればそれ、なければ回数予想`。`残回数 = 予定回数 − Σ 採用回数`。回数は円合計に入れない。
