## 4. 月次オペ（確定）

1. CIOが15日前後に「NISA月次」を想起し、スクショ貼付を指示  
2. 浜田が証券「資産状況」系スクショを貼る（必要ならラップ／iDeCoも）  
3. AI: ①月額・銘柄・枠 を読み取り → ③調整案は **1つだけ**（据置／増額／減額）  
4. 増額は **浜田単独で決めない** → AIチーム案＋浜田GO  
5. GO後に浜田が証券操作 → 変更時は再スクショで確認  
6. 本メモの「現状」行を更新（口座番号・生の明細は書かない）

**毎月必須にしない**: 生活防衛資金の深掘り（変化があるときだけ）

## 7. 分からないとき・AIが判断しにくいときの聞き先

AIチームは **方針の整理・選択肢の比較・質問文の下書き**まで。  
**個別の最適配分の断定・特定商品の売買指示**はしない（浜田GO＋必要なら専門家）。

| 聞きたいこと | どこに聞くか | 向く／向かない |
|--------------|--------------|----------------|
| 画面の見方・積立設定変更の操作・手数料一覧・商品説明書の事実 | **SBI証券**（チャット／電話／店頭・相談会） | 手続き・商品スペック向き |
| iDeCoの掛金変更・配分変更の手続き・移換・受取開始の制度 | **SBIベネフィット・システムズ等（iDeCo運営管理）** または SBIのiDeCo窓口案内 | 制度・手続き向き |
| 「自分の場合いくら必要か」「保険とのバランス」 | **中立寄りのFP（有料相談）** または社労士・税理士（年金・税制） | 人生設計向き。証券窓口は販売目線になりうる |
| 税制の細部（所得控除・受取時） | **税理士／税務署**（一般論は国税庁サイト） | 税の断定はAI・証券チャットに頼まない |
| 方針のたたき台・月次スクショ判定 | **AIチーム（本レーン）** | 専門家の代替にしない |

### iDeCo「2本が重なりやすい」とは（かんたん版）

- **先進国株式** ≈ 米国・欧州など（日本以外の主な先進国）  
- **全世界（除く日本）** ≈ 先進国 ＋ 新興国（中国・インドなど）  
→ 後者の中身の多くが前者と重なるので、**半分ずつでも「ほぼ同じ方向の海外株を二重に買っている」**イメージ。  
→ 悪いわけではないが、**分散の効きは見た目ほど増えない**。まとめるなら「除く日本だけ」か「先進国だけ」の1本、などが選択肢。
