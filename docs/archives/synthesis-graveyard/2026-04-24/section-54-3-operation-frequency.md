# §54-3 制定議論: コスト透明化 → Operation Frequency Management 転換

**日付**: 2026-04-24 21:01  
**Synthesis 元 commit**: (本ファイル commit 直後)  
**§54-3 候補 1 メイン AI 原案 vs Sonnet 反定立**: メイン AI 原案 (コスト推定 / Claude API price ベース) を Sonnet が「Cursor Ultra 定額モデル誤解 = フィクション」と完全否定 → 「操作頻度上限」転換で合導出 → 浜田 A 案 GO 21:01。

## 棄却された案 (反 / Sonnet 反定立 20:58 / Sonnet 直接書込相当)

### 反 1: コスト推定の中間層不要 (メイン AI 原案 / 棄却)

**棄却された案**: メイン AI が「AI が推定値を生成し浜田に提示」という中間層を提案。

**棄却理由 (Sonnet)**: 「コスト透明化は『浜田が Cursor IDE 設定画面を直接見る』だけで完結する。AI が推定値を生成するルールを制定することで、**実数値が存在するのに推定値を信じる倒錯**が生まれる。§54-3 は不要な中間層」。

### 反 2: Cursor Ultra 定額モデル誤解 = フィクション (メイン AI 原案 / 致命的盲点として棄却)

**棄却された案**: メイン AI が `input_tokens * 0.000015 + output_tokens * 0.000075 * 150` という Claude API price ベースの推定算出式を提案。

**棄却理由 (Sonnet / 致命的盲点指摘)**: 「**Cursor Ultra ($200/月) は定額サブスクリプションであり、トークン従量課金ではない。** 推定算出式は **Claude API の価格表** であって Cursor Ultra の課金体系と無関係。$400 クレジットも Cursor の API 枠の別概念。「Task tool 1 回 ≈ 5-15¢」の根拠も存在しない。**草案全体が架空のコストモデルの上に立っている**」。

### 反 3: §52-3 v3 Q6 と二重トリップワイヤー (メイン AI 原案 / 棄却)

**棄却された案**: メイン AI が「100% 緊急停止」を §52-3 v3 Q6 と独立に動かす想定。

**棄却理由 (Sonnet)**: 「§52-3 v3 Q6 の『スコープ外即停止』と §54-3 ルール 5『100% 緊急停止』が二重トリップワイヤーになる。推定誤差 ±20% を許容しながら『100% 到達で Tier A 自動停止』は矛盾 — 80% 実消費でも推定値 100% が発火し得る。§53-7-G-1 馴れ合い禁止の精神で言えば、AI 自身が自分のコストを申告する構造は **自己採点の甘さ** を制度化するリスク」。

### 反 4: 4/25 朝 Day 3 破綻シナリオ 3 件 (メイン AI 原案 / 棄却)

**棄却された案**: メイン AI が「cost-aggregator.mjs が Task tool 起動回数をカウント」と提案。

**棄却理由 (Sonnet 3 シナリオ)**:
- ケース A: cost-aggregator が空データ集計 → 毎日 ¥0 と報告し続け警告永遠に発火しない (Cursor 内に該当 API 不在)
- ケース B: 推定値が実数値と 50% 超乖離 → 浜田が「どの数字を信じるか」毎回裁定 = 透明化の逆効果
- ケース C: 月次レポート生成自体が Task tool を消費 = コスト管理のためのコストが計測不能ループ

### 反 5: 代替案 = 操作頻度上限 + 浜田直接確認 (Sonnet 提案 / 全面採用 = 合に統合)

**Sonnet 提案 (極端な逆視点)**: 「コスト管理を捨て『操作頻度上限』に置換する — 例『Task tool 1 日 20 回上限 / 超過で浜田承認待ち』。定額プランでは『コスト』より『過剰操作による品質劣化』が真のリスクであり、頻度上限は計測可能・透明・API 不要。コスト把握は浜田が月次で Cursor 設定画面を確認する 1 行の運用手順に落とし込む」。

**全面採用 (合に統合)**: メイン AI 原案 (コスト推定) を全廃 + Sonnet 案 (頻度上限 + 浜田直接確認) を全面採用 / ルール名も「Cost Transparency」 → 「**Operation Frequency Management**」に改名 (実態反映)。

## 合 (採用された Synthesis = §54-3)
