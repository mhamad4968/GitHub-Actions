# 社内 FAQ ポータル（使い方メモ）— 経理部の皆さま向け

このページは、パソコンに保存されている **HTML ファイル 1 つ**をブラウザで開いて使います。インターネットに出さなくても動きます（※「URL取得」機能だけは別の説明があります）。

---

## 1. 起動のしかた

1. 配布されている **`faq-portal-full.html`** をダブルクリックするか、ブラウザにドラッグして開きます。  
2. 左にメニュー、右に検索と FAQ の一覧が表示されれば成功です。

**大切なこと**  
- データは **お使いのブラウザの中（自動保存）** に記録されます。  
- **別の PC** や **別のブラウザ** では、最初からの状態になることがあります。  
- 共有したいときは、定期的に **「ファイルに保存」（バックアップ）** を取ってください（後述）。

---

## 2. 画面の見かた

| 場所 | 何ができるか |
|------|----------------|
| **左のメニュー** | カテゴリーを選ぶと、その分類の FAQ だけが右に表示されます。「🏠 すべて表示」ですべて見られます。 |
| **検索** | キーワードで質問・回答・カテゴリー名を探します。ひらがな・カタカナは同じものとして探します。 |
| **公開状態** | 「すべて」「公開のみ」「下書き」— 未完成の下書きだけ見たいときは「下書き」です。 |
| **並び** | 「更新日が新しい順」など、表示の順番を変えられます。 |

FAQ の行をクリックすると、**質問の下に回答が開きます**。もう一度クリックすると閉じます。

---

## 3. 新しい FAQ を書く（投稿）

1. ページの下の方にある **「📝 新規FAQ投稿」** を探します。  
2. 次を入力します。  
   - **カテゴリー** … プルダウンから選びます。  
   - **重要マーク** … 早く目立たせたいときにチェックします。  
   - **公開する** … **チェックを外すと「下書き」** になります（社員には見せず自分だけ向けの下書きとして使えます）。  
   - **質問** … いつもの聞き方で。  
   - **回答** … 本文です（下の「ちょっとだけ便利な書き方」を参照）。  
3. **「保存」** を押すと一覧で見えるようになります。

### ちょっとだけ便利な書き方（回答の中）

- **太字** … `**ここを太字**` のように書くと太字になります。  
- **箇条書き** … 行のはじめに `-` または `*` とスペース（例: `- 交通費`）。  
- **番号付き** … 行のはじめに `1.` とスペース（例: `1. 手順一`）。  
- **リンク** … `https://...` と書くと、クリックできるリンクになります。

---

## 4. 直したい・消したいとき

- FAQ を開いたあと、回答の下の **「✎ 編集」** で内容を変えられます。  
- **「× 削除」** でその FAQ を消せます（消す前に確認が出ます）。

---

## 5. PIN（暗証番号）がかかっている場合

担当者が **編集用 PIN** を設定していることがあります。

- **編集・削除・インポート・URL取得・カテゴリーの追加・変更** などの前に、左下の **「🔓 編集ロックを解除」** で PIN を入力します。  
- 解除できた状態は **しばらく続きます**（ブラウザやタブを閉じると、もう一度入力が必要な場合があります）。  
- PIN を知らないときは **情シスやポータル管理者** に確認してください。  
- **PIN を設定・変更できる人**は **「PIN を設定・変更」** ボタンから行います（平時は管理者向けです）。

※ PIN は厳密なセキュリティ用途ではなく、**誤操作や勝手な変更を減らすための簡易ロック**です。

---

## 6. バックアップ（ファイルに保存）と復元

### バックアップを取る

1. 左の下の方 **「ファイルに保存」** を押します。  
2. パソコンに **`faq-backup-日付.json`** のようなファイルがダウンロードされます。  
3. このファイルを **共有ドライブや安全な場所** に保管してください。

### 復元する（貼り付けインポート）

1. **「インポート」** を押します。  
2. バックアップファイルをメモ帳などで開き、**中身をすべてコピー**して貼り付けます。  
3. 確認のダイアログで **OK** すると、今のデータが **上書き** されます。  
   - **古いバックアップで上書きしないか**、必ず確認してから OK してください。

### 「URL取得」って何？

**インターネット上に置いてある JSON ファイル**の住所（URL）が分かっているときだけ、ワンクリックで同じ内容を取り込めます。  
会社の普通のフォルダや、kintone の画面の URL は **使えません**（技術的な制限）。  
**普段は「ファイルに保存」と「インポート」で十分**です。

---

## 7. そのほか便利な機能

| 機能 | 説明 |
|------|------|
| **テーマ** | 左の **☀ ライト／🌙 ダーク／🖥 自動** で画面の明るさの見た目を変えられます。 |
| **印刷** | ブラウザの「印刷」で FAQ を紙や PDF にできます（メニューは印刷時に入らないようになっています）。 |
| **カテゴリーの名前** | 左メニューの **✎ や ＋** で変更できます（PIN がかかっている場合は解除が必要です）。 |

---

## 8. 困ったとき

- **検索に出てこない** … 「公開状態」が「公開のみ」になっていて、下書きだけが該当していませんか。  
- **別の PC では真っさら** … データはブラウザごとです。**バックアップ JSON をインポート**してください。  
- **急に消えた** … ブラウザの「閲覧データ削除」で消えた可能性があります。バックアップからの復旧を試してください。

技術的な問い合わせは **情シス／管理者** にお願いします。
