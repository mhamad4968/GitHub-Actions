## 反省点（再発防止）

1. **一覧キャッシュとモーダル GET の二系統** — 行操作は常に **レコード id + 安定行 id** で再取得してから PUT（今回の教訓を TSB-036 系に集約）。
2. **ロールアップは「上書き」では「再構築」** — 支払から作る月次表は **対象外の月を空にする** まで含めて仕様化しないと孤児が残る。
3. **UI 用フィールドとレコード全体フィールドの混同** — `notes` と `payment_memo` の用途分離を SPEC に 1 行追記推奨。
4. **Excel コピーは表示形式が要件** — 数値 TSV だけでは不十分。**円・％は最初から要件確認**すると手戻りが減る。
5. **677 取得件数上限（500）** — 工種コード集計は画面上の一覧ベース。件数超過時の挙動は **未検証・要明文化**。
