### 列構成（ご要望どおり＋利用者列を追加）

| # | 列名 | 内容 |
|---|---|---|
| 1 | **PC名（キー）** | 594 の `PC_name` または `shared_terminal_name`（PC名なしは灰色表示）。クリックで該当 594 レコードへ |
| 2 | **利用者** | 594 の `user_name` |
| 3 | **紐付くWindowsID（行ごと）** | 627 から逆引き。`logon_name`（クリックで 627 レコードへ）／利用者名／account_type を行毎に表示。在籍ステータス(休職⏸／退職🪦)アイコン付き |
| 4 | **フラグ** | ✅ 正常 / 🟠 重複あり / 🟡 紐付けなし、＋紐付き件数 |
| 5 | **備考** | 種別／所属／ledger_record_id 異常／重複理由（同一WindowsIDが他PCで使われている場合は他レコードへの直リンク） |

### フラグ判定ロジック（2026-04-18 ユーザー指摘で 2 度修正）

```
🟡 NO_LINK : このPCに紐付く 627 アカウントが 0 件
             （ただし種別が「サーバーNAS」「その他」は除外）
🟠 DUP    : このPCに 2 件以上のアカウントが紐付いている
✅ OK      : それ以外（=紐付け 1 件以上、または対象外種別）
```

**除外ルール**:
- 同一WindowsID(logon_name) が他PCでも使われている場合は、フラグには影響させず備考欄に「ℹ 参考情報」として表示
- 種別が「サーバーNAS」「その他」のPCは、アカウント設定対象外のため 0 件でも 🟡 紐付けなし に含めず ✅ 正常 に算入。備考に「⚪ アカウント設定対象外（種別名）」と注記
- "ローカルアカウント"/空 は最初から除外

### UI 機能

- **絞込フィルタ**: PC名 / 利用者 / 部署・グループ / 種別ドロップダウン
- **フラグでON/OFF**: ✅ 🟠 🟡 のチェックボックスで切替
- **CSVダウンロード**: BOM付きUTF-8 で全列出力（Excel直接OK）
- **集計バナー**: 上部に色分けで「合計／正常／重複あり／紐付けなし」件数表示
- **専用ヘッダ**: 黒～紺のグラデで「ダッシュボード」感を演出（通常台帳と区別）
