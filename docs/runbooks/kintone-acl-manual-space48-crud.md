# kintone ACL 手動設定 — Space 48 メンバー CRUD

**承認**: RB-741-02（2026-06-22 浜田 GO）  
**契機**: 新規 app 作成スクリプトで `CB_NO04 No user has application management right` が出た場合

---

## 対象

Space 48 / thread 52 の **DB+Dash 型**台帳（734 型権限 — Space メンバー全員 CRUD）。

| 例 | App ID |
|----|--------|
| 複合機管理台帳DB | 741 |
| 複合機管理台帳 | 742 |

---

## 手順（kintone 管理画面）

1. **設定** → **アプリ** → 対象アプリを開く
2. **アプリの設定** → **アクセス権**
3. **Space 48**（または該当スペース）の **メンバー** に以下を付与:
   - レコード閲覧: **すべて**
   - レコード追加: **すべて**
   - レコード編集: **すべて**
   - レコード削除: **すべて**
4. **DB アプリ（741 等）**: 閲覧は全員可でも可。追加・編集・削除は **REST のみ**（customize で UI ブロック）— ACL は Dash と揃えておく（移行スクリプト・admin REST 用）
5. **保存** → **アプリを更新**（deploy）

---

## 確認

- Space 48 メンバーアカウントで 742 台帳を開き、新規・編集・削除ができること
- 741 DB 標準 UI から save/delete が **ブロック**されること（customize）

---

## スクリプト側

`setEveryoneAcl()` 失敗時は **警告のみで続行**（create スクリプト）。**手動 ACL は v1 リリース必須チェック**（`db-dash-v1-launch.md` §6）。
