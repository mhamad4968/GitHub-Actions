# 夕反省（evening-reflection）のスコープ

**制定**: 2026-05-30（浜田）  
**改定**: 2026-06-02（浜田）— **締め時のチャット返答も本スコープに限定**

## 書くもの（このファイルだけ）

1. **AI の失敗・反省**（事実ベース。言い訳ではなく再発原因）
2. **ミスが減るアップデート案**（ルール・手順・スクリプト・runbook 等）— **本日の作業から導いた改善のみ**
3. **承認済み／承認待ち**の改善案 ID

## 書かないもの（別ファイルへ）

| 内容 | 正本 |
|------|------|
| 本日の成果・deploy 結果・検収 | `19-SESSION-ONE-REPORT-YYYY-MM-DD.md` |
| クローズ・触らない・凍結 | `25-checkpoint-latest.md` 先頭 |
| **明日やること・第1手・レーン・スケジュール** | **書かない**（当日 **項番 -0** で決める） |
| タスク計画・優先順位案 | 朝イチ合意 |
| git 差分の羅列 | 雛形 §1 自動収集で足りる |

## 締め時チャット返答（2026-06-02 浜田 / **2026-06-13 R26 追補**）

セッション締めで浜田に出す要約は **次の 2 ブロックのみ**:

1. **失敗（事実）** — 表形式可
2. **改善案（ミス削減）** — ID 付き。承認済みなら GO 記録

**出さない**: 明日の作業一覧・「6/3 は ○○」・推奨 GO のスケジュール・第1手・レーン宣言の提案。

### R26 — スコープ分離（2026-06-13 浜田 GO）

| チャットの種類 | 書いてよい | 混ぜ禁止 |
|----------------|------------|----------|
| 夕反省 / 改善案承認 | 失敗・R ID・GO 記録 | **明日やること**・台帳 GO タイミング |

| 障害説明 | 切り分け 1 原因（R32 runbook 後） | handoff と壁時計の同時推測 |

正本: `.cursor/rules/session-close-execute-first.mdc`

## AI の手順

1. **R1**: 26 作成前に **必ず Read** — 本ファイル
2. `npm run evening:reflect` で雛形生成（任意）
3. **失敗**と **改善提案（ミス削減）** だけを仕上げる
4. **§「明日へ」は使わない**
5. **R2**: checkpoint「クローズ」項目を 26 に再掲しない
6. **R3**: 「明日の第1手」「タスク計画」「日程 GO」を 26 にも **チャットにも書かない**
7. 仕上げ後: `npm run verify:evening-reflection-scope`
8. 承認後 → runbook / rules / scripts へ反映（**実装タイミングは別途**）
