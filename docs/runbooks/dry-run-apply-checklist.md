# dry-run → apply チェックリスト（一括操作）

## 目的

本番の **一括更新・バックフィル・矯正スクリプト** を誤爆しないため、**毎回同じ順**で確認する。

## 手順（最小）

1. **`--dry-run` を先に実行**（`npm run …:dry-run` または `node … --dry-run`）。
2. **ログに残す**: `tmp/` またはスクリプト既定のログへ **標準出力をリダイレクト**し、**件数・更新予定・スキップ理由の1行サマリ**をチャットにも貼る。
3. **浜田 GO**（データ破壊・大量件数・仕様判断が絡むときは **§41 一問**）。
4. **`--apply` 実行**。
5. **再 dry-run または件数確認**で **冪等性**（2 回目が 0 件更新になる等）を確認できるなら実施。

## 受け入れ（検索・絞り込みを含むタスク）

- **「部分一致」の定義**: kintone クエリの `like` / ブラウザ内 `indexOf` / 完全一致のどれを正とするかを **Acceptance に1行**書く。
