📌 これは何？

個人のパソコンに Windowsのログイン名 と Microsoft 365のアカウント を
ボタンを1回押すだけで自動で作る仕組みです。

ボタン1回 → 3アプリ同時更新

ボタンを押すと、3つのアプリが一度に更新されます：
PC管理台帳（594）・社員マスタ（595）・個人採番マスタ（626）

📋 やり方はたった3ステップ 所要 30秒 2026-04-19 改修

  1. PC管理台帳（594）で、アカウントを作りたいパソコンのレコード（データ）を開く
  2. 画面上部にある
    🔗 個人アカウント紐付け
    ボタンをクリック → モーダル（小窓）が開きます
  3. 下記いずれかを選ぶ → 「✅ アカウントを紐付けました」と出たら成功 🎉
    選び方使うとき
    🔍 検索 → 既存選択このユーザーに既にアカウントがある（PC 引き継ぎ・2 台目の追加など）
    ＋ 新規アカウント作成このユーザーのアカウントがまだ無い（新人など）
💡 旧「アカウント管理台帳(627) 作成/更新して開く」ボタンは廃止されました。
新しいモーダル方式は番号の手入力が不要になり、誤入力事故を防げます。

🔗 紐付けモーダルの使い方 NEW

A. 既存アカウントに紐付ける場合

  1. 検索欄にログオン名 / 氏名 / メール / 部署のいずれかを入力 → 検索ボタン
  2. 結果テーブルで対象アカウントを探す。各行の右端に紐付け数バッジが表示されます
    バッジ意味
    0 / 2まだ 1 台も紐付いていない（自由に追加可能）
    1 / 2既に 1 台と紐付け中（あと 1 台追加可能）
    2 / 2上限到達（追加するには既存の解除が必要）
  3. 「選択」ボタンを押す → ✅ 紐付け完了

B. 新規アカウントを作成する場合

  1. モーダル下部の「＋ 新規アカウント作成」緑ボタンを押す
  2. 確認ダイアログ「採番プールから番号を取得し、メール XXX で新しい個人アカウントを作成します」→ OK
  3. ✅ 完了。3 つのアプリ（627 / 594 / 626）が同時に更新されます
⚠️ 新規作成にはメール（mail）が必須です。PC 台帳の mail が空ならボタン押下時にブロックされます。先に mail を入力してから再実行してください。

📌 1 ユーザー = 個人 PC 最大 2 台ルール

📋 規定: 1 個人アカウント = 1 ユーザー / 1 ユーザーは個人 PC 最大 2 台まで（会社用 + 持ち出し用）。
既に 2 台と紐付いてる個人アカウントを選んでも、エラーで止まります。
エラーメッセージに既存紐付け先の PC 名が表示されるので、不要な紐付けを解除してから再実行してください。

⚠ 利用者名が一致しないと警告が出ます

⚠️ 選んだアカウントの所有者名と、PC 台帳の利用者名が違うとき、判断材料付きの確認ダイアログが出ます。
1. 表記揺れ（フルネーム / 通称名 / 旧姓） → そのまま OK
2. 入力ミス → キャンセルして PC 台帳側を修正してから再実行
3. 代理設定 / 貸し出し中 → そのまま OK

🛡️ 重複チェッカー NEW 自動

2026-04-16 から、アカウント台帳(627)を 新規作成・編集して保存する瞬間 に、システムが自動で重複チェックを行うようになりました。

チェックする項目

項目内容
メール同じメールアドレスのアカウントが既にないか
WindowsID（ログオン名）同じログオン名が既に使われていないか
EMP-ID同じ社員番号のアカウントが既にないか（フィールドがある場合のみ）
⚠️ 重複が見つかった場合は、保存できません。
エラーメッセージに「どの項目が」「どのレコード(ID)と」重複しているかが表示されます。

既存の重複は警告バナーで表示

📛 すでに登録済みのレコードを開いたとき、もし重複があれば赤いバナーが表示されます。
バナーには重複先のレコードIDがリンクで載っているので、すぐに確認・修正できます。
✅ 編集中の自分のレコードは重複対象から自動で除外されます。
「同じレコードを編集して保存」しただけでエラーになることはありません。

🆘 困ったとき

🤔 「採番に空きがありません」と出た
→ 管理者に連絡。アカウント採番(626)に未使用レコードを追加してもらう。
🤔 「すでに紐付け済みです」と出た
→ そのPCは登録完了済み。もう何もしなくてOK。
🤔 「重複が見つかりました」と出て保存できない
→ エラーメッセージのレコードIDを開いて、本当に同じ人かを確認。
同じ人なら片方を「退職」にする。違う人なら、メール・WindowsID・EMP-IDのいずれかを正しい値に修正してください。
❌ エラーが出た
→ データは自動で元に戻ります。管理者にエラーのSTEP番号を伝えてください。

❓ よくある質問

Q. 「🔗 個人アカウント紐付け」ボタンが見当たらない
ボタンが表示されるのは 個人PCの詳細画面 です。
・種別が「共有」「JR端末」などになっていませんか？ → 個人に変更（共有は「🔗 共有アカウント紐付け」ボタンが出ます）
・画面のリロード（Shift+F5）を試してください
・既にアカウント紐付け済みでも、2 台目追加のためにボタンは常に表示されます
Q. 「規定上限の 2 台に達しています」と出た
1 個人アカウントは最大 2 PC（会社用 + 持ち出し用）までという規定です。
エラーメッセージに既存紐付け先の PC 名が表示されているので、
1. 不要な PC の詳細を開く
2. 「594⇔627 紐付け解除」ボタン（既存）で解除
3. 元のモーダルに戻り再度「選択」
の手順で進めてください。
Q. 利用者名が違う警告が出るが本人を選びたい
表記揺れ（フルネーム / 通称名 / 旧姓）や代理設定 / 貸し出し中なら「OK」を押して進めてください。
入力ミスの可能性があるなら「キャンセル」して PC 台帳側で利用者名を修正してから再実行が安全です。
Q. 自動登録した後にメールアドレスを変えたい
まず社員マスタ(595)で正しいメールに修正してください。
その後アカウント台帳(627)のレコードを編集して保存します。
新機能の重複チェックで、変更後のメールが他の人と被っていないか自動で確認されます。
Q. パスワードを変えたい
アカウント台帳(627)のレコードを開き、パスワード欄を編集して保存してください。
初期パスワードは採番アプリから自動コピーされていますが、変更しても問題ありません。
Q. 採番(626)プールがゼロになりそう
管理者へ連絡してください。空き在庫が10件を切ると一覧画面に警告が出ます。
新しい未使用レコードを追加すれば、すぐにまた自動登録ができるようになります。
Q. 退職した人のアカウントはどうなる？
社員マスタ(595)で退職日を入れて保存すると、
アカウント台帳(627)のアカウント状態が 自動で「退職」 になります。
手動で操作する必要はありません。詳しくは 異動・退職・買替ガイド。
Q. 重複チェックをスキップしたい
原則できません。
重複は 「同じ人が複数アカウントを持つ」「他の人のIDを誤って入力した」 といった事故の元なので、必ず解消してから保存してください。
どうしてもやむを得ない理由がある場合は管理者へ相談してください。
