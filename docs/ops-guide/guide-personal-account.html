🔑 個人アカウントガイド App 627 / 626

📌 これは何？

個人PCに Windowsログオン名 と M365アカウント を
ボタン1つで自動割り当てする仕組みです。

ボタン1回 → 3アプリ同時更新

📋 やり方はたった3ステップ

  1. PC管理台帳（594）で、対象のPCレコードを開く
  2. 画面にある
    📋 アカウント自動登録
    ボタンをクリック
  3. 「✅ 完了しました！」と出たら成功 🎉

⚙️ 裏で何が起きてるの？

（知らなくても大丈夫。興味がある人向け）

🎰 採番アプリ(626)
空きアカウントを取得
→
🔑 アカウント台帳(627)
新レコードを自動作成
→
💻 PC台帳(594)
👤 社員マスタ(595)
🎰 採番(626)
3つ同時更新！
🛡️ 途中で失敗しても自動で元に戻る（ロールバック）ので、データが壊れることはありません。

🔄 自動で作られるもの

項目どう作られるか例
ログオン名採番アプリから自動取得jbm00009
Windows名ログオン名 + [メール@前]jbm00009[m-kondo]
M365 IDメール@前 + @kensetsutoso01...m-kondo@kensetsutoso01.onmicrosoft.com
パスワード群採番アプリから自動コピー（初期パスワード）
アカウント状態自動で「有効」にセット有効 / 在籍

⚠️ 使える条件

条件OK / NG
種別が「個人」✅ OK
種別が「共有」「JR」など❌ NG（手動で）
利用者名が入力済み✅ OK
利用者名が空❌ NG（先に入力）
まだアカウント未登録✅ OK
もう登録済み❌ NG（二重登録防止）

🆘 困ったとき

🤔 「採番に空きがありません」と出た
→ 管理者に連絡。アカウント採番(626)に未使用レコードを追加してもらう。
🤔 「すでに紐付け済みです」と出た
→ そのPCは登録完了済み。もう何もしなくてOK。
❌ エラーが出た
→ データは自動で元に戻ります。管理者にエラーのSTEP番号を伝えてください。
