💻 PC台帳ガイド App 594

📌 このアプリは何？

会社のすべてのPCを管理する台帳です。
「誰が」「どのPCを」「いつから」使っているかが分かります。

🆕 新しいPCを登録する

  1. ＋ボタンで新規レコードを追加
  2. 種別を選ぶ
    種別意味
    個人1人が専用で使うPC
    共有みんなで使うPC
    JR端末JR用端末
    サーバーNASサーバー・NAS
  3. 利用者名をルックアップで選ぶ（個人の場合）
  4. PC名・シリアル番号・スペックなど必要事項を入力
  5. 保存ボタンを押す
✅ 個人PCを保存するとガイド画面が出ます。
「次にやること」を教えてくれるので、そのまま進めてOK！

🔄 PCを買い替える

  1. 古いPCのレコードを開く
  2. PC買替ボタンをクリック
  3. 新しいPCの情報を入力して保存
  4. 古いPCは自動で「使用停止」になる
💡 アカウントは自動で引き継ぎ。再登録は不要です。

📋 棚卸をする

  1. 一覧画面の上にある検索パネルを開く
  2. 拠点・種別・状態で絞り込む
  3. 各PCの現物を確認して、状態を更新する
🔍 カード表示に切り替えると、PCの状態が一目で分かります。

👀 画面の見方

🟥 一覧で行が赤い

🔴 アカウントが紐付いていない個人PCです。
→ レコードを開いて「アカウント自動登録」ボタンを押してください。

💬 保存後に出るポップアップ

📌 次にやること（アカウント登録やM365設定）への案内です。
「閉じる」で消えます。不要なら無視してOK。

❌ エラーが出た

🛟 データは自動で元に戻るので安心。
エラーログ（App 656）に記録されます → 管理者に連絡。

🚫 やってはいけないこと

NG操作理由
同じPCで2回「自動登録」を押す二重登録になる（実際にはブロックされます）
種別「共有」で自動登録ボタンを押す個人専用です（アラートが出ます）
利用者名を入れずに保存アカウント紐付けができなくなります
