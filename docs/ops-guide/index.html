📚 用語集 ― これだけ覚えればOK

画面に出てくる言葉の意味です。気になったときに見てください。

用語意味（やさしい説明）
レコード1件1件のデータ。Excel でいう「1行」のこと。
レコード番号 / $idレコードに自動で付く番号。重複しないユニークな番号。
ルックアップ他のアプリから情報を引っ張ってくる機能。クリックすると候補が出る。
サブテーブル1つのレコードの中にある「小さな表」。複数行を入れられる。
EMP-ID社員1人に1つだけ自動で付く番号（例：EMP-0042）。
PC台帳（594）会社のすべてのPCを管理する一覧表。
アカウント台帳（627）WindowsログインやM365アカウントを管理する一覧表。
社員マスタ（595）社員名簿。氏名・所属・退職日などを管理。
採番マスタ（626 / 667）未使用のアカウント番号がストックされている棚。

🆘 困ったとき・分からないとき

  1. まず該当のガイド（上のカード）を見る。各ガイドの末尾に「よくある質問」があります。
  2. エラーが出たら、画面を閉じずに エラーメッセージとSTEP番号 をメモ。
  3. データが壊れる心配はありません（自動で元に戻ります）。落ち着いて管理者へ連絡してください。
  4. 急ぎでない場合は エラーログ（App 656） も自動で記録されています。
