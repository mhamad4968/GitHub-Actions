# FAQ ポータル成果物ログ（置き場所の台帳）

**狙い**: 「どこに何があるか分からない」を防ぐ。FAQ ポータルの運用に必要な成果物（HTML・プロキシ・Windows 起動スクリプト等）の**正本の場所**と、配布・コピー先を**日付で追跡**する。

## 正本（原則）

- **正本（推奨）**: リポジトリ内の以下（Gitで追える場所）
  - `scripts/faq-portal-full.html`
  - `scripts/faq-kintone-proxy/`
  - `scripts/faq-windows/`
  - 関連ドキュメント: `docs/faq-portal-*.md`

**例外**: 社内PCの都合で一時的に `Documents` や共有に置くことはあるが、**最終的に正本へ戻す**（または正本が別リポ/別共有なら、このログに明記する）。

## 更新ルール（必須）

次のどれかをしたら、このファイルに **1 行**追記する。

- `faq-portal-full.html` を更新した
- `faq-kintone-proxy` の `.env.example` / `package.json` / `server.*` 等を更新した
- `faq-windows` の bat / txt（`proxy-url.txt` 等）を更新した
- 「正本の置き場所」が変わった（リポ→共有、共有→リポ 等）

## 追記テンプレ（コピペ）

```text
YYYY-MM-DD: [何を更新したか] / 正本: [パス] / 配布先(任意): [パス] / 注意: [権限・未コピー・未同期など]
```

## ログ（新しいものを下に追記）

```text
2026-04-05: 初版（FAQポータル成果物の所在が分からなくなる再発防止の台帳を追加）
```
