🆕 新しいPCを登録する

📝 新規登録のながれ

  1. PC管理台帳を開いて ＋（レコード追加） をクリック
  2. 種別を選ぶ（個人PC → 「個人」、みんなで使うPC → 「共有」）
  3. 利用者名をルックアップで選ぶ（個人の場合）
  4. PC名・シリアル番号・スペックなどを入力
  5. 保存ボタンを押す
✅ 保存すると、「次にやること」を教えてくれるガイド画面が出ます。
そのまま案内に従えばOKです。
🔗 アカウント自動登録（いちばん大事！）

🎯 これは何？

新しいPCに Windowsログオン名・M365アカウント を自動で割り当てる機能です。
ボタン1つで 3つのアプリを同時に更新 します。

3アプリ一括更新

📋 やり方（3ステップ）

  1. PC管理台帳で、対象のPCレコードを開く
  2. 画面にある 📋 アカウント自動登録 ボタンをクリック
  3. 「完了しました！」が出たら成功 🎉

⚠️ 使えるのは「個人」のPCだけ

🚫 共有PC・JR端末・サーバーでは、このボタンは使えません。
「種別が共有です」というメッセージが出ます。→ 手動で紐付けてください。

項目 例
Windows名 jbm0009+[m-kondo]
M365 ID m-kondo@kensetsutoso01.onmicrosoft.com
アカウント状態 有効 / 在籍
🔄 PCを買い替えるとき

🔄 買替のながれ

  1. PC管理台帳で古いPCのレコードを開く
  2. PC買替ボタンをクリック
  3. 新しいPCの情報を入力して保存
  4. 古いPCは自動で「使用停止」になる
💡 アカウント情報は自動で引き継がれるので、再登録は不要です。
📋 棚卸（たなおろし）

📦 棚卸のやり方

  1. PC管理台帳の一覧画面で 検索パネル を使って絞り込み
  2. 各PCの現物を確認し、状態を更新
  3. 一覧画面のカード表示で、視覚的に確認
🔍 検索パネルは一覧画面の上部にあります。
拠点・種別・状態で絞り込めます。
⚠️ 画面に出る警告の意味

🟥 一覧画面の赤い行

🔴 「個人PCなのに、アカウントが紐付いていない」 という意味です。

対処 → そのレコードを開いて 📋 アカウント自動登録 ボタンを押してください。

赤くなる条件：種別＝個人 ＋ 状態＝使用中 ＋ アカウント台帳番号＝空欄

💬 保存後のガイド画面（コンシェルジュ）

📌 個人PCを保存したあとに出る案内ポップアップです。

「アカウント管理台帳を開く」「M365管理センターを開く」のリンクが表示されます。
閉じるボタンで消せます。次のステップの参考にしてください。

❌ エラーが出たら

🛟 エラーメッセージに 「STEPいくつ」 と表示されます。

あわてなくて大丈夫。データは自動で元に戻ります（ロールバック）。
エラーログ（App 656）に詳細が残るので、管理者に連絡してください。
❓ よくある質問
🤔 ボタンが表示されないのはなぜ？
レコードの詳細画面で表示されます。一覧画面や編集画面では出ません。
また、すでにアカウントが紐付いているPCにもボタンは出ますが、
押すと「すでに紐付け済みです」と教えてくれます。
🤔 共有PCのアカウントはどうするの？
共有PCの場合、自動登録ボタンは使えません。
アカウント管理台帳（627）を直接開いて、手動でレコードを作ってください。
共有アカウント採番マスタ（667）から番号を確認できます。
🤔 採番アプリに空きがないと言われたら？
アカウント採番（626）に、未使用のアカウントが残っていません。
管理者に連絡して、新しいアカウントを追加してもらってください。
🤔 間違えて登録してしまったら？
管理者に連絡してください。
アカウント管理台帳（627）のレコードを削除し、
PC管理台帳（594）のアカウント番号欄を空にすれば元に戻せます。
🤔 エラーが出てもデータは壊れない？
はい、壊れません。
途中でエラーが起きた場合、自動で「ロールバック」（巻き戻し）されます。
中途半端な状態にはならないので、安心してください。
🤔 EMP-IDって何？
社員マスタに付いている 社員管理番号 です。
EMP-0001 のような形式で、全社員にユニークな番号が振られています。
今後、すべてのアプリを正確につなぐための「名札」のようなものです。
