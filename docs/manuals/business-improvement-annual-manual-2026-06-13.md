# 業務改善 年次ポイント集計 操作メモ（2026-06-13 更新）

**読者**: 浜田（集計実行者のみ）  
**正本**: 本ファイル（Word 転記は任意 — Q-MANUAL-01）  
**操作画面**: **699 ご利用ガイド**（713 はデータ保存のみ）  
**不明時**: Cursor / AI に照会可

---

## 1. 概要

- **目的**: 年度末に社員別年間ポイントを確定し、人事へ報告する。
- **対象年度**: **5/1 〜 翌4/30**（年度キー例: `2026`）。
- **集計基準日**: **集計実行日（本日）** を自動設定。基準日時点で **完了** の案件のみ集計。
- **未完了**: 翌年度繰越。

## 2. 手順

1. kintone Space 5 に **admin** でログイン。
2. **【業務改善提案システム】ご利用ガイド**（699）を開く。
3. **「年次ポイント集計」**（admin のみ）→ **暗唱番号**入力。
4. オーバーレイで **年度** を選び **設定を保存**。
5. **集計実行** → 再度 **暗唱番号** → 確認 → 実行。
6. **表1 / 表2 / 明細** を確認。検算パネル（集計件数 vs 新①完了件数）が一致（緑）であること。
7. 必要なら **CSV / xlsx / PDF** をダウンロード。
8. Outlook 等で人事へ **手動送信**（自動メールなし）。
9. 問題なければ **年度締め**（再集計ロック）。

## 3. 表の見方

| 帳票 | 内容 |
|------|------|
| **表1** | 月別件数（完了日の月）。セルクリックで該当提案一覧 |
| **表2** | 社員別 **A評価 / A-pt / B評価 / B-pt / C評価 / C-pt / 合計-pt** |
| **明細** | 1行1提案者。行クリックで新①詳細 |

- 複数提案者: **按分なし**（全員に同一ポイント — Q-ANN-02）。

## 4. 暗唱番号

- 保存場所: **697 設定マスタ** → 共通設定 → **`年次暗唱番号`**
- 入力タイミング: **パネル起動時** と **集計実行時**（毎回）

## 5. よくある例

| 状況 | 扱い |
|------|------|
| 基準日前に差戻し→再申請→完了 | **当該年度** に含む |
| 基準日時点で未完了 | **翌年度** 繰越 |
| 完了日が空 | 更新日時等で代替（要目視確認） |
