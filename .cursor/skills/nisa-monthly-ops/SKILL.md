# NISA 月次オペ（個人レーン）

## いつ使う

- **毎月15日前後**のセッション（CIOが自発声かけ）
- 浜田が「NISA見て」「積立額どうする」と言ったとき
- 方針メモ `docs/personal/nisa-ops.md` を更新するとき

**使わない**: kintone / deploy / 業務レーンと同一ターンで混ぜない。専用金融MCPは作らない。

## 役割

| 誰 | やること |
|----|----------|
| CIO | スクショ指示・読み取り・案1つ・メモ更新 |
| DeepSeek | 必要時のみ盲点1問（制度・出口） |
| Kimi | 必要時のみ長文記事の要約 |
| DDG | 必要時のみ制度・記事の事実確認 |
| 浜田 | GO・証券画面操作・スクショ貼付 |

## 手順（毎回この順）

1. **Read** `docs/personal/nisa-ops.md`（現状・触らないを確認）
2. 浜田へ貼付依頼（§41は後段のGO用。指示文は短く）:

```
NISA月次です。証券の「資産状況」（投資可能額・積立設定・保有が写る画面）を1枚貼ってください。
変更があれば SBIラップ／iDeCo も任意で。
```

3. スクショから読み取り、チャットに固定フォーマットで出す:

```
【NISA月次 yyyy-mm】
- つみたて月額: …
- 成長枠: …
- 銘柄: …
- 評価額帯: …（細かい口座番号は書かない）
- ラップ／iDeCo: （スクショあれば）…
- 判定案（1つだけ）: 据置 | 増額→月○万 | 減額→月○万
- 理由: 1〜2行
```

4. **増額・減額は浜田単独決めない**（合意済み）。案を出し §41 で GO 確認。
5. GO後: 浜田が証券操作。変更時は「同じ画面をもう1枚」で確認。
6. `docs/personal/nisa-ops.md` の現状行を更新（コミットは浜田が依頼したときのみ）。

## 毎月やること / やらないこと

- **やる**: ①月額・銘柄・枠の消化率 ／ ③調整案は1つ  
- **必須にしない**: ②生活防衛資金（変化があるときだけ）  
- **やらない**: 毎週催促・銘柄追加の常時提案・発注代行・3500万説の無批判な目標化  

## 目標数字の扱い

- 「1736万」= 記事試算のイメージ。必要額そのものではない。  
- 「老後3500万」= ネットの一律説。年金・支出で変わる → 鵜呑み禁止。  
- 詳細は正本メモ §3。

## 情報収集

専用MCPなし。順序: 正本メモ →（不足時）DDG → DeepSeek/Kimi。  
**日次巡回はしない。** 毎月15日前後の月次前に制度・変更の要点だけ DDG。浜田がURLを投げたときだけ深掘り。  
rag ingest はメモ・切り抜きが増えてから（後追い）。

## 判断が難しいとき

正本 `docs/personal/nisa-ops.md` **§7**（聞き先表・窓口質問例）。  
AIは質問文の下書きまで。SBI／iDeCo窓口・FP等への確認は浜田。結果スクショでメモ更新。
